# echoes-of-ruin

専門学校の卒業制作として制作している、ポストアポカリプスを題材とした探索型謎解きゲームのプロトタイプです。  
プレイヤーが廃墟となった世界を探索し、端末認証やドア開閉などのギミックを通して物語を進める体験を目指しています。

## 使用技術

- Godot 4.6.2
- GDScript

## 実装内容

- タイトル画面
- プレイヤー移動
- 会話UI
- 端末認証
- ドア開閉
- 場面遷移
- ポーズメニュー

## 操作方法

- ← →：移動
- Space / Enter：ジャンプ
- E：インタラクション
- Esc：一時停止メニュー

## 制作で意識したこと

プレイヤーが迷わず操作できるように、画面遷移やインタラクションの流れを整理しながら制作しています。  
また、世界観とゲームシステムが自然につながるように、探索や謎解きの導線を意識しています。

## この制作で学んだこと

企画した内容を実際に動く形にする過程で、仕様を整理し、必要な機能を段階的に実装していく重要性を学びました。  
また、ユーザーがどのように操作し、どこで迷いやすいかを考えながら制作することで、相手の視点に立って使いやすい仕組みを考える力を身につけています。
