# ART_DIRECTION — 美术方向管理

> 本文档用于记录《Echoes of Ruin（終末残響）》的美术方向决策。  
> 只记录已经讨论并形成共识的方向；尚未决定的内容明确标记为 TBD。  
> 后续按阶段持续更新，作为概念设计、AI 生成、像素资产制作和场景实现的共同依据。

## 0. 使用方式

### 0.1 信息来源与优先级

- **游戏设定／世界观／剧情／玩法事实**：以仓库中的现行设计文档为主要参考（如 `WORLD_BIBLE.md`、`GAME_DESIGN.md`、`MAP_DESIGN.md`、`CHARACTER_DESIGN.md` 等）。
- **美术方向与视觉决策**：以本对话中逐步确认的结论为主，并整理到本文件；仓库中其他文档已有的美术描述只作为背景参考，不自动视为最终美术规范。
- 当既有游戏设定与新的美术方案发生冲突时，优先指出冲突并讨论，不擅自修改核心设定。
- 当游戏设定存在空白、逻辑不足或会限制美术落地时，应主动提出疑问，由作者决定是否修订相关游戏设计文档。

### 0.2 工作方式

后续采用“讨论 → 质疑／校验 → 形成阶段结论 → 更新 ART_DIRECTION”的循环。避免在高层方向尚未确定时过早锁定色温、像素尺寸、材质参数等执行细节。

美术方向按以下顺序逐层建立：

1. 核心玩家体验（Experience Goal）
2. 视觉支柱（Visual Pillars）
3. 世界视觉逻辑（World Visual Logic）
4. 视觉语言（Shape / Color / Material / Lighting / Scale / Detail）
5. 区域差异与统一规则
6. 游戏可读性与镜头规则
7. 资产体系
8. 技术美术规范
9. Vertical Slice 验证
10. Art Bible / AI Prompt / Production Pipeline 固化

前层决策约束后层决策。已经确认的技术基准直接记录并作为后续资产统一标准；仍未确认的色板、区域细节等继续标记为 TBD。

# 1. 核心玩家体验 — 已确认

## 1.1 Experience Statement

游戏的持续情绪基底是：

- **压抑感**
- **孤独感**

这两种负面情绪不是为了单纯让玩家绝望，而是作为探索动力的一部分。

玩家在空无、压抑、无法立即理解的世界中前进时，应持续产生：

> “这里究竟发生了什么？”

这种疑问推动玩家继续探索，并期待通过环境、遗留物与逐步揭示的信息，最终理解世界的真相。

## 1.2 体验循环

当前确认的核心体验关系可以概括为：

**压抑 / 孤独**  
→ 感受到世界异常与缺失  
→ 产生疑问与好奇  
→ 向前探索  
→ 得到局部答案或新线索  
→ 发现更大的未知  
→ 再次向前

因此，美术的任务不是只表现“废墟很悲惨”，而是同时承担：

- 建立持续的压抑与孤独基调；
- 让空间本身不断留下值得追查的视觉问题；
- 通过场景中的缺失、痕迹、对比和异常，维持玩家的探索欲；
- 避免把负面情绪做成完全静止、无目标的绝望感。

## 1.3 与现有游戏设计的连接

该体验方向与现有设计保持一致：

- 主角在失忆状态下与玩家一起从零理解世界；
- 游戏以探索和调查为主要信息获取方式；
- 世界整体安静、人口与活动痕迹大量消失；
- 工业设施等区域仍保留制度和功能秩序的残余；
- 真相按照区域推进逐步揭示，而不是一次性说明。

因此，后续美术应优先思考“环境如何提出问题”，而不仅是“环境如何好看”。

## 1.4 当前阶段的设计推论

- 画面需要保留足够的**负空间、空置感或缺失感**，使孤独能够被空间直接感知。
- 场景需要存在明确但不过度解释的**视觉异常与遗留痕迹**，作为探索诱因。
- 压抑不能等同于“所有区域都同样黑、脏、灰”；否则会降低区域辨识度和长期探索动力。
- 视觉上需要在持续负面基调中保留少量“前方值得去看”的吸引点，但具体通过光、构图、色彩还是物件实现，TBD。

# 2. 负面情绪的世界来源 — 已确认

四类来源都会存在，但重要性与表现方式不同。

## 2.1 D：文明的物理性死亡 — 核心来源

这是当前优先级最高的来源。

主角醒来时，人类已经消失数十年。城市不只是“没有居民”，而是作为一个依赖人工生命维持、能源和自动化系统运行的巨大人工文明，已经进入或完成了**系统性死亡**。

玩家面对的核心问题不是单纯“谁把这里毁掉了”，而是：

> “这个曾经完整运作的世界为什么已经死去，而我为什么还在这里？”

美术上应表现文明从“运行中的系统”变成“停止、衰退、失去维护的系统”的过程与结果。

**重要限制：**
- “文明死亡”不等于所有区域都被炸毁、坍塌或变成传统废土。
- 序章工業区休眠设施依靠独立备用电源维持到主人公觉醒，因此允许存在局部低功耗设备、紧急照明、终端和安全系统。
- 不同区域应具有不同的“死亡方式”和衰退程度，而不是统一做成同一种破败。

## 2.2 A：空旷与人的渺小 — 强力辅助来源

居民区的核心空间概念是：

> **空旷而拥挤。**

建筑本身高度密集、人口容量巨大、空间压迫，但其中已经没有居民。大量为“很多人”设计的高层住宅、通道、生活设施与交通结构，在只剩主人公一人后反而强化孤独与渺小感。

需注意：
- “拥挤”主要来自建筑密度、重复结构、容量和尺度；
- “空旷”来自人的缺席、声音与活动的缺席、可见空间中的主体稀少；
- 两者共同制造“这个地方曾为无数人存在，现在却只剩一个人”的反差。

## 2.3 B：人类生活留下的痕迹 — 广泛存在，但不是“突然消失”

生活痕迹会贯穿多个区域，用于证明世界曾经被真实地使用过，并让玩家追问过去的人去了哪里。

但世界不是“一夜之间所有人同时消失”。主人公醒来距离人类消失已有数十年，因此环境叙事不能普遍依赖“刚刚离席”的瞬时定格。

后续表现需要区分：

- 能长期保存的结构与物件痕迹；
- 自动清扫、防疫、维护系统曾经工作过后留下的“被整理过的缺席”；
- 材料老化、灰尘、腐蚀、褪色、沉积造成的时间感；
- 少量能够跨越数十年仍成立的个人化痕迹；
- 档案、标记、改造痕迹、磨损方式等间接人类证据。

避免大量使用仍像“昨天刚有人住过”的杯子、食物、凌乱床铺等画面，除非所在环境和保存条件能够解释。

## 2.4 C：冰冷制度与技术管理 — 世界观强化来源

制度化的管理痕迹应作为科幻世界的重要视觉层存在：

- 编号与权限；
- 身份认证；
- 标准化模块；
- 资源等级与区域等级；
- 机械识别标记；
- 自动系统接口；
- 不同阶层获得不同空间与资源待遇的痕迹。

它不是全游戏唯一的压迫来源，但可以让玩家逐渐意识到：

> 这个文明在活着的时候，本身就存在冷漠、等级化和选择性保护。

# 3. 当前需要特别防止的方向偏差

## 3.1 “末日 = 到处都是废墟”

本项目的核心不是单纯的战争废墟观光。尤其工業区内部，主要损伤来自长期无人维护、能源衰竭与局部结构失效，而不是全面暴动或洗劫。

## 3.2 “几十年后 = 所有东西完全断电”

城市大部分系统确实已经停止，但序章工業区的残余备用电源属于明确例外。

## 3.3 “生活痕迹 = 瞬间消失现场”

时间跨度要求环境叙事表现“经过多年之后剩下什么”，而不是只复制常见的突然撤离场景。

## 3.4 “压抑 = 全程黑灰脏”

情绪基调需要持续，但视觉表现必须允许区域差异与节奏变化，否则长期探索会产生视觉疲劳。

## 3.5 “废墟 = 自然重新占领城市”

本项目的大多数区域不应使用常见的“藤蔓、青苔、杂草、鸟群、昆虫”来快速表达废弃感。生态缺席本身是世界观的一部分。

# 4. 能源状态的世界规则 — 已确认

## 4.1 唯一仍有供能的区域：序章工業区

- **除最开始的工業区外，其他地区已经没有可用能源。**
- 工業区依靠独立的备用电源维持到主人公苏醒时，但能源已经接近耗尽。
- 工業区只能维持最低限度设施，包括生命维持、紧急觉醒、安全系统和少量必要终端相关的低功耗功能。
- 工業区的残余供电是例外，不代表整座城市仍在缓慢运行。

## 4.2 对美术方向的直接影响

- 工業区可以使用少量状态灯、应急照明、残余终端和低功耗机械反应。
- 后续区域不能依赖仍在工作的屏幕、霓虹、自动门、广告牌、公共照明或持续运转的机械作为常规视觉元素。
- 后续区域的视觉信息、环境叙事与探索诱因，必须主要来自**建筑本体、自然/外部光、材料老化、静态遗留物、结构损伤与空间关系**。

# 5. 主角随身照明系统 — 已确认

## 5.1 设备定位

主角将在前期工業区获得一件军方／维护用途的稳定随身工作灯。

- 不是手持求生手电。
- 主要目的不是制造恐怖玩法，而是解决无电区域的基础探索可见性。
- 设备应体现未来专业设备“耐用、可靠、长寿命”的逻辑。
- 主要功能是照明，不作为全能扫描或信息读取工具。

## 5.2 光照形态

- 光源以主角自身为中心。
- 基本形态为**近似圆形的局部光域**。
- 边缘自然衰减。
- 中心区域清晰，外围逐渐衰减至黑暗。
- 不做明显的长距离定向手电光束。

## 5.3 光照范围

采用**中等范围**。

目标：
- 足够看清主角周围的地面、附近门体、交互物和基础空间关系。
- 无法在原地看清较远区域的完整细节。
- 不因范围过大削弱无电世界的压抑感，也不因范围过小违背专业设备的实用性。

体验原则：

> 给玩家一个稳定的最小可见范围，而不是舒适的完整视野。

# 6. Visual Pillars — 第一版已确认

## 6.1 死亡已久的城市

这不是灾难刚刚发生后的现场，而是一座已经失去人类、能源与维护很多年的城市。

核心要求：
- 时间必须能够被看见；
- 环境应体现长期停摆、老化、腐蚀、褪色、沉积、结构失效等结果；
- 不把“死亡”简单等同于全面爆炸、战争废墟或到处倒塌；
- 不同区域应有不同的老化方式与保存程度。

## 6.2 人类曾存在的各种痕迹

城市虽然已经无人，但不能像从未有人生活过的空壳。

核心要求：
- 通过长期仍可保留的生活、工作、制度、改造和使用痕迹，让玩家持续感受到“这里曾经有人”；
- 痕迹应符合数十年后的保存逻辑；
- 痕迹既包括私人生活层，也包括公共设施、职业活动、制度管理和阶级差异留下的证据；
- 这些痕迹应成为环境叙事的重要来源，而不只是装饰。

## 6.3 发达的未来科技感

世界必须让玩家明确感到：这是一个曾经高度发展的未来文明，而不是把现代城市做旧以后得到的普通废墟。

核心要求：
- 科技感优先来自建筑、设备、基础设施、材料、模块化结构、人机共用设计、自动化痕迹与制度化系统；
- 不依赖“霓虹灯、全息屏、到处发光”等表面符号维持未来感；
- 未来技术必须体现功能、维护、能源与物理结构逻辑；
- 即使设备已经断电、损坏，仍应从造型与结构上看出其时代先进性。

## 6.4 三者之间的关系

> **先进文明的遗骸**  
> + **时间造成的长期死亡**  
> + **仍能被阅读的人类痕迹**

# 7. 生态缺席与区域例外 — 已确认

## 7.1 基准规则

除明确例外区域外，城市中不应出现可见的生物活动。

这意味着大多数区域默认：

- 看不到鸟、昆虫、小动物；
- 看不到自然扩张形成的杂草、藤蔓、青苔覆盖；
- 废弃感主要依靠人工环境的老化、灰尘、腐蚀、沉积、破损与空置来表达；
- “人类消失后自然重新夺回城市”不是本作的默认末日图景。

这一规则服务于一个关键视觉印象：

> **人类消失以后，自然也没有回来。**

## 7.2 工業区外缘例外

靠近城市外部自然环境的工業区边缘，可以出现**少量、稀疏、脆弱的植物**。

但这些植物应体现：

- 生存条件差；
- 数量稀少；
- 分布不连续；
- 不能形成茂盛绿化或“自然正在全面复苏”的感觉。

它们更像环境边界上的残存生命，而不是城市再野化的开端。

## 7.3 上层区生态状态 — TBD

上层区过去拥有更多人工绿地、生态设施和“接近自然”的资源，因此其数十年后的生态状态暂不锁定。

目前保留两个方向：

- **全部枯死**：强化“连上层独占的自然也无法脱离人工系统生存”的主题；
- **局部失控生长／长满**：如果其封闭生态或某些系统具有足够自持能力，可形成与其他区域强烈不同的视觉冲击。

该选择将影响上层区的情绪、色彩、材料覆盖和与下层区的对比，因此需要单独讨论后再确认。

## 7.4 当前约束

在上层区方案确认之前：

- 不把“全城绝对无植物”写成不可破例的全局规则；
- 不在下层居住区、地下基础设施、科学技术区、政治中枢等区域随意加入生物性装饰；
- AI 生成提示默认排除常见的过度绿化废墟元素，除非该资产属于工業区外缘或未来确认的上层生态区域。

# 8. 区域对比原则 — 初步确认

## 8.1 不把“渺小感”设为全局视觉支柱

“人类个体在巨大文明遗骸中的渺小感”不作为全项目强制 Visual Pillar，而作为居民区的重要区域特征。

## 8.2 区域必须有情绪与阶级上的对比

虽然全世界都已经死亡多年，但不同区域不能看起来像同一种废墟。

尤其需要保留：

- **下层居住区**：高密度、拥挤、重复、压迫；“空旷而拥挤”是重要空间特征。
- **上层／富裕区域**：在空间余裕、材料品质、采光、环境质量、景观设计、公共设施完整度等方面，体现过去更“繁荣、舒适、体面”的社会位置。

“欣欣向荣”主要指**过去的设计意图与空间气质仍可被看见**，而不是这些区域在主人公到达时仍然活跃或运转。

# 9. 尚未决定

当前尚未锁定：

- 视觉支柱是否需要在现有三项之外继续增加
- “文明物理性死亡”的更多区域化表达机制
- 上层区最终生态状态
- 各区域更具体的老化方式
- 最终色板
- 镜头与构图的细节规则
- 各区域资产清单与模块化规范
- 像素画技术参数（仓库中已有数值暂不自动视为本对话确认结果）
