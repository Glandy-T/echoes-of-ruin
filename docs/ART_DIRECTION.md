# ART_DIRECTION — 美术方向管理

> 本文档用于记录《Echoes of Ruin（終末残響）》的美术方向决策。  
> 只记录已经讨论并形成共识的方向；尚未决定的内容明确标记为 TBD。  
> 后续按阶段持续更新，作为概念设计、AI 生成、像素资产制作和场景实现的共同依据。

## 0. 使用方式

美术方向按以下顺序逐层建立：

1. 核心玩家体验（Experience Goal）
2. 视觉支柱（Visual Pillars）
3. 世界视觉逻辑（World Visual Logic）
4. 视觉语言（Shape / Color / Material / Lighting / Scale / Detail）
5. 区域差异与统一规则
6. 游戏可读性与镜头规则
7. 资产体系
8. 技术美术规范
9. Vertical Slice 验证
10. Art Bible / AI Prompt / Production Pipeline 固化

前层决策约束后层决策。未到对应阶段时，不提前锁定具体画风、色板、像素密度等技术细节。

# 1. 核心玩家体验 — 已确认

## 1.1 Experience Statement

游戏的持续情绪基底是：

- **压抑感**
- **孤独感**

这两种负面情绪不是为了单纯让玩家绝望，而是作为探索动力的一部分。

玩家在空无、压抑、无法立即理解的世界中前进时，应持续产生：

> “这里究竟发生了什么？”

这种疑问推动玩家继续探索，并期待通过环境、遗留物与逐步揭示的信息，最终理解世界的真相。

## 1.2 体验循环

当前确认的核心体验关系可以概括为：

**压抑 / 孤独**  
→ 感受到世界异常与缺失  
→ 产生疑问与好奇  
→ 向前探索  
→ 得到局部答案或新线索  
→ 发现更大的未知  
→ 再次向前

因此，美术的任务不是只表现“废墟很悲惨”，而是同时承担：

- 建立持续的压抑与孤独基调；
- 让空间本身不断留下值得追查的视觉问题；
- 通过场景中的缺失、痕迹、对比和异常，维持玩家的探索欲；
- 避免把负面情绪做成完全静止、无目标的绝望感。

## 1.3 与现有游戏设计的连接

该体验方向与现有设计保持一致：

- 主角在失忆状态下与玩家一起从零理解世界；
- 游戏以探索和调查为主要信息获取方式；
- 世界整体安静、人口与活动痕迹大量消失；
- 军事设施等区域仍保留制度和功能秩序的残余；
- 真相按照区域推进逐步揭示，而不是一次性说明。

因此，后续美术应优先思考“环境如何提出问题”，而不仅是“环境如何好看”。

## 1.4 当前阶段的设计推论

- 画面需要保留足够的**负空间、空置感或缺失感**，使孤独能够被空间直接感知。
- 场景需要存在明确但不过度解释的**视觉异常与遗留痕迹**，作为探索诱因。
- 压抑不能等同于“所有区域都同样黑、脏、灰”；否则会降低区域辨识度和长期探索动力。
- 视觉上需要在持续负面基调中保留少量“前方值得去看”的吸引点，但具体通过光、构图、色彩还是物件实现，TBD。

# 2. 负面情绪的世界来源 — 已确认

四类来源都会存在，但重要性与表现方式不同。

## 2.1 D：文明的物理性死亡 — 核心来源

这是当前优先级最高的来源。

主角醒来时，人类已经消失数十年。城市不只是“没有居民”，而是作为一个依赖人工生命维持、能源和自动化系统运行的巨大人工文明，已经进入或完成了**系统性死亡**。

玩家面对的核心问题不是单纯“谁把这里毁掉了”，而是：

> “这个曾经完整运作的世界为什么已经死去，而我为什么还在这里？”

美术上应表现文明从“运行中的系统”变成“停止、衰退、失去维护的系统”的过程与结果。

**重要限制：**
- “文明死亡”不等于所有区域都被炸毁、坍塌或变成传统废土。
- 军事休眠设施在世界设定中曾依靠独立军用电力与自动控制长期维持，主人公的觉醒本身就是残余系统的最后行为之一，因此序章仍允许存在局部低功耗设备、紧急照明、终端和安全系统。
- 不同区域应具有不同的“死亡方式”和衰退程度，而不是统一做成同一种破败。

## 2.2 A：空旷与人的渺小 — 强力辅助来源

居民区的核心空间概念是：

> **空旷而拥挤。**

建筑本身高度密集、人口容量巨大、空间压迫，但其中已经没有居民。大量为“很多人”设计的高层住宅、通道、生活设施与交通结构，在只剩主人公一人后反而强化孤独与渺小感。

这一矛盾具有较强的项目辨识度，后续可能发展为视觉支柱之一。

需注意：
- “拥挤”主要来自建筑密度、重复结构、容量和尺度；
- “空旷”来自人的缺席、声音与活动的缺席、可见空间中的主体稀少；
- 两者不应简单互相抵消，而应共同制造“这个地方曾为无数人存在，现在却只剩一个人”的反差。

## 2.3 B：人类生活留下的痕迹 — 广泛存在，但不是“突然消失”

生活痕迹会贯穿多个区域，用于证明世界曾经被真实地使用过，并让玩家追问过去的人去了哪里。

但世界不是“一夜之间所有人同时消失”。主人公醒来距离人类消失已有数十年，因此环境叙事不能普遍依赖“刚刚离席”的瞬时定格。

后续表现需要区分：

- 能长期保存的结构与物件痕迹；
- 自动清扫、防疫、维护系统曾经工作过后留下的“被整理过的缺席”；
- 材料老化、灰尘、腐蚀、褪色、沉积造成的时间感；
- 少量能够跨越数十年仍成立的个人化痕迹；
- 档案、标记、改造痕迹、磨损方式等间接人类证据。

避免大量使用仍像“昨天刚有人住过”的杯子、食物、凌乱床铺等画面，除非所在环境和保存条件能够解释。

## 2.4 C：冰冷制度与技术管理 — 世界观强化来源

制度化的管理痕迹应作为科幻世界的重要视觉层存在：

- 编号与权限；
- 身份认证；
- 标准化模块；
- 资源等级与区域等级；
- 机械识别标记；
- 自动系统接口；
- 不同阶层获得不同空间与资源待遇的痕迹。

它不是全游戏唯一的压迫来源，但可以让玩家逐渐意识到：

> 这个文明在活着的时候，本身就存在冷漠、等级化和选择性保护。

因此 C 同时服务于美术氛围与主题表达。

# 3. 当前需要特别防止的方向偏差

## 3.1 “末日 = 到处都是废墟”

本项目的核心不是单纯的战争废墟观光。尤其军事区内部，现有世界设定明确要求主要损伤来自长期无人维护、能源衰竭与局部结构失效，而不是全面暴动或洗劫。

## 3.2 “几十年后 = 所有东西完全断电”

城市大部分系统确实已经停止，但不同系统的寿命、供能优先级和区域条件不同。序章尤其需要残余系统仍能完成主人公觉醒与少量安全功能，否则会与既有世界逻辑冲突。

## 3.3 “生活痕迹 = 瞬间消失现场”

时间跨度要求环境叙事表现“经过多年之后剩下什么”，而不是只复制常见的突然撤离场景。

## 3.4 “压抑 = 全程黑灰脏”

情绪基调需要持续，但视觉表现必须允许区域差异与节奏变化，否则长期探索会产生视觉疲劳，反而削弱压抑与孤独的效果。

# 4. 能源状态的世界规则 — 已确认

## 4.1 唯一仍有供能的区域：序章军事区

世界当前的能源规则明确如下：

- **除最开始的军事区外，其他地区已经没有可用能源。**
- 军事区依靠独立的备用电源维持到主人公苏醒时，但能源已经接近耗尽。
- 军事区只能维持最低限度设施，包括与生命维持、紧急觉醒、安全系统和少量必要终端相关的低功耗功能。
- 军事区的残余供电是例外，不是整座城市仍在缓慢运行的代表。

因此，离开军事区后，玩家进入的是一个真正失去供能的城市。

## 4.2 对美术方向的直接影响

这条规则意味着：

- 军事区可以使用少量状态灯、应急照明、残余终端和低功耗机械反应，形成“最后一点系统活动”的感觉。
- 后续区域不能依赖仍在工作的屏幕、霓虹、自动门、广告牌、公共照明或持续运转的机械作为常规视觉元素。
- 后续区域的视觉信息、环境叙事与探索诱因，必须主要来自**建筑本体、自然/外部光、材料老化、静态遗留物、结构损伤与空间关系**。
- “文明的死亡”在军事区之后应更加彻底，形成从“濒死系统”进入“完全失能城市”的明确阶段变化。

## 4.3 当前需要警惕的问题

- 不能为了“科幻感”而在后期场景中随意加入仍亮着的终端、霓虹和全息设备。
- 如果大量室内区域完全无电，则必须另外解决玩家为什么能看清环境、如何导航、如何辨认可交互物的问题；这将直接影响后续的光照设计与关卡可读性。
- 后期的信息揭示不能过度依赖电子终端，必须提前建立纸质记录、机械结构、标识系统、物理档案、损坏设备状态等替代叙事手段。

# 5. 主角随身照明系统 — 已确认

## 5.1 设备定位

主角将在前期军事区获得一件军方／维护用途的稳定随身工作灯。

- 不是手持求生手电。
- 主要目的不是制造恐怖玩法，而是解决无电区域的基础探索可见性。
- 设备应体现未来军用／维护设备“耐用、可靠、长寿命”的逻辑。
- 主要功能是照明，不作为全能扫描或信息读取工具。

## 5.2 光照形态

- 光源以主角自身为中心。
- 基本形态为**近似圆形的局部光域**。
- 圆形应作为规则，而不是硬边数学圆；边缘需要自然衰减。
- 中心区域清晰，外围逐渐衰减至黑暗。
- 不做明显的长距离定向手电光束。

## 5.3 光照范围

采用**中等范围**。

目标：

- 足够看清主角周围的地面、附近门体、交互物和基础空间关系。
- 无法在原地看清较远区域的完整细节。
- 既不因范围过大削弱无电世界的压抑感，也不因范围过小违背军用／维护设备应有的实用性。

体验原则：

> 给玩家一个稳定的最小可见范围，而不是舒适的完整视野。

## 5.4 美术与关卡影响

该照明系统将直接影响：

- 暗区场景的构图与细节分布；
- 交互物的可辨识距离；
- 下水道及封闭设施的压迫感；
- 明暗层级与像素细节保留方式；
- 自然光区域与人工随身光区域之间的节奏差异。
