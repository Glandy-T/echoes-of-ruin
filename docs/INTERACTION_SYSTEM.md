# インタラクションシステム

## 目的

探索中の調査体験を統一し、対象の情報量に応じて見せ方を変える。環境観察と情報読解を自然に促し、主人公の視点を通じた物語理解を強める。

## 調査可能な物体の名称表示

プレイヤーが調査可能な物体の範囲に近づくと、物体の近くに名称だけを短く表示する。例：`休眠ポッド 05`、`認証端末`、`巡回表`。E キー、操作動詞、矢印は表示しない。プレイヤーが範囲から離れる、対話・詳細調査・ポーズ／設定・短いシステム TextBox を開くと表示を消し、閉じた後も範囲内なら再表示する。

GameUI は単一の全体 `InteractionNameLabel` を使用する。複数範囲が重なる場合は最後に有効になった発生元を表示し、無効ノードを自動的に整理する。名称表示は設定から無効化できるが、E による操作は維持する。

## 調査の分類

| 種別 | 適用対象 |
| --- | --- |
| 詳細表示型 | 持ち運び可能な道具、ファイル、布告、地図、記録媒体、重要物品。 |
| 簡易表示型 | 休眠ポッド、損壊設備、壁、家具、ドア、通常の環境痕跡。 |

## 詳細表示型

1. プレイヤーがインタラクションキーを押す。
2. 画面中央に物品または文書の詳細画像を表示する。
3. 主人公の会話ボックスを表示する。
4. 主人公が内容への短い評価または考察を述べる。
5. プレイヤーが詳細画面を閉じた後、行動を再開する。

詳細表示中は SceneTree を pause せず、主人公入力だけをロックする。

## 簡易表示型

1. プレイヤーがインタラクションキーを押す。
2. 主人公の会話ボックスを直接表示する。
3. 個別の詳細画像は表示しない。

簡易表示中は主人公の移動を停止し、短い会話を表示する。

## Room 1 でのチュートリアル適用

序章 Room 1「Cryogenic Room（休眠ポッド室）」では、両方の調査形式を初めて導入する。

- 簡易表示型：主人公の休眠ポッド、損壊休眠ポッド、死亡者の休眠ポッドなど。
- 詳細表示型：**暫定名** `休眠者識別票` と `休眠処置同意書`。
- `休眠者識別票` は、操作権を得た直後に最初に注意を向けさせる自然な誘導対象とする。
- `休眠処置同意書` は任意調査であり、主線の進行条件にしない。

## テキスト方針

調査テキストは情報を提示すると同時に、主人公の性格を表す。通常の調査テキストは短く保ち、台詞の内容は [CHARACTER_DESIGN.md](CHARACTER_DESIGN.md) の認知・口調の規則に従う。

## 実装ステータス

| 項目 | ステータス |
| --- | --- |
| 近接時の単一オブジェクト名称表示と、調査時の DialoguePanel | 実装済み。 |
| 物体固有の名称を対象付近に表示 | 実装済み。 |
| 詳細画像の表示・閉じる操作・行動再開 | 実装済み。 |
| 詳細表示中の Player 入力ロック、簡易表示中の主人公移動停止 | 実装済み。 |
| 対象ごとの詳細表示型／簡易表示型のデータ設計 | Investigation Point の Inspector 設定で実装済み。 |
