# インタラクションシステム

## 目的

探索中の調査体験を統一し、対象の情報量に応じて見せ方を変える。環境観察と情報読解を自然に促し、主人公の視点を通じた物語理解を強める。

## 調査可能な物体の名称表示

プレイヤーが調査可能な物体の範囲に近づくと、物体の上方に名称を短く表示する。例：`休眠ポッド`、`古い端末`、`掲示板`、`配給記録`。プレイヤーが範囲から離れると表示を消す。

この表示は、対象を調べられることを直感的に伝えるためのものである。

## 調査の分類

| 種別 | 適用対象 |
| --- | --- |
| 詳細表示型 | 持ち運び可能な道具、ファイル、布告、地図、記録媒体、重要物品。 |
| 簡易表示型 | 休眠ポッド、損壊設備、壁、家具、ドア、通常の環境痕跡。 |

## 詳細表示型

1. プレイヤーがインタラクションキーを押す。
2. 画面中央に物品または文書の詳細画像を表示する。
3. 主人公の会話ボックスを表示する。
4. 主人公が内容への短い評価または考察を述べる。
5. プレイヤーが詳細画面を閉じた後、行動を再開する。

詳細表示中はゲームを一時停止する。

## 簡易表示型

1. プレイヤーがインタラクションキーを押す。
2. 主人公の会話ボックスを直接表示する。
3. 個別の詳細画像は表示しない。

簡易表示中は主人公の移動を停止し、短い会話を表示する。

## Room 1 でのチュートリアル適用

序章 Room 1「Cryogenic Room（休眠ポッド室）」では、両方の調査形式を初めて導入する。

- 簡易表示型：主人公の休眠ポッド、損壊休眠ポッド、死亡者の休眠ポッドなど。
- 詳細表示型：**暫定名** `休眠者識別票` と `休眠処置同意書`。
- `休眠者識別票` は、操作権を得た直後に最初に注意を向けさせる自然な誘導対象とする。
- `休眠処置同意書` は任意調査であり、主線の進行条件にしない。

## テキスト方針

調査テキストは情報を提示すると同時に、主人公の性格を表す。通常の調査テキストは短く保ち、台詞の内容は [CHARACTER_DESIGN.md](CHARACTER_DESIGN.md) の認知・口調の規則に従う。
