# Echoes of Ruin（終末残響）プロジェクト概要

## ゲームコンセプト

『Echoes of Ruin（終末残響）』は、2D ピクセルアートの探索型謎解きアドベンチャーゲームである。現行プロトタイプでは、プレイヤーが横方向のマップを移動し、端末を調べて認証を完了し、解放されたドアの先へ進む一連の体験を実装している。

卒業論文の GitHub 編集用原稿は [THESIS.md](THESIS.md) に置く。作者用の完全な世界設定は [WORLD_BIBLE.md](WORLD_BIBLE.md)、プレイヤーへの段階的な情報開示は [STORY_REVEAL_PLAN.md](STORY_REVEAL_PLAN.md) に分離して記録する。主人公設定は [CHARACTER_DESIGN.md](CHARACTER_DESIGN.md) を参照する。

## ジャンル

- 2D Pixel Art 探索型謎解きゲーム
- Godot 4.6.2／GDScript によるプロトタイプ
- 横方向の移動とジャンプを用いる 2D アクション探索

## 開発目標

現在のリポジトリから確認できる開発目標は、探索・調査・解除・場面遷移から成る基本ゲームループを成立させることである。

- タイトルからゲームを開始できること
- プレイヤーを移動・ジャンプさせられること
- オブジェクト付近で操作ヒントを表示し、`E` キーで調べられること
- 端末認証を条件にドアを開け、次のマップへ遷移できること
- ポーズ、設定画面、タイトル復帰用 UI を提供すること

本プロジェクトは卒業制作、2026 年 7 月末の前期発表用 Demo、およびゲーム開発関連の就職活動における補足作品として制作する。対応プラットフォーム、想定プレイ時間、対象年齢、完成時のコンテンツ量は **TBD**。

## 現在の Demo 段階の目標

現行 Demo は、次の最小限の縦スライスを確認する段階にある。

1. タイトル画面で `START` を選ぶ。
2. 開始マップで左側の開始地点から移動する。
3. 右側の端末を調べて生体認証を完了する。
4. ドアが上方向に開き、ドアを調べて次の部屋へ移動する。
5. 次の部屋の戻り口から開始マップへ戻る。

この Demo では、端末使用済み・ドア解放済みなどの状態を `GameState.world_flags` に、次の部屋で使用するスポーン ID を `GameState.next_spawn_id` に保持する。これらは現在のゲーム実行中だけ有効であり、ディスクセーブではない。複数の謎、敵、収集物、セーブ／ロード、音響演出、実際の音量変更・言語切替は未実装または**要補足**である。

## 第一段階の工程整理後の位置づけ

- メインシーンは `res://scenes/core/title_screen.tscn` である。
- タイトルから開始する機能検証マップは `res://scenes/dev/prototype_room_a.tscn`、往復先は `prototype_room_b.tscn` である。
- 両方の prototype は正式な休眠施設ではなく、移動、端末、ドア、シーン遷移、状態保持、UI を回帰確認するための開発用シーンである。
- 正式な軍事休眠施設シーンは、今後 `res://scenes/areas/military_facility/` に作成する。
- Door、Terminal、Scene Exit は `res://scenes/interactions/` の再利用可能シーンとして分離されている。
