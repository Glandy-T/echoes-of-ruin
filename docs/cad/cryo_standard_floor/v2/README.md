## 共享墙与尺寸反算

单区宽 `4×21-3×0.20=83.40`，单区深 `3×9.50+2×2.40=33.30`。房间净20.60×9.10，内部纵轴2.40、横廊3.50、舱间0.70均沿用Room1 v2。

核心外包 `11.20+2×4.20=19.60`；主体宽 `83.40+19.60+83.40=186.40`，深 `33.30+19.60+33.30=86.20`；最大宽 `186.40+2×4.90=196.20`。整层几何中心 `(93.20,43.10)`，四梯对称环绕中心。

核心外的纵向机器脊柱净6、横向机器廊净4，在核心前设局部转向入口和绕行分支。完整四分区整体退让，间隙余量不定义新功能，不增大厅、护士站或其他功能房。

## 两门直入楼梯

两座双跑楼梯外包 **7.30×4.20m P**；净梯段1.80、平台1.80、中缝0.20、墙0.20。层高3.80/24级，每跑12级；级高158.33mm、踏步300mm、水平跑长11×0.30=3.30。

西侧X=-2.60至4.70，东侧镜像，与机器横廊中心Y=43.10对齐。每座南/北墙各开一道净1.80入口，上/下分区的外侧应急连接带直接进入同一个1.80宽入口平台。删除v1缓冲前室、侧向转接门和外侧前室门，只有两处楼层入口。

机器横廊止于楼梯封闭侧墙。应急跨侧路径可经过区内受控桥、中央机器核心及另一分区人员廊到对侧楼梯。日常图保持四区独立，楼梯不作公共跨区捷径。门按双扇0.90+0.90比例示意；开启机构、门扇扫掠、实际通行方向、耐火等级未定。平台净空检查包括围护墙，未将示意开启线作为实体门叶验证。

## 四货梯、回转与等待

FN/FS/FW/FE各轿厢净 **3.20×3.80m P**、井道外包 **3.60×4.20m P**；东西梯平面旋转90°，四门净2.40均朝中央。后墙与核心外围墙共享。

中央净转运区 **11.20×11.20m P**。四梯背墙前各设4m深转向入口；每个入口有两侧净2.40绕行开口。含外围转向入口的局部最大包络 **28.00×28.00m**，全部在中央结构带和横廊退让区域，不侵入房间或人员廊。

载荷按1.10×2.30舱体，整车占位1.70×3.10（每侧宽余量0.30、长度合计余量0.80）。含0.10周边余量的全姿态圆形回转包络 `sqrt(1.7²+3.1²)+0.20=3.735534m`。

先测试中央10m：通向角部等待位的保守圆形扫掠要求半宽至少 `3.6/2+3.735534=5.535534m`，10m试验半宽余量 **-0.535534m**。取11.20后余量 **+0.064466m**，在已含整车0.10周边余量的圆包络之外再留此余量，作为从8–10m初试反算增大的依据。实际车辆专门轨迹仍需设计。

四个Q等待位位于中心相对坐标(±7,±7)，各放1.70×3.10整车，不占中央净转运区。进出等待位按全姿态圆形胶囊扫掠检查；四位同时占用，主运输直线扫掠及转向圆仍无碰撞。运输假设为可平移/原位旋转机器人平台；轮距、转向机构、挂接、调度未设计。门每侧余量0.35，轿厢每侧/每端余量0.75/0.35。

分别禁用每台梯节点，并在该门洞放置关闭门障碍。每次其余三梯均从四个机器入口可达，共12条保留路径；运输扫掠不碰关闭门。未计算吞吐量或故障恢复时间。

## 编辑与来源

使用FreeCAD 1.1.4自带Python运行`build_freecad.py`，独立GUI运行`finish_in_freecad.FCMacro`追加原生尺寸，带reportlab/pypdf的Python运行`export_pdf.py`（Windows SimSun字体），`package_artifacts.py`生成清单和ZIP。FCStd不依赖自定义代理即可打开编辑。

若A404在刚载入/重算时显示暂态0值，先等待投影完成，再运行`refresh_native_dimensions.FCMacro`刷新尺寸；此宏不改设计参数、不自动保存。GUI重新打开后的8个尺寸已逐一回读一致。参数联动原生几何和A404；A401–A403为排版快照。设计参数变更先同步`layout.py`逻辑与`drawings.py`尺寸说明，再重建验证；合并墙分段不保证适应任意大幅变更。Room1参数试改仅验证联动，保存时恢复已交付v2基准。
