## 0E. 标准层最终收尾修正（3D Blockout 复核，2026-10-07）

> **本节为当前最高优先级。** 最新整层3D Blockout（提交 `b84e34c446ba42c25e23af99f0157f606beb9de2`）整体空间通过目视复核。  
> 本轮只修三个明确的几何生成问题，不再改标准层平面布局、房间位置、交通核心或疏散逻辑。修复并重新验证后，标准层阶段即可收工。

### 0E.1 修复人员电梯井下方误铺楼板

当前3D脚本把整个 `elevator_node` 矩形直接作为楼板区域生成，因此四个人员电梯井下方也被铺了楼板。

要求：

- 四个人员电梯节点中的**连接廊 / 前室保留楼板**；
- **电梯井实体范围必须从结构楼板中扣除，形成真实竖向井道洞口**；
- 轿厢自身可继续用独立的轿厢地面参照表示；
- 不改变人员电梯节点外包、轿厢净尺寸、门位或四区位置；
- 修复后从俯视和斜俯视确认四个人员井道均无误铺结构板。

### 0E.2 补齐人员走廊到西 / 东消防楼梯之间缺失的楼板

当前平面路径、墙体和防火门已连通，但3D `floor_cells` 未完整覆盖两侧人员疏散连接廊，导致西 / 东消防楼梯附近出现“有通路逻辑但局部无地面”的情况。

要求：

- 补齐西侧上下分区人员走廊 → 西消防楼梯的受保护连接廊楼板；
- 补齐东侧镜像区域；
- 楼板必须连续到楼梯入口平台，不留悬空跨步；
- 不新增房间、不改变楼梯位置、不扩大连接廊；
- 楼板范围以现有受保护疏散廊和已验证墙体边界为准。

### 0E.3 修复南侧左右电梯节点与保护廊之间的 0.20 m 墙体断缝

该缝从早期版本继承，不是入口、伸缩缝或设计功能。

已确认南侧左右对称位置存在：

- 电梯 / 前室边界墙一段结束；
- 保护廊边界墙下一段晚 **0.20 m** 才开始；
- 产生与当前 `Wall = 0.20 m` 相同宽度的无意义缺口；
- 北侧对应位置没有此问题。

要求：

- 修正南侧西、东两处墙体生成端点，使相邻墙段**连续共边**；
- 不增加门洞；
- 不把该缝解释为入口、伸缩缝、检修口或其他功能；
- 对比修复前后平面 / 3D，确认只有这两处0.20m断缝被闭合。

### 0E.4 门扇范围说明

当前Blockout只有门洞和门楣，未制作实际门扇 / 开启扫掠。

本阶段允许保持如此：
- 普通房间门、受控门、消防门可在后续美术 / 详细设计时决定为自动滑门等形式；
- 本轮**不要求**为了收尾给全部门增加开关动画或门扇实体；
- 但门洞位置和净宽继续保持现有工程基准。

### 0E.5 收尾验证与冻结

修复完成后：

1. 重新生成 / 保存修正版2D与3D源文件；
2. 检查四个人员电梯井结构楼板已正确开洞；
3. 检查西 / 东两侧疏散连接廊楼板连续；
4. 检查南侧西 / 东两个0.20m墙缝已闭合；
5. 重新跑现有墙体碰撞、门洞净空、人员走廊净空、楼梯和舱体包络验证；
6. 至少重新导出：
   - 开顶整层斜俯视；
   - 正交俯视；
   - 西或东侧电梯 / 楼梯连接局部近景；
7. 确认未改变：
   - 48室 / 960舱；
   - 四分区位置；
   - 四个人员电梯尺度与位置；
   - 四座消防楼梯尺度与位置；
   - 中央四货梯、Q等待位和机器核心；
   - 标准层主体外包和已接受疏散拓扑。

若以上全部通过，将本标准层标记为：

`STANDARD FLOOR SPATIAL BLOCKOUT ACCEPTED / FROZEN FOR NEXT BUILDING STAGE`

之后不再继续微调本层工程布局，除非在整栋楼堆叠、结构或游戏相机验证阶段发现新的明确冲突。

## 0C. v3 最终空间纠正：整体上下收拢，不做四角房间单独错台（2026-10-07）

> **本节优先级最高，覆盖下方 0B 中“四角房间单独错台”的要求。**
> 当前要解决的核心问题只是：v2 中央横向机器通道上下存在过大的无功能空白，看起来不像有意设计。

### 0C.1 上下半部整体移动

以 v2 的四个完整分区为基准：

- **NW + NE 上半部整体向下平移**；
- **SW + SE 下半部整体向上平移**；
- 四个分区内部的 3×4 房间、2.4 m 人员走廊、人员电梯节点均随各自分区整体移动；
- 不拆散房间网格，不单独移动 NW-04 / NE-01 / SW-12 / SE-09；
- 不改变 Room 1 的 21.0 × 9.5 m 模块；
- 不改变每区 12 室、整层 48 室。

移动量由 FreeCAD 实尺测试决定，目标是尽量吃掉横向机器通道上下两侧明显过量的空白，但必须保持：
- 中央四货梯核心工作包络；
- Q 等待位；
- 机器人回转 / 等待空间；
- 必要防火分隔；
- 横向机器通道本身合理连续。

### 0C.2 左右方向暂不压缩

- 四个分区的左右位置先保持 v2 关系。
- 不要求 NW / SW 向右推，也不要求 NE / SE 向左推。
- 原因是左右方向会直接受到 Q 等待位、货梯与机器人回转包络限制。
- 不为了消灭所有空白而强行挤压中央纵向方向。

### 0C.3 剩余左右空白的定义

如果上下收拢后，中央核心左右仍有不能消除的空间：

- 这些空间统一归入**连续的中央机器物流 / 作业区**；
- 不再标成“未定义空白”；
- 不单独切成无用途的小房间；
- 不把 4 m / 6 m 通道画成突然扩宽又收窄的怪异喇叭口；
- 图面上应让中央物流核心及其周边作业区读成一整块连续、明确的机器空间。

### 0C.4 保留的 v3 内容

以下 v3 修改继续有效：

- 四个人员电梯维持一区一梯；
- 左右两座消防楼梯保留；
- 新增北 / 南两座中央消防楼梯；
- 纵向机器通道北半段 / 南半段可在紧急状态作为受控人员疏散段；
- 中央四货梯核心始终禁止人员穿越；
- 紧急时人员只可沿纵向通道向北 / 南楼梯方向疏散；
- 中央四货梯 + Q 等待位 + 机器人物流核心继续保留。

### 0C.5 下一版验证要求

下一版应从 **v2 主体排布**重新生成，并报告：

1. 上半部整体下移距离；
2. 下半部整体上移距离；
3. 横向机器通道上下原空白减少了多少；
4. 是否与 Q、四货梯、机器人回转包络发生冲突；

6. 左右剩余机器作业区的实际净尺寸；

图纸目标不是追求每一平方米都被填满，而是让剩余空间看起来具有明确机器作业用途，不再像 v2 那样出现明显“多出来的一大片”。

## 0B. v3 输出纠正：回到 v2 主体，只做中央四角房间局部错台（2026-10-07）

> **本节优先级高于下方 0A。当前已生成的 v3 平面不接受其房间重排方式。**

- **以标准层 v2 的四分区和48间房整体排布作为基准恢复。**

### 0B.2 真正需要处理的是中央核心四个角

只优先处理下列四个最靠中央核心的房间：

- NE-01

但该方向会接近 / 侵入 Q等待位、机器人回转和四货梯核心工作包络，因此：

- **第一版先只做上述上下方向局部移动。**

下方“删除中央机器通道周边无功能空白带”不得再解释为：

### 0B.6 下一版验证

下一版必须对比 v2 / 当前错误v3 / 修正版，并至少报告：

## 0A. v3 修正要求（基于标准层 v2 审阅，2026-10-07）

> **本节优先级最高。** 与下方 v2 修正或旧章节冲突时，以本节为准。  
> v2 的 48 室、四分区、Room 1、左右两座消防楼梯、中央四货梯核心均保留；本轮修正人员电梯假设、中央机器通道周边的无功能空白带，以及应急疏散网络。

### 0A.1 四个人员电梯：一区一梯作为当前设计假设接受

- 四个分区仍各使用 **1 台人员电梯**，左上 / 左下 / 右上 / 右下各一组，位置与 v2 保持。
- 当前轿厢净尺寸约 **2.10 × 2.40 m P**、井道外包约 **2.50 × 2.80 m P** 可继续使用。
- 本项目允许采用未来高速、高可靠、智能调度电梯作为世界观前提；参与者又按楼层与时间窗分批进入，因此本轮**不因“每区只有一台”而增加电梯数量或放大轿厢**。
- 以后整栋楼阶段如需验证峰值吞吐，再单独计算；本轮不要把人员电梯运力列为阻止标准层推进的未解决问题。

### 0A.2 删除中央机器通道周边的无功能空白带

v2 为了让中央 19.60 m 物流核心形成规整十字，把核心所需的结构带尺寸沿整条横向 / 纵向方向拉满，导致中央通道与休眠分区之间出现了没有任何功能定义的空白带。本轮必须取消这种处理。

要求：
