全部48室均显示20舱，共960舱。SW-06/SE-06/NW-06/NE-06四个代表室完整复用已验证Room1 blockout的80实体闭舱模板（每舱Base/Body/Lid/Window）；其余44室使用同一来源的20个精确舱外包盒。没有用空房代替其余房间，也没有缩舱或改门位。所有模板内嵌在当前FCStd内，以App::Link复用；独立打开CAD不依赖外部链接文件。

原生清晰分组：楼板、墙/门楣、48隐藏房间外包、人员/机器地面、四梯、轿厢净空地面、48舱体实例、模板、尺度柱、可隐藏主区顶板、应急核心隔断。墙坐标从已验证二维墙并集精确转成三维，真实门洞和绕行开口保留，门楣从2.40m以上开始。门扇本身与扫掠未制作。

四梯每跑11个踏步面加平台最后一级，共24级。两跑真实3.30m、净宽1.80m，半层平台+1.90m，上平台+3.80m。楼梯井向上延续，不把+3.80m上平台封成屋顶；本模型在一个楼层范围截断，上层结构未建。扶手、楼梯结构和法定净高仍待详细设计。

北梯Y74.70..82.00，南梯Y4.20..11.50，完全在主体内；西东两梯原位。人员楼梯入口逻辑和中央核心人员禁入规则沿用二维基准。应急全宽核心隔断默认隐藏表示常态开放，可按组显示用于查看边界；实际门控/消防构造仍是后续任务。

## 实际核验与修改

最终保存文件重开：731个原生对象、48个内部模板实例；所有有效Shape通过，墙XY最大误差小于0.0001mm。94个门洞/绕行开口的实际3D净宽与2.40m净高棱柱无结构交叠，8条人员廊全净高无结构交叠；全部48个舱体集合都在所属房间净界内，4完整模板各80实体、44简化模板各20实体，总960舱。88个踏步面均在本梯井内，四个半层/上层平台按原模块建出。

3D文件独立打开即可测量与修改原生Part::Box尺寸、体块摆放和App::Link实例。XY是冻结的接受布局，不建议通过随意挪体块改变工程基准；更改布局需先更新v3_inset并重新生成。高度/门楣/楼梯踏步部分原生表达式联动；顶板布尔几何与冻结XY须重跑脚本，不能把本版当完整参数化BIM。

复现需在项目目录中使用便携FreeCAD `bin/python.exe build_blockout.py`，输入`../v3_inset/floor_layout.json`和已验证`../../cryo_room1/blockout_v2/room1_3d_blockout_v2.FCStd`；专用GUI进程运行`render_blockout.FCMacro`；`validate_blockout.py`读回；`make_gallery.py`生成图册；`package_blockout.py`打包。普通Python负责图册和打包（Pillow），无需插件。打开最终CAD不需要这些源码依赖。

尚未验证疏散容量/时间、消防等级/联锁、实际门扇扫掠、楼梯结构净高/扶手或真实机器人运动。单层Blockout不能代表整栋疏散或最终游戏可读性通过；后续可在此模型上测试相机及低角度游戏视角。
