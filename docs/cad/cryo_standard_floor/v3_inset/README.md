# 标准层 v3 inset / 0D 北南楼梯完全内嵌

依据提交`16898b0561e0ac3a96697ff501a4ba26380221ec`，简报0D最高优先级。接受的v3_final平面（17cd63c）保持；旧版本目录和原文件均保留原字节。本版只修正北/南两座楼梯的位置，并为整层3D Blockout提供基准。

## 仅两座楼梯移动

北梯整体向南2.60m：Y77.30..84.60→74.70..82.00；南梯整体向北2.60m：Y1.60..8.90→4.20..11.50。X均91.10..95.30，外包4.20×7.30m。两梯完全位于主体Y4.20..82.00内；不扩大主体。

西/东楼梯原位，仍外包7.30×4.20m、内嵌4.70/外伸2.60m。四梯使用同一U形模块：净梯段和平台1.80m、24级/每跑12级、踏步300mm、级高158.33mm（层高3.80m暂定）；西东各2门、北南各1门净1.80m直入，无新增前室。

对比接受版逐个核对48室、8条人员廊、4人员梯节点、4货梯、4Q、4转弯预留区及所有连续机器作业区，坐标完全相同。Room1仍21×9.50m，四区完整3×4，人员净廊2.40m，容量48室/960舱，上下半区先前4.20m收拢保持；本轮不重新解释或调整中央空白。

主体186.40×77.80m；含外侧人员节点最大196.20×77.80m（深度从修正前最大83.00减5.20m）。核心19.60×19.60、净转运11.20×11.20、左右连续作业区各78.70×11.20、纵段车道6m及侧带各6.80保持。

## 路线与实体

所有48条北/南楼梯候选路线各缩短2.60m；48条西/东候选路线完全相同。每室仍有本侧与本半层北/南两个方向；最远中心→最近楼梯仍66.95m，舱侧保守77.70m，因为SW-02/SE-03/NW-10/NE-11仍选择未移动的西东梯。不能把新增楼梯路线缩短量直接从全层最大值减去。

日常只走本区外侧人员梯；紧急纵段停机、内端门开启、人员只向外楼梯；中央核心及全部转弯预留区始终对人员禁入，南北全宽19.60m应急隔断保持。

FreeCAD实尺：355全约束有效草图、244有效墙填充；全部净门洞、48房净区、8平台、192条0.45m胶囊路径、38条机器轴向扫掠、回转和Q满位/单货梯关门故障检查通过。原生投影10项尺寸及参数试改/恢复、保存后重开读回均通过。`qa/inset_validation.json`列出两梯前后坐标和96条路线逐条比较。0C收拢候选报告从已接受版保留，不作为本轮新设计讨论。

## 文件与复现

- `standard_floor_v3_inset.FCStd`：原生可编辑2D；A401-A403排版快照，A404原生实时投影及10项真顶点尺寸。
- `exports/standard_floor_v3_inset.pdf`：3页A2；A401总平面1:500、A402完整典型SW分区1:200、A403楼梯与核心局部1:100。
- `exports/A404_native_live.pdf`、`qa/`：FreeCAD直接出图和验证证据。
- [完整整层3D Blockout](../blockout_v3/README.md)：北南内嵌验证通过后直接推进，另有原生CAD及10视角。
- `artifact_manifest.json`、`standard_floor_v3_inset_delivery.zip`：完整清单与逐文件SHA256。

使用便携FreeCAD `bin/python.exe build_freecad.py`；专用GUI进程运行`finish_in_freecad.FCMacro`；`refresh_publication.py`/`export_pdf.py`重新生成排版；`reopen_in_freecad.FCMacro`刷新原生投影与快照；最后`check_inset.py`、`verify_saved.py`核验，`package_artifacts.py`打包。

大幅改变参数导致墙并集分格拓扑变化时需重建，A401-A403文字不是实时参数联动。`refresh_native_dimensions.FCMacro`提供手动刷新A404。来源简报Git blob `29870c510e912c6af29e9066b2d8309515876c39`。

当前是几何/路径验证及灰模空间验证。960人疏散容量/时间、消防构造/联锁、门扇扫掠、机器人实际转向/调度仍未详细验证；一区一台人员梯的本阶段设定按已接受假设继续。
