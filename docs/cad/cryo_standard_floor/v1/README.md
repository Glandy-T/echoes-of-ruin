# 标准休眠层 v1 — 二维工程验证

依据 GitHub `71ba4633094de972cbd229a2e890946e740f04ab` 的 `STANDARD_FLOOR_ENGINEERING_BRIEF.md` 绘制。采用已交付 Room1 v2 模块，不改动其原文件。本轮没有正式三维、立面、材质或楼层堆叠。

**结果：二维门洞、净空与动线拓扑验证通过；疏散设计仍未定案。** 最远房间中心到最近楼梯入口平台的水平中心线路径为 **106.95 m**，舱侧操作位保守路径约 **117.70 m**。该距离偏长，下一轮需要专门解决。960人疏散容量、时间、消防要求、无障碍、运输机构均未验证，不能将本版当作施工或疏散批准图。

## 门位与动线

坐标原点为主体左下外角，+X向右、+Y向上。四区 SW、SE、NW、NE；每区自下往上3排、每排自左往右4室编号01–12。南侧区Y原点0，北侧区Y原点37.30；西侧区X原点0，东侧区X原点93.60。

- 外排只朝邻近人员走廊开门；中排朝两条人员廊各开门。门中心都在房间长边中央，与室内2.40纵轴对齐。房间内部不重新设计。
- 蓝线为日常人员流线：四区各自独立，两条走廊通过2.40外侧封闭前室到本区电梯，不经过其他休眠室或机器廊。
- 橙虚线为应急人员流线：外侧连接带的延伸段、受控门和楼梯前室；内侧受控门及必要机器通道也作为备用连接。平时不跨区开放。
- 灰虚线为机器流线：6m纵向脊柱、4m横廊与独立货梯。东侧人员廊的内端穿过服务带的2.40净应急桥也只在紧急状态使用。
- 楼梯与四个电梯节点分开；没有额外大厅、护士站或新的公共功能。货梯服务带未使用部分只是占位预留，不定义新房间用途。

路径算法禁止把其他房间作为中转节点；中排双门不会导致穿房捷径。48室都能到本区电梯，不能通过日常图去其他区电梯；应急图中48室均能到两座楼梯。路径长度从房间中心量到楼梯入口平台，**不包括竖向下楼**。117.70m为106.95加室内2.90+7.85的保守接近路线，沿既有Room1横廊离开，不直接穿过舱体。

FreeCAD/OpenCASCADE回读：248个有效墙单元之间正体积碰撞0；48室净内区无墙侵入；98处全部门洞有效；143段动线按0.45m宽中心线矩形探针检查无墙侵入；两处货运旋转圆与两段整车扫掠外包均无墙体碰撞。0.45m只作静态比例探针，不证明全员通过能力或动态转身。

所有322个原生草图全约束；A404回读最大宽196400、主体宽177000、深70600、机器纵6000/横4000、人员廊2400、梯段1800 mm。RoomWidth、MachineSpine、RoomDoor编辑试验逐个回读所有墙单元坐标并与重新生成布局比较，恢复基准后保存；StoreyHeight修改时级高联动。

A401–A403为同一几何数据排版的SVG快照；出版PDF嵌入中文字体，三页已实际渲染检查，无图框外文字，文字和图形色彩一致。A404是实时原生投影。改变参数后，不要将旧排版页当成新参数结果。

## 重现和编辑

基准方案重建：使用本地FreeCAD 1.1.4自带的 `bin/python.exe build_freecad.py`；在FreeCAD GUI运行 `finish_in_freecad.FCMacro` 追加原生尺寸、回读和导出。使用带reportlab/pypdf的Python运行 `export_pdf.py` 生成出版PDF，字体为Windows SimSun。`package_artifacts.py` 生成明确文件清单和SHA256。

FCStd采用原生参数、草图、挤出和TechDraw对象，无自定义代理，重新打开不依赖本项目Python模块。参数可以在Parameters属性中查看和试改；任意拓扑变更须先修改 `layout.py` 输入/逻辑、同步 `drawings.py` 的尺寸说明，再重建并重新验证。合并共享墙的分段拓扑和出版尺寸文字不会自动适应任意大幅设计变化。Room1尺度仍按已锁定v2使用，参数试改仅为联动测试。
