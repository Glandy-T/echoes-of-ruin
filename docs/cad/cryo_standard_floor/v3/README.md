## 四向应急网络

正常：四区人员各到本区外侧电梯；受控人员门关闭。机器在6/4通道、局部转向入口及四货梯核心正常运行。

紧急：八个内端受控门开启；北/南纵向区段机器人停运；核心前两处净6m机器开口的人员隔断关闭。进入北半段的人员只能向北梯，进入南半段的人员只能向南梯。隔断工程形式、耐火与控制联锁待细化，图中不能将常态机器开口误读为永远关闭的实体墙。

路径图为有向图：人员入纵向段的门单向入，纵向段的应急边只向外；机器网络在人员最短路计算中排除。楼梯作为终点，不允许借一个楼梯间绕到另一分区当捷径。每个房间均有本侧西/东梯、对应北/南梯两种明显不同的水平逃生方向；48室的最近梯计算考虑四座梯，不能到达的另外两座记录为不可达而非穿核心强接。

最远SW-11（其镜像同值）中心路线：`SW-11 → SW_C1_2 → SW_C1_1 → SW_C1_0 → SW_C1_Outer → SW_StairApproach → SW_StairLandingCorner → West_StairLanding`，72.25m，完全不穿核心。所有48室的两种路线、选定最近梯与节点见JSON；最远编号集合另存`worst_room_ids`。

舱侧保守路线在中心路线基础上增加沿既有Room1横廊/纵轴的2.90+7.85=10.75m，得83.00m。该量是保守上界，既不含下楼也不声称每个室内操作位恰有同样距离。两项相较v2均减少40.50m，中心最大值改善35.92%。**只验证水平连通与静态净空；疏散容量、时间、防火分隔及无障碍仍未定案。**
