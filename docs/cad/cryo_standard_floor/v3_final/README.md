## 最大收拢量的实尺证据

`measure_compression.py` 用 FreeCAD/OCC 检查0、2、4、4.2、4.3、4.4、4.5m候选的48间完整模块与原位核心/转弯预留区相交。

4.20m恰好将下区北外墙面接到Y37.50、上区南外墙面接到Y48.70。继续到4.30m，四个最靠核心房间的完整外包开始侵入东西4m转弯预留区。所选方案保留整个预留区，而不是仅看单条中心线能否通过。Q车体至房间外包最小净距1.95m，含0.10m安全余量的回转圆至房间外包最小净距0.332233m。等待位满位及动态进入扫掠另有实体测试。

## 路径、防火边界与几何验证

日常人员只连接本区外侧人员电梯，不能借中央核心跨区。应急允许从人员廊内端受控门进入对应北/南机器臂，路径有向地只向外到北/南楼梯；西/东保护通道直达同侧楼梯。算法禁止把其他休眠室或另一座楼梯当穿越捷径。

应急时整个对应机器臂停运，核心南北两条19.60m全宽隔离边界关闭，人员内端应急门打开。边界覆盖整个纵向机器空间，不能从6m车道旁边的作业带绕入核心；火灾控制设施的构造及联锁为后续详细设计，不以图上的细线代替已完成的消防系统。

楼梯为同一U形模块：井道7.30×4.20m（北/南旋转），梯段与平台净1.80m，24级、单跑12级、踏步300mm、层高3.80m暂定、级高158.33mm，内嵌4.70m/外伸2.60m。四个人员电梯保持净轿厢2.10×2.40m；一期一区一梯假设接受。

实测结果：363个全约束有效草图、252个有效二维墙填充；48房净区、8楼梯平台、所有96个净开口通过，墙体无正体积互撞。192条0.45m胶囊路径，38条机器轴向扫掠、31个回转圆、8条整回转圆等待扫掠通过。Q四位满载仍可通行；四种单货梯关门故障各剩12条运输路线通过。人员边全程与核心/预留区及闭合隔断无交叠。

## 修改和复现

使用本地便携版FreeCAD的`bin/python.exe build_freecad.py`生成原生几何及A401–A403 SVG/数据；运行`measure_compression.py`生成平移测试；在专用FreeCAD进程运行`finish_in_freecad.FCMacro`建立10个投影尺寸并试改/恢复参数。RoomWidth21.2m、TransferClear11.25m、FreightDoor2.6m试改后逐墙读回正确，层高4m试改后级高正确；最终参数均恢复。

`refresh_publication.py`与`export_pdf.py`用当前JSON生成排版；PDF用ReportLab和SimSun，字体嵌入。修改尺寸后应重新生成JSON与排版；A401–A403是快照，不随FreeCAD实时参数自动改字。`reopen_in_freecad.FCMacro`重开文件后刷新投影缓存、更新快照并验证全部尺寸。`refresh_native_dimensions.FCMacro`提供用户手动刷新A404。`verify_saved.py`在最后保存后读回文件及旧版本哈希；`package_artifacts.py`只打包显式文件。

墙体按正交并集分格；大幅参数编辑改变分格拓扑时须重新运行生成脚本，不能只依赖已有分格表达式。Compression由FreightOuterDepth推导为保留完整核心工作预留区的收拢极限，不用于任意穿插房间。
