v3保留48室/960舱、四人员电梯、左右楼梯和中央四货梯，新增北/南楼梯，采用12个内列房间局部向外错台及真实净2.4m连接廊。普通机器通道直接贴邻房间边界，中央19.6m核心只在节点局部膨大；浅灰为建筑轮廓外的室外凹口。

主体阶梯轮廓包络178.00×94.20m，含外置节点187.80×99.40m；不是一整块包络矩形楼板。最远中心路径72.25m、舱侧保守83.00m，较v2分别缩短40.50m；48室均有外端/内端两种明显不同的疏散方向。北段只能向北、南段只能向南，紧急时本段停机、核心人员隔断关闭，人员路径不穿中央货梯核心。

**一区一台人员电梯的世界观与分批进入假设已接受，不阻止本轮推进。** 当前仅二维拓扑和静态净空核验通过，疏散容量/时间、防火门实际开启和消防细节仍需设计。未开始正式3D或整栋堆叠。
