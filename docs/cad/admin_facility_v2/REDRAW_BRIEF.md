# 管理设施 A201 重绘任务：建筑方案平面图

> 本文件用于下一轮 FreeCAD / Codex 重绘。当前 `A201_v2` 的问题不是参数记录错误，而是**图纸表达方向错误**：它更像关系验证报告，不像建筑平面图。
>
> 本轮优先级：**先让人一眼看懂空间，再谈审查报告。**

## 1. 本轮目标

重做 `A201` 为一张清晰的**概念工程 / 建筑方案平面图**。

目标观感介于：

- 清晰易读的建筑方案平面图；
- 简化后的 CAD 建筑平面图。

**不是施工图，也不是参数验证报告。**

打开图纸后，应当无需先读大量说明文字，就能直接回答：

- 建筑外轮廓在哪里；
- A～J 十个入口在哪里；
- 自动认证区在哪里；
- 共享汇流大厅在哪里；
- 工作人员 / 异常处理区在哪里；
- 工作人员内部厕所在哪里；
- A～J 十个监控 / 日志工位在哪里；
- 左右公共厕所在哪里；
- 两处主要地图 / 导视在哪里；
- 三个后出口在哪里；
- 人员大致如何从前侧进入、通过认证、看导视分流、再从后侧进入园区。

## 2. 必须直接画成建筑几何的内容

不要再把主要功能画成漂浮的虚线框、箭头或单独关系符号。

主图中至少直接表现：

1. 管理设施单层外轮廓；当前 65 m × 45 m 仍作为验证基准，不代表最终锁定外包。
2. 有厚度感的外墙 / 主要内部隔墙表达。墙厚尚未确认时允许使用**设计阶段暂定值**，但必须标为 `PROVISIONAL`，不能假装是最终施工值。
3. 正面 A～J 十个入口组，按草图逻辑连续布置。
4. 每个入口后的自动认证 / 闸机区域，用实际平面占位表达，而不是只写 A～J 标签和箭头。
5. 认证后的共享汇流大厅。
6. 中央工作人员 / 异常处理区；当前概念边界约 18 m × 12 m。
7. 工作人员内部厕所改为设置在**工作人员区后侧 / 上方靠墙居中**，入口朝工作人员区内部；不要放在工作区几何正中心。
8. 原二楼的 **A～J 十个监控 / 日志工位全部并入一楼工作人员区**。当前按两排五个布置进行空间验证；每个工位继续对应一栋休眠楼。
9. 共享大厅左、右两侧各一个公共厕所；中央不设公共厕所。
10. 两处园区地图 / 电子导视改为放在**工作人员区与左右公共厕所之间的纵向分流通道**，面向从认证区进入大厅的人群。人群应自然先看到地图，再向左 / 中 / 右分流。不要再把地图贴在建筑左右外墙。
11. 后侧三个公共出口，用真正门洞 / 开口表达，不是关系符号。

## 3. 当前空间验证要求

### 工作人员区

当前 18 m × 12 m 工作人员区需要同时容纳：

- 十个 A～J 监控 / 日志工位；
- 工作人员 / 异常处理基本办公功能；
- 后侧靠墙居中的工作人员厕所；
- 连续的内部通行空间。

十个工位当前采用**两排五个**，不要恢复原二楼 2–3–3–2 四排阵列。桌面可继续以约 **1.8 m × 0.8 m** 作为验证值；必须检查椅后退让、排间通道、厕所入口通路是否真实可用。

若现有 18 m × 12 m 可以合理容纳，则不要为了“更宽松”随意扩大；若出现真实冲突，则报告冲突与最小修正。

### 地图 / 导视

地图不是装饰墙面，而是**分流节点**。

- 左地图位于工作人员区与左公共厕所之间的纵向通道；
- 右地图位于工作人员区与右公共厕所之间的纵向通道；
- 两块地图均面向从前侧认证区进入大厅的人群；
- 不得阻塞纵向通行净宽；
- 图面应能看出“认证 → 看到地图 → 左 / 中 / 右分流 → 三后出口”的逻辑。

## 4. 允许使用设计阶段暂定值

过去“所有未确认尺寸都只写 TBD、不落位”的做法导致主图失去建筑意义。

本轮允许为了空间验证使用 `PROVISIONAL / 暂定` 参数，例如：

- 墙厚；
- 厕所初始占地；
- 门洞宽度；
- 闸机组占地；
- 工作人员区在建筑内的精确 XY；
- 十个工位的精确间距；
- 地图的具体宽度 / 厚度 / 精确位置；
- 公共厕所相对位置；
- 认证区进深。

但必须遵守：

- 已确认值与暂定值分开标识；
- 暂定值必须能在参数表中单独修改；
- 如真实尺度验证发现冲突，报告问题与最小修正，不要偷偷改掉已确认设计意图；
- 不得因为采用暂定值就升级成施工级细化。

## 5. 图纸表达规范

A201 主图以**空间可读性**为第一优先级。

### 线条层级

- 建筑外墙 / 主要切割墙：最粗；
- 内部隔墙：中等；
- 门、设备、闸机、洁具、工位占位：较细；
- 人流方向：最淡 / 最细，可用少量箭头；
- 不要用大量相同粗细的线让图面失去层级。

### 标注

- 功能名称直接放在对应空间内部；
- A～J 入口和 A～J 工位直接标注；
- 标出主要总体尺寸、主要分区尺寸与必要通道宽度；
- 尺寸链优先放在建筑外围；
- 不要在主图上堆满说明段落。

### 门与厕所

- 门应采用建筑平面图常见的门洞 / 门扇表达，必要时表现开启方向；
- 公共厕所和工作人员厕所应在平面内成为真实空间，而不是 `NTS` 漂浮框；
- 洁具可以采用极简占位符，仅用于判断厕所是否具有基本可用尺度，不要求施工级卫浴设计；
- 左右公共厕所至少考虑一个无障碍 / 通用卫生间位置，但具体配置仍可标为暂定。

### 图框与文字

- 保留简洁图名、图号、比例、版本和少量备注即可；
- `TBD / PROVISIONAL` 集中说明控制在一个小框内；
- 不要让参数说明、GitHub commit、公式、吞吐条件占据主图大面积。

## 6. A202 / A203 的定位

- `A201`：真正的管理设施单层建筑方案平面图，必须成为主要阅读页。
- `A202`：如有需要，可做工作人员区局部放大，重点检查十工位 + 后侧厕所 + 内部通行；也可补充入口认证局部，不要重复关系示意。
- `A203`：可继续保留面积复核、吞吐输入、TBD 清单等审查内容，但它是**辅助审查页**，不是主平面图。

## 7. 不要做的事情

- 不要继续把建筑主体画成一个空的 65×45 m 矩形，再靠文字解释内部功能。
- 不要把厕所、入口、出口画成漂浮的 NTS 框。
- 不要把工作人员厕所放回工作区几何正中心。
- 不要把地图贴回左右外墙。
- 不要恢复原二楼 2–3–3–2 工位阵列；一楼当前验证方案是两排五个。
- 不要因为参数尚未最终确认就拒绝落位。
- 不要堆满轴网、结构详图、机电、消防施工符号；当前不是施工图阶段。
- 不要自行恢复 2F、楼梯或升降台。
- 不要重新发明管理设施功能关系。

## 8. 完成标准

导出后先只看 A201，不看说明文字，应能在 5～10 秒内识别：

`十入口 → 认证 → 共享大厅 → 两侧地图 / 导视 → 左 / 中 / 右分流 → 三后出口`

同时应能直接看出：

`工作人员区 = 十个 A～J 工位 + 后侧靠墙内部厕所 + 异常处理功能`

如果仅凭图形仍然无法看懂上述空间关系，则本轮仍不合格。
