# 管理设施最终封盘修正：地图放大 + 2D / 3D 一次更新

> 基准：当前 `v2-FINAL` 平面与最新 3D blockout。  
> 本文件是管理设施本阶段最后一次修改说明。**只允许修改两块园区地图 / 导视板的尺度；其他空间、尺寸、位置、家具、流线和功能全部冻结。**

## 1. 唯一修改项：两块地图板放大

当前两块地图在 3D 人视角中视觉尺度过小，更像需要走近阅读的小型导览牌，不符合本方案“认证后远距离一眼识别、自然完成左 / 中 / 右分流”的目的。

因此：

- 两块地图继续保持当前**左右纵向分流通道中的位置**；
- 继续**面向从认证区进入大厅的人群**；
- 不改变通道、工作人员区、公共厕所或出口的位置；
- 平面参数中的地图正面宽度由当前约 **2.0 m** 放大到 **4.0 m**；
- 3D 中地图有效可视面建议约 **4.0 m 宽 × 2.0～2.2 m 高**；
- 保持薄型信息板 / 导视墙语言，不把它做成房间或厚重设备；
- 可保持当前安装方式，只需保证从认证后的人眼视角能够明显识别为主要园区总图；
- 放大后重新检查通行净宽，但**不得为了地图而移动其他已冻结空间**。现有通道余量充足，预期应可直接容纳。

目标不是增加信息细节，而是提高**远距离可见性与分流识别性**。

## 2. 2D 与 3D 必须同步更新

本次不要只改单独一个模型文件。一次性完成：

### 2D

- 更新 `plan_layout.py` 中对应地图尺寸参数；
- 重建 / 更新 `admin_facility_v2.FCStd`；
- 更新 A201–A203（以及项目当前实际维护的相关平面 / TechDraw 页面）；
- 重新导出 SVG / PDF；
- 更新几何验证数据，确认放大后的地图不阻塞左右纵向通道。

### 3D

- 从更新后的同一套平面参数重新生成 3D blockout；
- 不手工另做与 2D 参数脱节的地图；
- 两块地图 3D 尺度按本文件第 1 节执行；
- 重新输出 `evidence/visual_blockout/` 中受影响的视角，至少包括：
  - `02_after_auth_human_view`；
  - `06_overall_birdseye`；
  - 如现有其他截图中地图明显可见，也一并重出。

## 3. 冻结项：禁止顺手修改

以下全部保持最新版本，不再调整：

- 65 × 45 m 建筑外包基准；
- 20 × 14 m 工作人员区；
- 十个 A–J 工位及两排五个布局；
- 工作人员卫生间及两隔间 + 两洗手位；
- 左右公共厕所及不分男女、两排全封闭隔间方案；
- A～J 十入口与认证闸机；
- 三个后出口；
- 工作人员区、厕所、地图的现有 XY 关系；
- 墙高 / 当前 3D blockout 高度；
- 其他门洞、墙体、设备、桌椅、厕所隔间尺寸；
- 不增加柜子、屏幕墙、会议区、装饰物或新的功能房间。

如果更新地图后没有出现真实几何冲突，不再提出新的“优化”修改。

## 4. 完成条件

完成后确认：

1. 2D 与 3D 使用同一套地图尺寸参数；
2. 两块地图均约 4 m 宽，并在 3D 中具有约 2.0～2.2 m 的有效可视高度；
3. `02_after_auth_human_view` 中无需走到地图前即可明显看到两块导视；
4. 左右纵向通道仍保持宽松，不产生拥堵或碰撞；
5. 其余冻结项没有发生变化；
6. 平面图、FreeCAD 文件、3D blockout、验证数据和相关截图全部重新提交。

满足以上条件后，将管理设施标记为：

`ADMIN FACILITY SPATIAL DESIGN FROZEN`
