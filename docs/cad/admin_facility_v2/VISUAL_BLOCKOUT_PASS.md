# 管理设施 v2-FINAL：3D 实际空间效果验证

> 本任务从当前 `v2-FINAL` 管理设施平面方案继续。当前平面与主要空间关系本阶段视为已完成；本轮目标不是继续改平面，而是把已确认/暂定的平面几何真正立起来，验证人在空间中的尺度感、视线与分流体验。
>
> 基准提交：`4bed2280537ade3218349df315408dc799b5bda5`。

## 1. 本轮目标

在 FreeCAD 中基于现有参数化平面直接生成一个**真实尺度、低细节的 3D architectural blockout**，并输出若干视角截图。

重点回答：

- 从 A～J 入口进入时，空间是否显得过空或过压迫；
- 通过认证后，能否自然看到两侧地图并理解左 / 中 / 右分流；
- 20 × 14 m 工作人员区与十个工位在实际高度下是否合理；
- 工作人员内部卫生间、左右公共厕所的空间感是否正常；
- 三个后出口从大厅内部是否容易识别；
- 5.5～6 m 级层高在这个 65 × 45 m 大厅中是否合适。

这不是游戏最终美术，也不是施工深化。

## 2. 必须继承当前平面，不得重新设计

直接从当前 `plan_layout.py` / `.FCStd` 的同一套参数与平面几何生成 3D，不要手工另画一套不受参数驱动的模型。

保持：

- 65 × 45 m 当前建筑外包基准；
- 正面 A～J 十入口与认证区；
- 中央共享大厅；
- 工作人员区当前 20 × 14 m PROVISIONAL 边界；
- 十个 A～J 工位，两排五个；
- 工作人员卫生间在工作区后侧靠墙居中；
- 工作人员卫生间当前两独立隔间 + 两洗手位；
- 左右两个不分男女的公共卫生节点；
- 公共卫生间两排全封闭隔间，并保留较大通用隔间；
- 两块地图位于工作人员区与左右公共厕所之间的纵向分流通道，朝向从认证区进入的人群；
- 后侧三个大出口；
- 不恢复 2F、楼梯、升降台或旧主屏。

如 3D 建模暴露真实碰撞或无法使用的空间，只报告问题，不在本轮擅自改平面。

## 3. 3D 建模深度

只做能够判断尺度和视线的简化体块。

### 建筑

- 地面 / 楼板：简单平面或薄板；
- 外墙、主要隔墙：从当前平面墙体真实拉高；
- 建筑总净高/墙高先以 **约 5.8 m PROVISIONAL** 做视觉测试，仍处于既定 5.5～6 m 范围内；
- 门洞、后出口、入口开口必须真实留空，不能用实墙再贴门符号；
- 顶部可制作简单可隐藏屋面，但默认截图时应根据视角隐藏屋面，方便检查内部空间。

### 入口与认证

- A～J 入口滑门/门扇只需简单板件；
- 闸机、挡栏按现有平面占位拉成约腰高设备体块；
- 不做机械细节、屏幕 UI 或品牌装饰。

### 工作人员区

- 十张工作桌、椅子、每工位双屏用极简体块表现；
- 卫生间两隔间、两坐便器占位、两洗手位需要立起来；
- 不增加当前方案没有的会议室、柜子、沙发等家具。

### 公共厕所

- 隔间必须是接近真实高度的全封闭私密小室，不使用现代公共厕所半高隔板的视觉语言；
- 两排隔间和较大的通用隔间都直接按当前平面立体化；
- 洗手区域只做简化台盆体块；
- 不增加小便池，不按男女分区。

### 地图 / 导视

- 两块地图做成朝向来人的立式或墙式信息面板体块；
- 高度与安装方式使用合理 PROVISIONAL 值即可；
- 重点验证进入大厅时是否能直接进入视线，而不是设计 UI 内容。

## 4. 视觉表达

本轮只需要**中性建筑模型效果**：

- 墙体、地面、设备使用简单白 / 灰 / 深灰层级即可；
- 可用非常轻微的功能色区分闸机、地图、工位，但不要发展成正式美术方案；
- 不做锈蚀、废墟、绿化、灯光叙事、贴图、材质细节；
- 不要把它做成赛博朋克室内设计。

如果 FreeCAD 视图允许，可加入 1～2 个约 1.7 m 高的纯尺度参考人形/柱体，仅用于判断建筑尺度；不要把它当主角模型。

## 5. 必须输出的视角

至少输出以下 6 张 PNG（或同等可快速查看的图片）：

1. `01_front_entry_oblique`：建筑正面斜视，能看到 A～J 十入口与整体宽度；
2. `02_after_auth_human_view`：约 1.6 m 眼高，从认证区后方看向大厅，检查地图是否进入视线；
3. `03_hall_to_rear_exits`：大厅中央看向后侧三出口；
4. `04_staff_area_oblique`：工作人员区斜俯视，能看清十工位 + 后侧卫生间；
5. `05_public_wc_oblique`：任选一侧公共厕所斜俯视，能看懂两排全封闭隔间与洗手区；
6. `06_overall_birdseye`：去掉/隐藏屋顶后的整体鸟瞰透视。

图片应尽量保持正常透视，不要使用夸张广角导致空间被视觉拉大。

## 6. 检查要求

完成后至少记录：

- 当前测试墙高 / 总高度；
- 人视角相机眼高；
- 是否出现新的实体碰撞；
- 地图在认证后人视角中是否可直接辨认；
- 三后出口是否在大厅视野中清楚；
- 20 × 14 m 工作人员区是否显得明显过大 / 过小；
- 公共厕所是否显得明显拥挤或空旷；
- 65 × 45 m 总体空间是否在 3D 中出现明显失衡。

若没有明显问题，则将管理设施标记为：

`SPATIAL BLOCKOUT ACCEPTED FOR ART DIRECTION`

下一阶段再进入外观、材质、灯光、未来工业设计语言和游戏镜头适配；不要在这一轮提前展开。
