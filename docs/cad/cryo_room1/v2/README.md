## 余量与验证口径

外包21.00×9.50 m，室内净尺寸20.60×9.10 m；净面积187.46 m²。左右墙边至最大底座外包的净余量各1.05 m，前后端各0.50 m。入口缓冲指后墙内面至后排舱头端的0.50 m条带；中央通道贯穿至横向主通道。

横向尺寸链：`21.00 = 2×0.20 + 2×1.05 + 2(5×1.05 + 4×0.70) + 2.40`。

进深尺寸链：`9.50 = 2×0.20 + 2×0.50 + 2×2.30 + 3.50`。

居中的1.40 m人员门接入2.40 m通道，门后两侧各展开0.50 m。房间增宽1.00 m，其中0.80 m用于纵向通道，两侧墙边余量各增加0.10 m。前后舱位Y坐标和端部余量不变。该方案完整容纳20舱，未压缩已确认的操作间距与横向通道，入口轴线更宽；空间比例是否采纳仍需设计审阅。

正体积实体碰撞实测为0。独立保存回读已核对全部舱外包与原生尺寸；对照v1，只有上述三项参数变化，80个舱体分层在平移对齐后逐一比较形状一致，且v1文件字节未变。GUI测试房宽、进深、舱宽、间距、舱高、纵向通道和门宽七项参数联动全部通过，恢复基准后保存。

## 来源与再生成

21.00×9.50 m、2.40 m纵向通道及1.40 m人员门均为设计阶段暂定值。静态闭舱验证不覆盖开盖扫掠、人体上下舱/回转、维修搬运、机器人更换或消防机电；舱体更换路径留待背部服务系统阶段。室内净高TBD，1.30 m墙高仅供剖切显示。
