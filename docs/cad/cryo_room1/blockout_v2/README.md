## 八项判断

| 判断 | 观察与结论 |
|---|---|
| 21×9.5 m比例 | 仍是横向延展的标准设备室；四区、十字通道和20舱在俯视中清楚，未见明显空间失衡。 |
| 1.4 m门接入2.4 m通道 | 门后左右各展开0.50 m，门口人视角形成明确展开，单人进入没有被舱体夹住的感觉。 |
| 门后左右舱是否太贴 | 最近后排舱距后墙内面0.50 m；面向入口的内侧底座距中心线各1.20 m。视觉上仍近，但通道中心连续，没有侵入门洞或中央轴线。 |
| 3.5 m横向通道 | 人视角显示较宽敞的主通道，与2.4 m纵向轴线有明确主次；偏宽但未达到明显失衡，不修改平面。 |
| 0.7 m舱间操作位 | 视觉上紧，适合单人静态接近或站位。直径0.45 m尺度柱在该间隙可放入，底座口径两侧仅各0.125 m剩余；不能据此确认转身、上下舱或协助动作可接受。 |
| 3.4 m暂定净高 | 与1.0 m舱体、1.68 m尺度柱比较，空间偏高且冷静，但未见明显压低或夸张大厅化；继续作为P测试值。 |
| 生命保存室身份 | 低矮单层、内收主体、独立舱盖和头端观察区保留标准化设备感。灰模与重复闭舱排列仍可能引起临床或停尸间联想；最终生命保存设备的美术辨识须后续验证，本轮不更换造型。 |
| 新增碰撞 | 全部90实体两两检查，正体积碰撞0；门洞真实留空；原v2全部80舱体分层未改变。 |

上述空间感结论来自固定相机的人工视觉判断，不是施工尺寸、人体工效认证或玩家感受测试。所有舱保持闭合；没有新增管线、消防机电、装饰、家具、材质叙事或灯光叙事。

## 再生成

使用本项目FreeCAD 1.1.4的`bin/python.exe`运行`build_blockout.py`；随后在独立GUI实例执行`render_blockout.FCMacro`；渲染完成后运行`validate_blockout.py`；人工核对8张最新PNG后，以带Pillow的Python运行`package_blockout.py`。

生成脚本依赖相邻`v2/room1_engineering_v2.FCStd`与`v2/cad_validation.json`。不要覆盖原v2文件。新高度参数在`Parameters`中编辑，原生墙体、门楣、地板与顶板通过表达式联动；改动后需重新截图与回读验证。原v2工程平面保持基准，不随这个独立3D模型变化。
