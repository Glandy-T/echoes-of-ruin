## 实尺结果

RoomWidth/RoomDepth 明确按**外包**口径解释。墙厚0.20 m P。

| 项目 | 本版结果 |
|---|---|
| 外包 / 室内净尺寸 | 20.00×9.50 / 19.60×9.10 m |
| 舱体最大外包 | 1.05×2.30×1.00 m P |
| 舱数量与组织 | 20；四区各5；前后两排各10；长轴沿Y |
| 纵向 / 横向通道净宽 | 1.60 / 3.50 m |
| 同区长边操作间距 | 0.70 m（按最大底座外包量取） |
| 左右墙边净余量 | 各0.95 m |
| 前后墙边净余量 | 各0.50 m |
| 后墙中央门 / 门内缓冲带 | 1.60 / 0.50 m P |
| 静态正体积实体碰撞 | 0 |

门内缓冲带定义：后墙内面至后排舱头端的空置条带；中央1.60 m通道贯穿到横向主通道。0.50 m条带不是独立回转前室，也不作为侧面上下舱通路。

横向反算：`W=2t+2s+2(5w+4g)+a`；进深反算：`D=2t+2e+2l+c`。

以 **侧边余量≥0.70 m、端部余量≥0.50 m** 为本轮暂定比较条件（不是规范最低值），1.05 m宽舱在19.50×9.50 m即可装入；1.10 m宽舱则需20.00×9.50 m。选用简报建议起点20.00×9.50 m，兼容舱宽范围，没有压缩通道或0.70 m间距。19.00×8.50 m旧方案端余量为0，侧边只有0.45 m；9.30 m进深则端部各0.40 m，比本轮0.50 m测试目标各少0.10 m。以上是几何与已说明余量假设下的反算，不宣称全工况最小尺寸。

## 舱体分层（均为 P 占位几何）

底座最大外包1.05×2.30，平面倒角0.12 m；主体每侧内收0.04 m，舱盖每侧内收0.06 m。底座厚0.20H；主体底Z=0.24H、厚0.40H；舱盖底Z=0.68H、厚0.30H；头端观察区底Z=0.98H、厚0.02H。观察区长0.50 m、横向每侧内收0.16 m、距头端0.18 m。前后排观察区分别朝前/后墙，镜像位置只用于本轮测试。

分层之间有0.04H结构间隙；所有层均在最大外包内。观察区的半透明显示只示意磨砂区域，内部人体、材料、玻璃厚度、密封和最终工业造型均未设计。

## 参数编辑与再生成

在FreeCAD的 `Parameters` 修改长度属性即可联动草图、实体及A304原生投影。编辑后保存为新的版本文件；不要覆盖本版审阅基准。A301-A303是出版快照，不会自动更新。

生成工具：本地FreeCAD 1.1.4 `bin/python.exe` 运行 `build_freecad.py`，GUI运行 `finish_in_freecad.FCMacro`，带reportlab的Python运行 `render_pdf.py`，FreeCAD Python运行 `validate_saved.py`。`build_freecad.py --parameters-from 修改文件.FCStd` 可读入参数，但默认重建v1输出，故应先复制本目录到新版本目录后运行。重排之后必须重新检查所有图纸标注；A303敏感性表保留当前基准比较，不能充当任意新布局的结论。
