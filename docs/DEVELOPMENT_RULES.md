# 設定・開示ルール

## 目的

本書は、卒業論文を基盤とする世界観の一貫性を守り、追加設定・実装・台詞・記録物による矛盾や早期ネタバレを防ぐための運用規則である。

## 設定の区分

新しい設定は必ず次のいずれかに分類して記録する。

| 区分 | 定義 | 記録先の目安 |
| --- | --- | --- |
| A. 論文確定 | 卒業論文で明記された世界観、歴史、因果、区域機能。 | `WORLD_BIBLE.md` の「論文確定の世界観基盤」 |
| B. ゲーム制作追加設定 | 論文の核心を損なわず、ゲーム体験・演出・実装のために追加する内容。 | `WORLD_BIBLE.md` の「ゲーム制作追加設定」、各設計書 |
| C. 暫定的な表現案 | ゲーム内での見せ方の候補であり、論文確定または世界設定上の確定事実ではないもの。 | 各設計書で「暫定的な表現案」と明記する。 |
| D. TBD | 内容・時期・範囲・表現方法が未決定、または論文母本との確認が必要なもの。 | 各文書の `TBD` 節 |
| E. 現在区域で開示禁止 | 作者用には存在するが、その章のプレイヤーと主人公には確定情報として提示できないもの。 | `STORY_REVEAL_PLAN.md` の当該区域の非開示項目。 |

追加設定は論文の核心テーマ、二重計画、段階的な真相開示、主人公が偶然生き残った設定を破壊してはならない。

## 情報開示

- 早期区域は異常・不在・故障・矛盾を見せる場所であり、最終原因を説明する場所ではない。
- プレイヤーに出す情報は必ず [STORY_REVEAL_PLAN.md](STORY_REVEAL_PLAN.md) の当該区域の許可範囲に従う。
- 作者用の完全な真相は、プレイヤー向け台詞、UI、記録物、公開資料へそのまま転記しない。
- 技術的真相は科学技術区、政策的真相は政治中枢区で開示するという役割分担を守る。
- 軍事区では、人員・指揮・補給の不在や停止を示してよいが、外宇宙移民、秘密撤離、軍人の最終選別、地球の恒久的放棄へ直接結び付けない。
- 「最後の会議が秘密撤離の偽装だった」という案は暫定的な表現案として管理し、確定資料や序章の記録物へ事実として書かない。

## キャラクターと記録物

- キャラクターの台詞は、本人の身分・立場・時点で知り得る情報だけを用いる。
- 主人公の台詞は [CHARACTER_DESIGN.md](CHARACTER_DESIGN.md) の性格・一人称・台詞規則に従う。
- ファイル、端末、ログ、映像、放送を作る際は、必ず「誰が残したか」「なぜ残ったか」「誰に読まれることを想定したか」を決める。決められない場合は `TBD` とする。
- 記録物は説明のためだけに大量配置せず、環境・仕掛け・区域の役割と結び付ける。

## 変更時の確認

1. 追加内容を A〜E のいずれかへ分類する。
2. 論文確定と矛盾しないか確認する。
3. どの区域でプレイヤーに見せるかを確認する。
4. 早期ネタバレ、作者知識の混入、キャラクターの知識超過がないか確認する。
5. 暫定的な表現案を、論文確定またはゲーム世界の確定事実へ昇格させていないか確認する。
6. 判定できない場合、または論文母本との確認が必要な場合は、確定扱いにせず `TBD` として残す。
