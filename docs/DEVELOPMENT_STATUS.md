# 開発状況

## 現在の開発段階

基本操作、インタラクション、状態保持、2 マップ間の遷移、共通 UI を備えた**探索型謎解きゲームの初期プロトタイプ段階**である。第一段階の工程整理を実施し、メインシーン、Player、GameUI、インタラクション、開発用マップを用途別ディレクトリへ分離した。現在の `prototype_room_a.tscn`／`prototype_room_b.tscn` は機能検証用の簡易マップであり、これとは分離して序章 Room 1「4F 第一休眠室」の正式灰盒第一版を作成した。正式な開場演出、台詞、調査内容、ピクセルアートは未実装である。

## 完了している機能

- DotGothic16 を使用した、1280×720 基準のタイトル画面第一版
- タイトル画面の「はじめる」「設定」「終了」と、キーボード／マウスによるフォーカス操作
- 「はじめる」による Demo 状態の初期化と、開発用 `prototype_room_a.tscn` への一時的な遷移
- タイトル設定画面の操作ヒント表示切替、ウィンドウ／フルスクリーン切替、戻る操作
- `canvas_items`／`keep`／`fractional` による、16:9 を維持したウィンドウ拡縮
- プレイヤーの左右移動、重力、ジャンプ
- `move_left`／`move_right`／`jump` を用いた独立入力割り当て（A・D・W、方向キー、Space）
- Enter を通常移動時のジャンプから分離し、`dialogue_advance` 専用入力として使用
- idle / walk のスプライトアニメーションと左右反転
- プレイヤー追従用 `Camera2D`
- Terminal／Scene Exit の近接検知と `E` キー操作
- 端末認証によるドア解放アニメーション
- 閉鎖中の Door による物理的な通行阻止と、開放後の当たり判定無効化
- Scene Exit による `prototype_room_a.tscn` と `prototype_room_b.tscn` の往復
- `GameState.world_flags` による端末・ドア状態の実行中保持
- `next_spawn_id` と共通 Room Controller による部屋ごとのスポーン適用
- Room Controller の Inspector 設定による部屋別 Camera 境界
- テキストボックス、操作ヒント、フェードアウト
- 複数の近接範囲に対応する、発生元ごとの操作ヒント管理
- ポーズ／再開、設定画面の表示
- `GameState.interaction_hints_enabled` による、タイトル画面とゲーム内 UI で共通の操作ヒント表示 ON/OFF
- 操作ヒント表示設定の現在の実行中におけるシーン間保持
- ポーズメニューからタイトルへの復帰
- 画面下部の第一版主人公独白／調査用 `DialoguePanel`
- Enter／マウス左クリックによる手動改ページ、最終ページでの終了、Esc による即時終了
- 対話中のプレイヤー入力ロック（空中では重力と着地処理を継続）
- 既存キャラクター画像を用いた暫定ポートレートと、7 種類の表情 ID 用インターフェース
- 画像表示と同一 `DialoguePanel` を組み合わせる `DetailOverlay`
- `start_dialogue()`／`start_detail_dialogue()` を呼び出す再利用可能な Investigation Point
- 対話、詳細調査、ポーズ／設定、通常インタラクションの排他制御
- `prototype_room_a.tscn` に限定した通常独白／詳細調査の DEV テストポイント
- `cryo_room_4f_01.tscn` による 1920×720 の正式 Room 1 灰盒第一版
- 空間上の 5 基の休眠ポッド、主役の「POD ID 04」、各ポッドの状態／銘板用 Marker2D
- 局所的な天井崩落、歩行可能な床・壁・設備・瓦礫の灰盒衝突
- `OpeningCameraClose`、`OpeningCameraWide`、`PlayerControlStart` の開場演出用 Marker2D
- 日常巡回表、壁付け検査台、同意書ファイルと、限定的な将来調査用 Marker2D
- `cryo_room_exit_authorized` を使用する DEV 身元認証 Terminal と出口 Door の基礎連動

## 実装済み UI のうち機能が未接続のもの

- BGM 音量スライダーは変更値をコンソールへ出力するのみで、音量ミキサーには接続されていない。
- 言語選択は選択値をコンソールへ出力するのみで、ローカライズ処理には接続されていない。
- 設定内容はセッションをまたいで保存されない。
- BGM と言語のラベルには、現在未接続であることを表示している。

## 第一版対話 UI の範囲外

- 第一版の主人公独白／調査会話ボックスと操作ロックは実装済みである。既存の小型 TextBox は、操作ヒントと短いシステムフィードバック用として分離したまま維持する。
- 正式ポートレートと表情差分、タイプライター表示、音声、会話履歴、分岐選択肢、会話 Resource は未実装である。
- 対話内容の保存、ローカル設定保存、複雑な会話管理用 Autoload は実装しない。
- `S` と下方向キーのゲーム内動作は未設定であり、しゃがみや下方向移動は未実装である。

## Demo 開発範囲

完成 Demo の制作範囲は、最大で第二章「下水道」までとする。世界観、主人公、開示順、調査システムの設計は各設計文書に記録済みであり、今後は実装対象へ落とし込む段階にある。
