# 主角重设计简报（给 Codex）

> 2026-11-17，Claude Code 根据与用户的讨论整理。
> **本简报优先于** [侧面诊断](PROTAGONIST_SIDE_VIEW_REVIEW.md) 第 3 节的 S1／S2／S3 剪影任务，以及 [v4 正面](experiments/protagonist_apose_v4/README.md)、v5 三视图中的长发、长袖、写实比例设定。它们保留作历史和失败教训。
> 下表区分**用户已确认**和**提案待用户确认**。提案只能出剪影供用户选择，不能当成已批准的规格去上色或做 3D。

## 1. 为什么要重设计

1. **侧面像"穿棉袄"**：侧厚约为正面宽的 0.8（目标 0.55～0.65）。"宽松直筒＋略挺布＋收口长袖"的设定本身就会画出一件厚外套，详见侧面诊断。
2. **白长袍＋黑长直发＋赤脚**，是日式恐怖片幽灵的标准组合，在暗绿色的休眠室里尤其明显，和"冷静、主动"的人设相反。
3. **整体偏写实**：旧人设规定"避免过度变形、优先自然人体比例"，提示词又一直写"成人小头、6.5 头身"，再加上分开画的手指、脚趾、肌肉起伏和多层皮肤明暗，结果像"缩小的写实人像"，和低模＋像素贴图的场景风格对不上。
4. **一直在为过场衣服花力气**：主角要横穿沙漠化的死城走 7～10 天（WORLD_BIBLE），睡袍和赤脚不可能是她旅途的主要造型。

| 衣服随剧情变化 | **阶段一**（Room 1 → 走廊 → 楼梯 → 1F）穿休眠服；**阶段二**在管理设施的工作人员区找到并换上留下的衣物，作为 Demo 的收尾："被保存的人"变成"准备出去的人"。 | 💬 提案 |

| 阶段二：旅行装 | 工作人员留下的外套或防护外衣，对她来说**偏大**，套在休眠服外；找到的鞋；可以用捡到的东西把刘海别起来。每件都是从这个死去世界里捡来的。 | 💬 提案 |

| 脸 | **按概念 C**：五官极简，简单的眼睛和一点神情，不用整块眼部阴影（概念 A 试过，缩小后显得阴森）。 | ✅ 11/24 用户确认 |

## 3. 简化程度：三档剪影比较（下一轮唯一任务）

**同一个阶段一造型**（短发、短袖及膝休眠服、赤脚），出三档简化程度：

| 档位 | 头身 | 形体 | 手脚 | 明暗 |
|---|---|---|---|---|
| **L1 现状写实** | 约 6.5 | 有肩、肘、膝等解剖起伏 | 分开的手指、脚趾 | 皮肤多层过渡 |
| **L2 简化** | 约 6 | 躯干、手臂、腿当成简单体块 | 手为"连指手套＋拇指"，脚为一个简单块 | 每种材质只分亮面＋暗面两色 |
| **L3 更图形化** | 5.5～6 | 体块更方、更概括 | 同 L2，更概括 | 同 L2，轮廓更硬 |

每一档都要交：

1. **正面＋侧面纯黑剪影**（128px 画布，头顶、脚底高度沿用 v4），附侧厚／正宽实测值：躯干 0.55～0.65，下摆不超过 0.8。
2. **两色平涂版**（亮面＋暗面），只用来判断体块，不是成品。
3. **游戏实际大小预览**：缩到 Room 1 游戏镜头中的人物高度，和舱体并排放进同一画面看。

这一步**不调用 PixelLab 和 Tripo**，用 Aseprite 手画或简单几何拼出即可。用户选定档位后，再进入第 4 节。

## 4. 选定档位之后的顺序

**11/17 已选定 L2。**画正面定稿时一并处理比较图中看到的两点：
- 衣身不要是直筒：正面下摆略呈 A 字展开；侧面后背从肩胛到腰有轻微内收（对应[侧面诊断](PROTAGONIST_SIDE_VIEW_REVIEW.md)第 4 节第 2 条）。厚宽比仍按 0.55～0.65 验收。
- 正面发顶不要平：加一点弧度和略乱的发梢，读成"刚睡醒的短发"，不像头盔。

1. 按选定档位画阶段一的正面定稿：剪影 → 两色 → 上色。可以用 PixelLab 在剪影内上色，但外形由剪影锁定；提示词只写这一张要画什么，加一句"严格保持导图外形"，不再罗列几十条禁止项。
2. 用同一剪影方法做侧面、背面，按[侧面诊断](PROTAGONIST_SIDE_VIEW_REVIEW.md)第 4 节验收。
3. 阶段二外套和鞋**单独设计、单独审**，先剪影，再上色，作为可以后穿上去的独立部件。
4. 三视图确认后才进 3D，按 v4 README 已写好的停止条件执行。阶段一和阶段二共用同一个身体和骨架。

## 5. 不要做的

- 不要继续修 v4 正面或 v5 侧面、背面，也不要以它们作为新设计的导图。
- 剪影档位确认前，不要上色、不要调用 Tripo、不要改 Godot 里的占位角色。
- 不要恢复长发、长袖、"略挺"、"宽松直筒"、"6.5 头身小头"这些旧描述。
- 不要用长提示词去压外形问题，先由剪影锁定外形。
- 阶段二目前只是提案，未经用户确认，不要把换装写进剧情或关卡设定文档。

## 附录 1（11/24）：正面上色前，先定"感觉"

**现状**：L2 正面剪影和两色体块用户都认可了。用户的原话是"形状很简洁，没啥可审的空间"。也就是说，外形这一步已经够了，接下来真正决定这个角色好不好看的，是上色和质感。

**这一轮想要的**：在 PixelLab 正式上色之前，先用 Codex 自带的生图出几张"成品大概会是什么样"的概念图，让用户挑一个感觉。过去几轮的经验是，让工具直接一次画对很难；先把"想要什么"定下来，后面 PixelLab 才有明确的目标。

**这个角色要给人的感觉**（比任何具体规格都重要）：
- 刚从休眠舱里出来的普通人：单薄、有点虚弱、没整理过，但站得是直的，眼神（或者说脸的朝向）是向前的。
- 她是被制度统一处理过的人：统一剪短的头发、统一配发的休眠服。不是英雄，也不是幽灵。
- 放在暗绿色、低功率应急照明的休眠室里，她应该是画面里最容易被找到的东西，但不能像贴上去的。

**我们的判断**：
- 生图模型好看但不稳定，也守不住像素格和剪影，所以这一轮的图**只当参考目标，不当素材**。
- 外形以已认可的 L2 正面剪影为准：头身、短发长度、短袖、及膝、赤脚都不变。生图时可以把剪影或两色版当参考图喂进去。
- 几个还没定的提案（眼睛那一片用阴影处理、胸口小舱号 P12 或腕带、配色），正好可以在概念图里试一试，让用户看到效果再决定。它们出现在概念图里，不代表已经批准。

**可能的方向**（只是起点，你有更好的想法可以直接提）：
- 方向一：脸几乎不画，眼睛一带是一块阴影；衣服是冷白、很薄的布。
- 方向二：脸只留极少的五官暗示；衣服略暖的米白，带一点洗旧的感觉。
- 方向三：在一、二之间，加上小小的 P12 标记，看身份标记能不能在小尺寸下读出来。
- 可以再加一个你自己觉得最好的方向。

**交付物**：
1. 3～4 张概念图，每张附一句话说明这个方向想表达什么。
2. 一张并排拼图（长边 ≤ 960px）。
3. 每张缩到 Room 1 游戏里的实际人物高度（约 117 原生像素）各放一份，和已认可的两色版并排，看小尺寸下哪个还成立。
4. 回报里自查：哪些地方偏离了 L2 剪影（比如头变大、头发变长、袖子变长），直接写出来，不要为了"看起来一致"去掩盖。

**边界**：不要参考或模仿 Pixel Canals 等第三方作品来生图；这一轮不调用 PixelLab 和 Tripo，不改游戏里的角色。

**开工前**：先用三五句话说你的理解、打算和觉得有歧义的地方，等用户确认再动手。

## 附录 2（11/24）：正面正式上色

> **11/24 用户修订，优先于下文旧轮廓要求。** 主角是被抽签选中的年轻成年人。L2 只约束约六头身、连指手、整块脚等比例与简化程度。正面站姿和轮廓采用 PixelLab 原图 raw/master.png，保留肩臂、腿脚及原生像素位置。右衣侧黑块改冷灰绿，A／B 暖白和脸部小样见[当前对照](experiments/protagonist_front_c_raw_v2/README.md)。

**这一轮想要的**：用 PixelLab 在已认可的 L2 正面剪影里，画出正式的正面像素图，作为之后侧面、背面和 3D 贴图的基准。

- 手臂：剪影是 45 px 宽，概念图都在 33～35 px，看起来更自然。这一轮先按剪影画；如果你画完觉得手臂明显偏粗，在回报里提出来，附一个收窄的对比，由用户决定。

## 附录 3（11/24）：侧面

**现状**：正面已定稿：[B_original.png](experiments/protagonist_front_c_raw_v2/B_original.png)（PixelLab 原图站姿、原脸、衣色 B 再暖一点）。用户对它的评价是"确实不错"。上一轮也说明了一件事：她现在之所以像个人，靠的是肩、肘、手、腿之间自然的衔接，而不是轮廓有多准。

**这一轮想要的**：画出同一个人的侧面（朝右即可），作为之后背面和 3D 的依据。

**要保住的感觉**：和正面是同一个人、同一件衣服、同样的颜色；单薄、刚醒来，但站得直。侧面最要紧的是**不能再像"穿棉袄准备出门买菜"**：衣服是挂在身上的薄布，前面从胸口、后面从肩胛落下，后背有起伏，下摆不撑开。

**我们的判断**：
- **厚度是这一轮唯一需要量的数字。** 躯干侧面厚度约为正面躯干宽的 0.55～0.65（之前的侧面约 0.8，所以像棉袄）。这个数字是用来防止"立起来的外套"的，不是用来逐像素对齐的；量出来在附近、看起来像个人，就可以了。
- **正面定稿管颜色、发型、脸、衣长和头身比例**；侧面的外轮廓和站姿让它自然。不要把结果硬塞回任何剪影，上一轮正是因为这样才坏掉的。
- 短发从侧面看后脑要有体积，不要贴头皮；赤脚、连指手保持和正面同样的简化程度。

**可能的做法**（你有更好的做法可以直接提）：
- 以正面 B 作为 PixelLab 的参照，再给一张很粗的侧面体块草图（只表达厚度和前后关系）做导图；结果出来后只修颜色和明显的错误，不重排像素。
- 如果 PixelLab 有直接从参照转向的功能，也可以试，但要量厚度；偏厚就回到草图导图。
- 两三次还不对就停下来回报问题在哪，不要无限抽卡。

**交付物**：
1. 侧面原生 PNG（128×128）和 Aseprite 源文件。
2. 对比图：正面 B ｜ 侧面，同高并排；另附一张旧"棉袄"侧面 ｜ 新侧面。
3. 侧面放进 Room 1 同机位画面（和正面同一张背景、同样大小）。
4. 回报里写：量到的侧厚／正宽；侧面和正面在颜色、发型、衣长上有没有对不上的地方；为了满足厚度有没有牺牲别的。

**边界**：只上传项目自有的图给 PixelLab；记录提示词、原始输出和额度。这一轮不做背面和 3D，不改游戏里的角色。

### 附录 3 修正（11/24）：侧面手腿收窄（在附录 4 之前做）

## 附录 4（11/24）：背面

**现状**：正面 [B_original.png](experiments/protagonist_front_c_raw_v2/B_original.png) 和侧面 [side.png](experiments/protagonist_side_c_v1/side.png) 都已定稿，用户觉得侧面"还好"，可以用。关于侧面厚度的更正：附录 3 的 0.55～0.65 原本指"侧面躯干厚度 ÷ 正面含袖的肩宽"，按这个口径，侧面约 0.6，下摆约 0.63，都没问题；上一轮报的 0.94 是拿腋下躯干比的，是我们的数字没写清楚。

**这一轮想要的**：同一个人的背面，凑齐三视图，作为 3D 的依据。
