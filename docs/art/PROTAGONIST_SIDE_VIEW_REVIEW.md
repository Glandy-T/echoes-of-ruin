# 主角侧面立绘：问题诊断与下一步建议（给 Codex）

> 2026-11-17，Claude Code 应用户要求所写。用户评价 v5 侧面"像穿棉袄准备出门买菜"，希望先听另一方的看法，再交给 Codex 继续改。
> 本文件只是诊断和建议，**不是已批准的设计**；哪一个方向成立，由用户看完剪影后决定。本次没有生成、修改任何主角图或 3D，PixelLab／Tripo 调用 0 次。
> 依据：`docs/art/experiments/protagonist_apose_v4/`（已提交），以及本机未提交的 `docs/art/experiments/protagonist_apose_turnaround_v5/`（`raw/side.png`、`raw/side_pose_fix_unreviewed.png`、`source/prompt_side*.txt`）。

## 1. 量出来的问题

在 128px 原生图上逐行测量袍子范围（正面量躯干，避开手臂；侧面量前后厚度）：

| 高度（y） | 正面宽 | 侧面厚 | 侧厚／正宽 |
|---|---|---|---|
| 60（腰） | 24 px | 19 px | **0.79** |
| 80 | 28 px | 23 px | 0.82 |
| 100（下摆） | 32 px | 28 px | **0.88** |

真人躯干的前后厚度一般只有肩宽的一半多一点。穿宽松睡袍后，侧面看下摆前后可以略厚，但躯干部分大约在 **0.55～0.65** 才像一个人。现在侧面几乎和正面一样宽，**截面接近圆柱**，所以读起来像一件有填充物、自己撑着形状的外套，也就是"棉袄"。`side_pose_fix_unreviewed.png` 只改了手的位置，袍身数值完全相同，问题没有被它修掉。

看图还能看到几处加重棉袄感的细节：

- **后背是一条从肩膀垂到下摆的直线**，没有肩胛、腰背的起伏，前面也只在胸口鼓一下就直落。布料没有"挂"在身体上的位置，看起来像衣服自己立着。
- **长袖是一根粗管**，从肩到手腕粗细不变，压在身体侧面，再加上一圈深色描边，就成了外套袖子。
- **下摆平直、偏厚**，前后几乎没有张开或收拢，像硬布。
- 领口高、脖子几乎被头发和领子挡住，肩线又平又方，整体显得缩着、裹着。

## 2. 为什么会这样：不只是 PixelLab 抽得不好

### 2.1 设定本身在推向"厚外套"

v5 侧面提示词里同时要求了：`loose straight calf-length body`、`roomy garment`、`slightly structured polyester-blend woven cloth`、`tapering long sleeves`，又要求 `coherent side depth of chest, back`。

"宽松＋直筒＋略挺的布＋长袖"这个组合，在现实里就是一件不贴身、能自己撑住形状的长外套。正面图因为看不到厚度，问题不明显；一到侧面，AI 就会忠实地给出一个又厚又直的筒。**所以这不是抽卡运气，而是描述本身的结果。**再多加修补条件（比如上一轮专门修手的高度），也只是在同一个错误的筒上改局部。

### 2.2 流程让 AI 去猜厚度

现在的做法是"把这张正面图旋转成侧面"。正面图里没有任何厚度信息，AI 只能自己猜，而提示词又说要 roomy、要有 depth，于是猜得偏厚。提示词越长、约束越多（v5 侧面提示词有四百多词），越容易互相拉扯，而且看不出到底是哪一条起了作用。

## 3. 建议的下一步（按顺序，每步给用户看了再往下）

### 第 1 步：先定侧面剪影，暂时不画像素

在 128px 画布上只画**纯黑剪影**，正面和侧面成对，头身比、身高、头顶和脚底位置都沿用 v4 正面。剪影可以用 Aseprite 手画，或用身体 v2 模型渲染侧面轮廓后再描。不调用 PixelLab，几乎零成本。建议出三组，让用户选：

| 方案 | 袍子的剪法 | 侧面目标 |
|---|---|---|
| **S1 修比例** | 设定基本不变（长袖、及小腿、直身），只把厚度改对 | 腰部侧厚约为正面宽的 0.6；后背从肩胛到腰有轻微内收；下摆前后略张开 |
| **S2 换成垂坠布** | "略挺"改为"薄而垂"，胸口以下布料贴近身体落下；袖子改七分或更细的长袖；下摆略收 | 腰部 0.55 左右；前面从胸点挂下，后面从肩胛挂下，中间有空隙但不鼓 |
| **S3 更像病号服** | 及膝或略过膝、短袖或五分袖、领口稍开，露出脖子和锁骨 | 0.55 左右；露出更多手臂和小腿，显得单薄、脆弱，更像"被保存的人" |

每组都给出正面＋侧面黑剪影和一张缩到游戏实际大小的预览。S2、S3 会改动已认可的正面，必须由用户决定；如果选了，正面 v4 也要做一次相应修改，不能只改侧面。

### 第 2 步：用剪影约束上色，不再"旋转正面"

用户选定剪影后：

1. 用选中的剪影做导图。可以在 Aseprite 里先铺 2～3 个平色块，分出头发、皮肤、袍子和主要明暗。
2. 让 PixelLab 只负责**在这个外形里上色和刻画**（Edit／inpaint），不再让它决定外形。
3. 提示词改短：只写这一张要画什么，以及一句"严格保持导图外形"。不再罗列几十条禁止项。
4. 验收先看剪影（缩小到游戏尺寸看是否还像棉袄），再看细节。

### 第 3 步：之后才进 3D

剪影和三视图确认后，再按 v4 README 已写好的 3D 顺序和停止条件往下走：灰模外形 → 开口和内部结构 → 试穿和关节动作 → UV／贴图 → Godot 实拍。

## 4. 侧面验收标准（建议写进下一轮任务）

1. **厚度**：腰部侧厚约为正面躯干宽的 0.55～0.65；下摆前后可以更宽，但不超过正面下摆宽的 0.8。
2. **布料挂点**：前面从胸点、后面从肩胛落下，后背线有起伏，不是一条直线。
3. **袖子**：袖宽不超过前臂宽约 1.3 倍，肩头不方、不鼓。
4. **脖子**：侧面能看到一小段脖子和下颌线，不被领子和头发完全吞掉。
5. **描边与明暗**：袍子外轮廓描边不比头发描边粗；袍子内部的明暗块不超过 2～3 块，避免填充物的质感。
6. **小尺寸检查**：缩到游戏实际高度后，看起来仍是"穿着睡袍的人"，而不是"穿着外套的人"。

## 5. 不建议继续做的

- 不要在 v5 侧面上继续叠加局部修补（比如再修手、修袖口）。外形本身不对，局部修得再好也是棉袄。
- 不要用 `side_pose_fix_unreviewed.png` 作为下一步的输入。
- 剪影没定之前，不调用 Tripo，也不做背面。
- 不要靠加长提示词去压厚度，先改设定，再改流程。
