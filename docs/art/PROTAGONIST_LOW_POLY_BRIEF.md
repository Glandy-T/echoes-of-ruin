# 主角低模与像素贴图制作简报

**2026-11-06当前入口：[身体v2同机位与临时动作检查](experiments/protagonist_tripo_body_v2/preview.html)。** 用户本轮接受白袍外形先保留，要求继续身体。身体v2修复脚趾局部28对交叉，保留其他人体表面与原始法线；身体母版及GLB重导已通过静态几何检查。独立临时骨架工程已做19骨、4项归一化权重和A姿势／抬臂／弯肘／迈步4帧诊断，均无真自交，但仍非生产动画／最终权重批准。白袍外形不重设计，其272对相交和2条非流形边仍要在绑骨前整理；之后统一身体与衣物姿势、共享骨架试穿。没有最终UV／像素贴图或Godot角色替换。原始分件导出、整人头发v2和失败结构v3均保留独立来源，不能混作已完成角色。

**头发简化要求已明确：**模型只保留发型轮廓和少量大块发束，细发丝、卷丝、悬空窄条没有必要，不为它们安排精细UV。后续发束分界交给像素贴图；不能因此把整块头发做成僵硬头盔。有限清理能保住造型则继续用本源；需要大幅重建时按用户已授权方向分别制作头发、可见身体、白袍，不再反复整人生成。身体v2已做有限静态与临时姿势检查，衣物仍需结构整理及试穿，不能据此宣布完整角色可动画。

**历史版本不作当前基线：**[本地修模v1](experiments/protagonist_blender_cleanup_v1/README.md)被用户否决（“负优化了”）；[H2.5免费灰模](experiments/protagonist_tripo_h25_v1/README.md)有后发碎片、粗块手指、未合理分件；[国际版P2.0免费试作](experiments/protagonist_tripo_trial_v1/README.md)当时未能导出。三者只留追溯，不能继续当作已认可模型或与此次国内版混用。旧“主角暂停”已被11月6日用户恢复指令取代，旧模型否决仍然有效。

设计参考状态（2026-11-03）：正面v2获用户认可为继续制作的基准；三视图v1背面手脚朝向被用户指出错误，已建立v2返修候选与更新部件标注，待审。用户明确预期3D后还会调整，尚未批准最终模型。本文件接续现行角色身份设定，不取代`docs/CHARACTER_DESIGN.md`中的人物性格与世界事实。

## 已确认与本轮范围

- 最终采用低模3D＋像素贴图；现有Sprite3D继续占位，Room 1模型、布局、镜头与灯光不动。
- 用户最新服装要求：“白袍吧，不用什么复杂的，就是统一的休眠服感”，并希望考虑时间痕迹。
- 用户审看v1后指出脸显得“苦大仇深”、肤色太深，并确认沿《INSIDE》式弱化五官的方向修正：肤色更浅、偏中性暖色，脸与手脚统一；省略明确眉眼、嘴角和重眼窝，保留简单面部体积。借鉴其面部信息简化方式，不复制角色设计；不把参考截图上传生成服务。v2获用户“还可以”的继续制作认可，三视图沿用，3D后可再调整。
- 主体图像用PixelLab，Aseprite只做有图层记录的局部精修与文件整理。Pixel Canals只作技术观感参考，不上传其NoAI内容。
- 先做一张正面设计，检查外形；认可后补同设计的侧面和背面，再进行3D初稿、低模整理、UV与最终像素贴图。没有认可正面前，不批量生成其他方向或动作。

## 第一稿暂定解释（不是用户最终外观批准）

沿用当前占位的深色长发、年轻女性、简单浅色长袍印象，改成自然成人比例。亚洲系方向仍为原设定中的暂定项。正面平视、全身、双臂稍张开，便于后续建模；不是游戏相机效果图。

服装先试：普通闭合圆领、宽松但不臃肿、长袖露出手、约小腿下部长度的白色休眠袍。没有腰带、翻领、复杂扣件、装甲、医疗器械或花纹，不画成医生实验服、和服或战斗装。第一稿暂用赤足以表达刚苏醒；领型、袍长、鞋袜和具体发型长度均待看稿确认。

## 时间感的制作判断

几十年属于设施经历的时间，不表示主人公一直在地面行走或穿着衣服暴露于室内。封闭休眠中的温湿度、织物类型与保存系统尚无足够参数，不能科学断言应有多少泛黄或破损。

因此第一稿建议克制处理：白／冷灰色织物轻微失白、存放产生的软折痕、领口袖口和折边少量灰冷色差。它应读成保存很久的统一休眠服，而非满身锈黄、泥污、霉斑、血迹、破洞或僵尸服装。醒来后的新磨损留给后续剧情和移动阶段。脸与身体不因环境年代自动变老。

## 规格、验收与下一步

- 正面稿先用192×256原生画布，是本张参考图的试作尺寸，不是角色最终贴图尺寸或游戏精灵规格。严禁拉伸旧96px精灵充当自然比例。
- 外形优先：自然的头身比、对称站姿、可理解的头发和袍体体积、四肢与衣服边界清楚；不能只有“技术生成成功”。
- 正面图认可后，其他视图须对齐头顶、肩、腰、膝和脚底；不能分别抽出不同人。需要多视图3D生成时按该工具的实际接口分别导入。
- 三视图验收必须逐项检查前后解剖朝向：背面头／颈、肩背、手背／掌面、拇指位置、脚跟／跟腱、脚趾朝向；同时对照侧面的手指放松程度与脚部姿态。头顶脚底对齐、配色一致、文件检查通过不能代替这些检查。v1曾出现“后背配正面手脚”，用户指出后将其背面列为错误参考，必须返修再进入3D。
- 3D初稿需先通过静态外观审查，再整理变形网格、UV和绑定。最终纹素密度以现行像素基准与Room 1实机观感验证，不把本参考画布当UV贴图直接投影。
- 既往`player_character_assembled_v5`等拼装试作未获认可，不作为本轮默认模型。

## 3D部件拆分计划

用户要求生成三视图时同时考虑应拆分的部分。三视图主稿保持完整穿着的人物，另交部件标注；完整造型和部件可编辑性应同时保留。以下为目标制作结构；目前已分别取得身体与白袍；身体v2已有独立临时骨架探针，尚未装配或完成生产绑定。

| 部分 | 建议结构 | 理由与边界 |
|---|---|---|
| 身体可见部分 | 头颈、手、脚归身体体系；头可独立编辑，接缝安排在领口／发际遮挡处 | 保持自然人体体积和皮肤材质统一。首轮不必完整精修衣内不可见身体；保留必要的躯干／腿部代理与变形参考，避免袍子下面完全没有人体结构。 |
| 白色休眠袍 | 一套独立衣物网格，袍身与袖子连续连接，领口、袖口、下摆有必要厚度 | 便于UV、贴图与穿插处理，不把衣服画在裸身体上，也不把袖子／下摆拆成悬空纸片。裙摆保留可控的变形区域；首轮不引入布料物理。 |
| 头发主体 | 后发作为独立低模体块，前额与两侧发束可作为独立小块或可分选组 | 便于调整后脑／发尾轮廓、遮挡与贴图；保持有限体块，不逐根发丝，不默认透明发卡。三视图未见的背部发尾长度是候选设计。 |
| 眼鼻口与表情 | 用头部简单体积和低信息贴图表达 | 不独立制作眼球、牙齿、嘴腔或细密表情拓扑。鼻部轮廓要有基本体积，弱五官不等于完全平面。 |
| 骨架与导出 | 一个角色骨架驱动身体、衣物和必要头发块；保留可识别网格名与材质分组 | 部件独立不意味着动作互相脱离。最终在Godot核对权重、穿插与统一比例；当前只有身体单独临时骨架探针，尚未生产绑定或导入。 |

AI生成的3D结果未必自动遵守这些边界。若生成成整块，仍须在Blender分离／整理拓扑、补遮挡表面、展开UV并重新分配权重；不能只按贴图颜色切开就称为可动画角色。用户于11月6日明确同意分件再生成，现已生成中性、无私密细节的衣内基础身体；其他服装与复杂装备仍不在本轮范围。

当前正面候选：[主角正面 v2](experiments/protagonist_front_v2/README.md)，仅改肤色及面部信息；[v1](experiments/protagonist_front_v1/README.md)保留原始来源与回退，其细画眉眼和沉重神情不作为建模依据。

当前三视图与部件标注：[主角三视图 v2](experiments/protagonist_turnaround_v2/README.md)，背面仅返修手脚朝向；[v1](experiments/protagonist_turnaround_v1/README.md)背面为错误追溯，不作建模依据。

## 换装与运动约束（2026-11-06新增）

- 身体、白袍和头发分别保留可编辑网格，最终共用一个 humanoid Armature、同一休止姿势与比例。换衣服替换衣物网格，不重建每套骨架；遮挡身体可在运行时隐藏，但保留完整编辑源。
- 先统一 A 姿势和肩／肘／腕／髋／膝位置。当前身体与白袍的臂角不同，不能直接自动权重就算完成；不把网页“Quad”标签当成关节变形拓扑保证。
- 颈、袖口、下摆需真开口，腋下无封死折片和交叉；肩肘、髋膝保持连续合理布线，衣服有抬臂和迈步余量。身体v2已修复脚趾相交；衣服结构检查与遗留问题见当前实验报告。
- 长袍下摆必要时增加同一骨架内的裙摆辅助骨，首轮不引入布料物理；身体与衣服权重需共同检查，不独立自动绑定后硬拼。
- 最低动作验收：待机、转身、行走／迈步、双臂抬起、弯肘、跨步与坐起需求核对；从正侧背观察腋下、袖口、裆部、膝与下摆，查穿插、塌陷及异常拉长。静态网格检查通过不代表这些通过。
- 顺序固定为外形审看→有限拓扑修整／统一姿势→试穿→临时骨架与动作小样→UV及PixelLab像素贴图→Godot同镜头与动画复核。身体单独4个临时姿势已实际渲染并检查，衣物／游戏动作测试未执行，不以此宣告可动画交付。
