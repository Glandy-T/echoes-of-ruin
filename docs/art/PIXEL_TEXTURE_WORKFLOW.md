# 像素贴图制作流程（2026-11-02 更新）

适用于Room 1及后续场景的像素贴图生成、返修和游戏内验收。当前约束为**PixelLab主制作＋Aseprite局部美术精修**，更新此前“返修只能使用PixelLab”的限制；不能擅自改成纯手绘主体、程序化脏污或其他生成工具。视觉／颗粒执行起点、代表小样与停止返修规则见[像素美术制作基准](PIXEL_ART_PRODUCTION_STANDARD.md)。

1. **视觉基准：Pixel Canals。** 以其低模 3D 承载像素贴图的方式、可读的像素簇、材质层次和固定镜头下的整体精细度为硬参考；借鉴技术表现，不照搬建筑、色彩或具体设计。对照时区分观察与技术推测。该作品页面有 NoAI 标记，不能把其截图、模型或贴图上传给 PixelLab 等生成服务。
2. **主体生成与大范围返修：PixelLab。** 使用项目自身的模型、UV、贴图、导图或已确认素材作为输入；先锁定需保留的轮廓、结构、原生密度和位置。记录实际接口、提示词、输入、原始输出和用量。主体不合格仍交PixelLab处理，不无限抽卡，也不能把未调用PixelLab的结果称为其原始输出。
3. **局部美术精修与整理：Aseprite。** 允许逐处整理像素簇边缘、清理突兀色块、调整少量痕迹、处理UV边界与编号；保留独立命名图层及修改说明。继续承担分层、遮罩、裁切、配准与导出。脚本只准备导图、遮罩、检查和打包，不绘制随机污斑／粗多边形代替主体制作；不得把精修后的成品全部描述为未经修改的PixelLab原图。
4. **验收：原尺寸、放大和游戏镜头都看。** 检查像素簇尺度是否一致，有无大块突兀色块、随机脏污、UV 接缝、门框假光；再导入 Godot，在当前 Room 1 灯光与相机下截图，与前版和 Pixel Canals 的技术表现目标对照。保存原始 PixelLab 结果和最终导出，区别候选与已验收版本。
5. **工具受阻时遵守分工。** 需要PixelLab生成或大范围返修却无法接入时，保留原版并说明，不能擅自更换主体工具；已有底稿的授权局部Aseprite精修可继续。默认代表资产先收敛，用户认可后冻结，不再无目标重开全室风格比较。

本约束优先于旧的“PixelLab唯一返修工具”和更早“脚本直接重画做旧”的说明。新授权不改变过去素材的真实来源。空间尺寸、建模、UV、灯光及动画仍按各自现行文档管理；本轮只更新约束，没有生成新贴图。

**2026-10-30 当前墙面完成度基准：用户已认可 [r23 A/B](experiments/room1_wall_detail_r23/README.md)。** 保留接缝／灯槽／墙脚成组沉积、细碎边缘和逐渐变淡的过渡；完整大面不等于减少到只剩黑缝和几粒散点。所有差分改变痕迹分布，保持相近丰富度；检查最弱的单块半板，不能只看整面墙的平均密度。增加大块剥落／裂纹也不算提高完成度。推广见 [r24全墙](experiments/room1_wall_detail_full_r24/README.md)，实际巡检须覆盖前墙两端、门洞墙肩、四角与被舱体遮挡的下沿。原生256px仅是这些资产的文件属性，不自动成为全项目像素规格。下文r11–r16保留为制作来源和历史记录，不覆盖本项最新要求。

**2026-10-30 当前地坪完成度基准：用户已认可 [r25 C](experiments/room1_floor_detail_r25/README.md)。** 全室推广见[r26](experiments/room1_floor_detail_full_r26/README.md)：原生像素直接按世界位置配准，采用不同PixelLab原图，不把一个样段反复平铺，也不先缩小再放大。地坪连续无缝，模型与布局不动；接触痕、四处原有漏液保持位置逻辑。实际原生全图和游戏机位都要检查重复与技术分块边；主体问题交PixelLab、明确局部问题可用Aseprite精修，不能用脚本污斑或模糊掩盖。

## 历史来源记录（不作为当前操作步骤）

以下r10–r16及旧基线说明保留制作事实，当前实际版本查[版本索引](ROOM1_VERSION_INDEX.md)，不能因历史正文出现“现行”“最新”就覆盖2026-11-02规则。

首轮旧墙面返修见 [PixelLab r10 样段](experiments/room1_wall_pixellab_r10/README.md)：先审左墙两块墙板的颗粒与材质强度，再推广四墙，随后处理旧地板材料。该样段尚未替换原全室基线。

**历史墙面基准：[r11 四墙统一重做](experiments/room1_wall_pixellab_r11/README.md)。**用户指出r10仍混有旧粗做旧后，r11只用干净底色／灯槽／接缝／保护带作输入，剔除全部旧材料色差与旧化图层，再用PixelLab生成四墙新材质。默认新材质不混用r6，旧图仅在历史比较时装载。

用户认可r11后，新增 [r12 墙板差分安排](experiments/room1_wall_pixellab_r12/README.md)，继续沿用r11基调，通过更多PixelLab原图和固定的单墙板分配减少重复。

当时的审图补充为 [r13 后墙与灯带](experiments/room1_wall_lamp_r13/README.md)：补齐门所在宽墙板的材质强度，加入PixelLab灯罩／槽边细节，并解决可见发光面过曝掩盖像素纹理的问题。其余r12差分安排保留。

[r14 地坪返修](experiments/room1_floor_pixellab_r14/README.md)同样从干净导图重建，弃用旧人工做旧。底材使用PixelLab图像生成接口，接触痕使用其编辑接口；保留原图、弃用原因、110 generations实际记录及Aseprite母版。独立候选未替换正式入口，当前沿用原烘焙作材质对照。

[r15 地坪差分](experiments/room1_floor_variants_r15/README.md)保留r14单块材料基调，新增PixelLab原图并剔除近似复制，最终用7份底材、5份接触、4份漏液固定安排；脚本只做统一调色板配准与原生像素边界拼接。分开记录独立原图数、铺设次数与200 generations实际用量，不能把翻转或近似复制算作新原图。

[r16 单舱材质返修](experiments/room1_pod_pixellab_r16/README.md)继续用PixelLab，从结构导图与功能编号出发，去掉v4后加的脚本旧化。四套外壳＋共用舱内材质共15图，150 generations实际调用；玻璃、动态屏幕和全部灯管部件保持，不宣称为本轮新生成。只绑定P12实体表面，不提前推广其余19舱。
