# 像素贴图制作流程（2026-10-29 确认）

适用于 Room 1 及后续场景的像素贴图生成、返修和游戏内验收。此流程是用户确认的约束，不得在没有用户明确同意的情况下改成手绘、程序化脏污或其他生成工具。

1. **视觉基准：Pixel Canals。** 以其低模 3D 承载像素贴图的方式、可读的像素簇、材质层次和固定镜头下的整体精细度为硬参考；借鉴技术表现，不照搬建筑、色彩或具体设计。对照时区分观察与技术推测。该作品页面有 NoAI 标记，不能把其截图、模型或贴图上传给 PixelLab 等生成服务。
2. **生成和返修：PixelLab。** 使用项目自身的模型、UV、贴图、导图或已确认素材作为输入；先锁定需保留的轮廓、结构、分辨率和位置，再用 PixelLab 生成或修改像素材质细节。可以选择 PixelLab 网页、官方 API 或 Aseprite 扩展，但必须明确记录实际使用方式、模型／接口、提示词、原始输出和额度。不能把未调用 PixelLab 的手工结果称为 PixelLab 产物。
3. **整理：Aseprite。** 用于分层、遮罩、裁切、配准、保留功能性标识及导出可编辑母版；脚本可准备遮罩、检查尺寸和打包文件。不得用手绘或程序生成的污斑、粗多边形代替 PixelLab 的纹理创作。必要的局部技术修整需说明其范围与原因。
4. **验收：原尺寸、放大和游戏镜头都看。** 检查像素簇尺度是否一致，有无大块突兀色块、随机脏污、UV 接缝、门框假光；再导入 Godot，在当前 Room 1 灯光与相机下截图，与前版和 Pixel Canals 的技术表现目标对照。保存原始 PixelLab 结果和最终导出，区别候选与已验收版本。
5. **工具不可用时暂停该贴图制作。** 说明 PixelLab 接入或输出哪里受阻，保留现行版本并等待修复或用户明确改变流程；不能擅自转用手工方案。

本约束优先于早期文档中“用 Aseprite／脚本直接重画贴图”的历史试作记录。空间尺寸、建模、UV、灯光及动画仍按各自现行文档管理。

**2026-10-30 当前墙面完成度基准：用户已认可 [r23 A/B](experiments/room1_wall_detail_r23/README.md)。** 保留接缝／灯槽／墙脚成组沉积、细碎边缘和逐渐变淡的过渡；完整大面不等于减少到只剩黑缝和几粒散点。所有差分改变痕迹分布，保持相近丰富度；检查最弱的单块半板，不能只看整面墙的平均密度。增加大块剥落／裂纹也不算提高完成度。推广见 [r24全墙](experiments/room1_wall_detail_full_r24/README.md)，实际巡检须覆盖前墙两端、门洞墙肩、四角与被舱体遮挡的下沿。原生256px仅是这些资产的文件属性，不自动成为全项目像素规格。下文r11–r16保留为制作来源和历史记录，不覆盖本项最新要求。

首轮旧墙面返修见 [PixelLab r10 样段](experiments/room1_wall_pixellab_r10/README.md)：先审左墙两块墙板的颗粒与材质强度，再推广四墙，随后处理旧地板材料。该样段尚未替换原全室基线。

**现行墙面风格基准：[r11 四墙统一重做](experiments/room1_wall_pixellab_r11/README.md)。**用户指出r10仍混有旧粗做旧后，r11只用干净底色／灯槽／接缝／保护带作输入，剔除全部旧材料色差与旧化图层，再用PixelLab生成四墙新材质。默认新材质不混用r6，旧图仅在历史比较时装载。

用户认可r11后，新增 [r12 墙板差分安排](experiments/room1_wall_pixellab_r12/README.md)，继续沿用r11基调，通过更多PixelLab原图和固定的单墙板分配减少重复。

最新审图补充为 [r13 后墙与灯带](experiments/room1_wall_lamp_r13/README.md)：补齐门所在宽墙板的材质强度，加入PixelLab灯罩／槽边细节，并解决可见发光面过曝掩盖像素纹理的问题。其余r12差分安排保留。

[r14 地坪返修](experiments/room1_floor_pixellab_r14/README.md)同样从干净导图重建，弃用旧人工做旧。底材使用PixelLab图像生成接口，接触痕使用其编辑接口；保留原图、弃用原因、110 generations实际记录及Aseprite母版。独立候选未替换正式入口，当前沿用原烘焙作材质对照。

[r15 地坪差分](experiments/room1_floor_variants_r15/README.md)保留r14单块材料基调，新增PixelLab原图并剔除近似复制，最终用7份底材、5份接触、4份漏液固定安排；脚本只做统一调色板配准与原生像素边界拼接。分开记录独立原图数、铺设次数与200 generations实际用量，不能把翻转或近似复制算作新原图。

[r16 单舱材质返修](experiments/room1_pod_pixellab_r16/README.md)继续用PixelLab，从结构导图与功能编号出发，去掉v4后加的脚本旧化。四套外壳＋共用舱内材质共15图，150 generations实际调用；玻璃、动态屏幕和全部灯管部件保持，不宣称为本轮新生成。只绑定P12实体表面，不提前推广其余19舱。
