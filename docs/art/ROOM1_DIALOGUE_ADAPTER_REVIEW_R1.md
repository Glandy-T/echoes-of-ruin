# Room 1 3D 调查与对话适配试验 r1

在 Godot 打开 `scenes/dev/room1_dialogue_adapter_review_r1.tscn`，按 F6。角色起始位置有一个不可见的临时测试区域：进入范围显示「E：調査テスト」，E 开始两页测试对话，Enter 翻页，Esc 关闭对话或打开暂停菜单。WASD 移动，原有审查按键仍可用。临时文字和区域不代表正式物件或剧情。

场景继承现有纸片角色／灯光审查入口，通过 Area3D 检测角色；提示位置由 3D 摄像机投影到 2D 代理，再交给原 GameUI。原 UI 通过试验场景控制器的 `set_input_locked` 锁定角色移动，关闭对话后恢复。正式主场景、原 UI、旧角色和原审查场景未改动。

Godot 4.6.2 headless 运行 `scripts/dev/verify_room1_dialogue_adapter_r1.gd`，检查区域进入／离开、提示、模拟 E、两页对话、对话期间移动受阻及关闭后恢复，均通过。自动检查不代表实际显示、遮挡或操作手感已通过用户审查；学校机器需重新导入并试玩。此试验只支持一个临时点，多交互目标选择、正式剧情内容和主门芯片检测尚未实现。
