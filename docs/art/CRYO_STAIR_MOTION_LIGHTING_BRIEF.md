# 休眠楼消防楼梯间：运动感应式应急灯带（2026-10-29）

> 状态：**已确认的美术／体验方向**，仍待 Godot 灯光、范围、动画与工程安全测试；不是本次已实现的功能。
>
> 适用范围：现行休眠楼 **西、东、北、南四座消防楼梯间**，优先设计主人公实际经过的楼梯路径；其余楼梯可复用同一模块。不得改变冻结 CAD 的楼梯位置、平台、梯跑、门洞和通行关系。

## 已确认方向

1. **感应种类：运动感应，非声控。** 楼梯间的灯随人的移动按区段自动响应，不需要主动操作开关。
2. **照明强度：楼梯间必须比 Room 1 昏暗的休眠室明显更亮。** 楼梯踏步、落脚处、平台及转弯边缘要清楚可见，符合应急通道不致因照明不足引发事故的设计目的；不追求恐怖式漆黑楼梯。
3. **建筑语言：一体化嵌入式灯带。** 可优先研究沿梯跑侧墙顺坡、经过平台转为水平的连续灯带，或与扶手上方／墙体转角统一构造。具体高度、照射方向、长度和可见截面待实机审图；不额外堆外露灯具。
4. **体验效果：“走到哪，灯就提前亮到哪”。** 人接近一段梯跑／平台时，当前位置与前方相邻区段先增亮；继续移动时下一段依次亮起。身后的灯**延时、渐变**恢复基础亮度，避免突然熄灭或出现一盏盏灯追逐脚步的舞台效果。
5. **没有人时也保留最低安全导向亮度**，而不是楼梯彻底黑暗。检测信号中断、角色暂时站着不动，也不能立刻关灭正在使用的梯段：需要覆盖停留情况的合理保持时间或占用判断。感应仅控制**增亮**，不作为唯一安全照明保障。
6. **世界观理由：**长年无人、一般照明已减载，消防楼梯作为紧急退出路径仍由有限应急电力维护低功率导向照明；有人经过时提升该分区亮度，使安全和节能兼容。表达冷静、持续履行职责的自动化系统，不添加主动欢迎或对话。

## 视觉节奏参考（概念，不锁数值）

| 状态 | 对应视觉 |
| --- | --- |
| 无人 | 极弱但可辨的连续导向灯、踏步轮廓仍可见 |
| 接近楼梯口／下段 | 入口平台与前方一整梯跑逐步增亮，不等脚踩到暗处 |
| 移动中 | 相邻一段提前变亮；主体周围及下一处转角可安全辨路 |
| 暂停或转身 | 保持当前安全亮度，不能立即因无动作而熄灭 |
| 离开某区段 | 身后灯延迟变暗，回落至基础安全亮度 |

## 尚待独立确定

- 灯带嵌入高度、墙面/扶手/平台衔接方式、照射方向、颜色与准确亮度；
- 运动感应区段划分、提前触发距离、淡入淡出时长和停留检测/保持策略；
- 不同楼层与地下层是否复用相同布局；断电、故障或疏散状态的保底供电方案；
- Godot 实现及视觉审核：开/关态各一组实机截图和角色实际上下楼梯的连续录像；动态增亮不应破坏既有静态烘焙或制造跳亮阴影。
