# 主角衣发素材候选与制作方向

2026-10-13。候选已看作者实物预览，尚未购买或下载源模型。
用户认可白袍外观；头发仍待选定，完整组合尚未批准。

## 当前决定

用户否定了自建头发的外观，要求除建筑外优先寻找现成素材，再做适配修改。
停止 `player_character_v3` 的自建衣发路线；该目录的造型、贴图和预览均不作为批准资产。
此前用户认可的 pistachio 人体基模可保留，独立进行 UV 与骨架验证。

角色要求仍是：165 cm、自然比例、长发、白色长衣、赤脚，无绘制五官但保留面部体积。
身体、头发、衣服保持独立可编辑网格和 UV。先确认静态外观，再处理动作与最终像素贴图。

本轮反馈：用户表示免费几何发型包中没有想要的普通黑长发；白袍不错。
头发改按普通黑长直发筛选，不能用卷曲、翘起或明显风格化的发型代替。

后续用户又否定写实发片过于精细，明确要求从现成低模角色里寻找普通黑长直发，先看原素材。
因此 hamza 写实发片也不再作为优先试用方案。白袍继续保留；本轮没有生成、购买或下载新资产。
