## 归档位置与恢复

本机归档位于项目同级：`../Room1本机整理归档_20261102/snapshot_173418/`。

- `MANIFEST.json`：原相对路径、归档相对路径、大小和SHA-256。
- `before_sync/`：同步前存在差异的本地版本。
- `inactive_local/`：移出的历史试做及本机资料。
- `SYNC_PLAN.json`：同步前文件清单。该清单和本机归档不上传GitHub，可能含私人账户额度记录等本机信息。

另有先前归档`../Room1历史试作归档_20261028/`，继续保留。

恢复main中的某个历史实验时，在项目根目录执行，例如：

```powershell
git sparse-checkout add /docs/art/experiments/room1_pixel_cluster_r20/
```

需要临时恢复main全部历史源：`git sparse-checkout disable`。这只恢复当前main文件，不回退整个工程。重新精简前先检查本地新修改。

需要恢复本机独有旧资料时，从MANIFEST指定路径复制到一个新的检查目录，核对SHA后再决定是否引回项目；不要直接覆盖当前main。
