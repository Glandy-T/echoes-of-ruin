# Room 1 地面偏黄修正 r9

2026-10-27。用户否定r8地面沉积的黄色观感和不自然配色。原因是沉积亮部用了偏黄绿色的高亮灰，与原蓝灰地坪冲突。本轮只校正颜色，保留r8所有沉积／漏液的形状、位置和透明度；r8作为被指出配色问题的历史版本保存，不再当作颜色已通过。

[原光照下颜色对照](preview.html) · [7层／10层Aseprite](editable/) · [当前Blender源](room1_floor_palette_r9_packed.blend) · [颜色／遮罩核验](source/palette_check.json)

- 四个新增沉积层改用低饱和冷灰蓝，浅色峰值降低：例如舱角灰从RGB155/168/151改为121/137/145，浅边从174/184/163改为136/148/154。暗接触根保留，避免泛黄亮框。
- 原漏液1591个偏暖浅色像素改为140/157/165；漏液暗膜、渗染层及全部漏液alpha保持。四处漏液仍在P03/P06/P13/P18。
- 原地坪主面与基础材料三层RGB不改；20舱轮廓、四边沉积、所有十层alpha与r8逐像素一致。地面输出的颜色通道保持R≤G≤B，去除偏黄绿的色阶；该检查仅针对本候选，不是全项目色板规范。
- 模型、UV、墙面图、舱体、布局、灯带参数与曝光保持。新颜色图已参与配套1024样本烘焙，并另存打包Blender工程；不是靠全局色调、曝光或灯光把黄色盖掉。

F6运行`scenes/dev/room1_floor_palette_r9.tscn`，F切r8旧色／r9冷灰蓝；I切r8／r9配套光照，N颜色诊断，J回位，WASD移动。正式主入口不变。运行时需要场景Shader绑定当前PNG，裸GLB仍仅为保留UV2的几何载体。

预览分别展示旧配色、新色＋同一r8光照、新色＋新配套光照。全部实际Godot图1280×720，无截图提亮；近景和游戏相机在各组一致。颜色诊断总览另覆盖完整地坪和20舱，不作为正式照明效果。具体回退和源包检查见`quality_check.json`。

`source/build_floor.py`保留r8确定的轮廓算法，只替换颜色；`source/package_floor.lua`保存两份分层母版并重开导出；`source/check_palette.py`检查alpha和原主面不变、偏暖颜色消除。`scripts/dev/bake_room1_floor_palette_r9.py`生成配套工程／光照，`readback.py`可在没有独立raw文件时读取源内已打包的raw。日志、raw EXR和备份不上传。无新增AI／PixelLab调用。

本轮可供用户审查修色结果，不把技术核验或颜色通道条件当成用户最终美术认可。
