# 45° 主待机 D · 呼吸与重心

[上一版与这版同速播放](45/compare.gif) · [1×](45/breath_1x.gif) · [3×](45/breath_3x.gif) · [六帧并排](45/six_frames.png) · [Room 1 动图](45/room_native.gif) · [完整镜头](45/room_1.png)

从选定的 [r1 D 原图](../protagonist_idle_pose_45_r1/D/raw/01.png) 独立绘制六个姿势。人物开始吸气时，骨盆逐渐往画面右脚靠；左膝随大腿微屈。胸廓吸气时向前外侧展开，肩线随骨盆略微反斜，两只垂手跟随各自的肩。放松侧脚跟只在重心已经移过去以后卸力，前脚掌持续接地。呼气初段肩胸回落时，身体还靠在右脚上。

[制作脚本](animate.py) 用同一张三角网连接腰、胯、肩、四肢和脚底接地点。头与脸保持刚体位移，单独给几簇刘海尖和后发梢延迟。六帧仍为 600、500、500、300、500、400 毫秒。第一帧与 D 文件逐字节一致，面部色块、下摆底缘、右脚底和左前掌已逐帧核对。所有帧均从 D 取色，0 generations。

[Godot SpriteFrames](breathing.res) 已重载验证。Room 1 原机位采用首帧比例和固定脚底锚点渲染全部六帧。[拍摄脚本](room.gd) · [原比例预览脚本](room_preview.py)
