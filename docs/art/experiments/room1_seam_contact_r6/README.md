# Room 1 接缝旧化接触修正 r6

2026-10-27。用户指出所有黑色接缝与污渍之间夹着干净空边。本轮统一修正四面墙38条纹理接缝，保留r5原版，不改地面、舱体、模型、UV、布局或照明。

[前后对照](preview.html) · [逐像素检查](source/quality_check.json) · [分层母版](editable/)

## 原因与修正

r5的`protect_joint_cores()`实际保护了8px完整接缝轮廓，把旧化在该范围内全部清空，连两侧亮倒角也不允许接触。`seam_film()`又停在接缝外缘，导致暗膜与黑色芯之间固定留有干净亮条。图上看起来像污迹悬在旁边，并非模型裂缝或烘焙接头。

r6只保护中央2px密封芯，允许上下沿沉积与缝边旧膜覆盖两侧肩部；原先停在外侧的旧膜延伸到密封芯相邻像素。未有旧化的部分仍保留原倒角，不将整条缝旁强行涂黑。发光面保护规则不变。

四墙总共18975个像素改变，全部位于原接缝8px范围内、44–248行；黑色芯与灯罩像素精确保持。四份8层Aseprite重开导出与运行PNG逐像素一致。此规则适用于之后的同类旧化：保护真正需要保留的结构芯，不对整个轮廓挖出固定宽度的干净隔离带。

## 使用与验证

F6运行`scenes/dev/room1_seam_contact_r6.tscn`；默认修正。V切r5原接缝／r6修正；M仍比较墙地模式，N颜色诊断，J回位。主入口不变；r5继续保留。新场景继承r5，只替换四墙颜色图。

`capture.gd`输出同机位左中右前后对照、颜色诊断与恢复、前墙和转角技术图。另由`capture_baseline.gd`实际运行独立r5场景，确认V回退与当前r5左中右画面逐像素一致；本轮比较使用重新渲染的基线，不混用历史截图。N往返后修正版也逐像素一致。前墙技术图临时显示实体并恢复原剖切。截图均1280×720、原照明，无提亮。

`source/build_walls.py`生成32张源层；`source/package_walls.lua`打包4个母版，导出运行PNG后重新打开母版导出到`source/readback/`。`source/review.py`检查全部接缝芯、相邻旧膜接触、改变范围、灯罩和实际截图，生成预览。运行资产在`assets/art/room1_seam_contact_r6/`。本轮无AI调用；新固有色反射未重新烘焙。
