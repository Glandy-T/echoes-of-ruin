# Room 1 主门与自己舱体交互

在 Godot 打开 `scenes/dev/room1_door_sensor_review_r1.tscn`，按 F6。按 `0` 到门前，再用 WASD 靠近：测试芯片开启时，门板上会先出现约 1.5 秒临时扫描线，然后用约 3 秒滑开。U 切换测试芯片；离开后门延迟关闭，有人处于门口感应区域时保持打开。门、扫描效果和认证规则尚未最终定稿。

门后是黑色，人物不能走出房间。门开启后在门口按 E 使用出口；当前没有下一场景，所以只显示尚未准备的提示。`destination_scene` 是留给后续场景的配置，只有有效目标时才执行场景切换。

开场自动出现两句「あ……頭、痛い……。」「ここは……どこ？」；Enter 翻页，Esc 可关闭，结束后恢复操作。同一次游戏运行内再次进入不重复播放，新游戏重置后可再播放。

靠近 P12 按 E，可调查主角自己的休眠舱：原画面变暗，现有 128×48 屏幕贴图放大叠在画面上，不移动游戏镜头，叠层使用与 P12 屏幕相同的动态 NAME／SYS 内容和进度条，NAME 显示「グラン」。两句台词是「情報パネル……？」「グラン……私の名前、みたい。」；Enter 翻页，Esc 关闭，关闭后画面和移动恢复。屏幕断电时只显示屏幕关闭提示，不展示亮着的特写。其他舱和其他物件台词尚未加入。

运行 `scripts/dev/verify_room1_door_sensor_r1.gd`，检查开场台词、门、舱体台词、信息图叠层、镜头不移动、关电和退出对话，均通过。`capture.gd` 生成 `evidence/` 下的真实 Godot 截图。叠层用 `room1_pod_detail_overlay.gdshader` 复现 v8.1 屏幕的窄边显示和实时文字；没有改动源图或原舱体。旧门板仍是占位，扫描线是临时视觉提示，房间静态烘焙没有为动态门更新。正式主场景未切换。
