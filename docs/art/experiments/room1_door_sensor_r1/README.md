# Room 1 主门与自己舱体交互

在 Godot 打开 `scenes/dev/room1_door_sensor_review_r1.tscn`，按 F6。按 `0` 到门前，再用 WASD 靠近：测试芯片开启时，门板上会先出现约 1.5 秒临时扫描线，然后用约 3 秒滑开。U 切换测试芯片；离开后门延迟关闭，有人处于门口感应区域时保持打开。门、扫描效果和认证规则尚未最终定稿。

门后是黑色，人物不能走出房间。门开启后在门口按 E 使用出口；当前没有下一场景，所以只显示尚未准备的提示。`destination_scene` 是留给后续场景的配置，只有有效目标时才执行场景切换。

开场自动出现两句「あ……頭、痛い……。」「ここは……どこ？」；Enter 翻页，Esc 可关闭，结束后恢复操作。同一次游戏运行内再次进入不重复播放，新游戏重置后可再播放。

靠近 P12 按 E，可调查主角自己的休眠舱，显示「情報パネル……？」「グラン……私の名前、みたい。」；P12 屏幕的 NAME 显示「グラン」。之后可考虑在游戏画面上叠加信息面板等调查特写，不移动游戏镜头；当前尚无特写图。其他舱和其他物件台词尚未加入。Enter 翻页，Esc 关闭，显示对话时角色移动锁定。

运行 `scripts/dev/verify_room1_door_sensor_r1.gd`，检查开场台词与不重复播放、无芯片阻挡、扫描先于开门、慢速滑动、门板和碰撞同步、黑色门洞、不能走出、出口按键、门口防夹、离开自动关门、舱体台词及对话锁定，均通过。`capture.gd` 生成 `evidence/` 下的真实 Godot 截图。旧门板仍是占位，扫描线是临时视觉提示，房间静态烘焙没有为动态门更新。正式主场景未切换。
