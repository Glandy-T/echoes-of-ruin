# Room 1 主门与自己舱体交互

在 Godot 打开 `scenes/dev/room1_door_sensor_review_r1.tscn`，按 F6。按 `0` 到门前，再用 WASD 靠近：测试芯片开启时，门板上会先出现约 1.5 秒临时扫描线，然后用约 3 秒滑开。U 切换测试芯片；离开后门延迟关闭，有人处于门口感应区域时保持打开。门、扫描效果和认证规则尚未最终定稿。

门后是黑色，人物不能走出房间。门开启后在门口按 E 使用出口；当前没有下一场景，所以只显示尚未准备的提示。`destination_scene` 是留给后续场景的配置，只有有效目标时才执行场景切换。

靠近 P12 按 E，可调查主角自己的休眠舱，显示旧版已有的两句「これ……僕？」「見た目は、まあ普通か。」。旧版第三句涉及旧编号 4-14-04，与目前 P12 不对应，暂未使用。旧项目的开场自动独白尚未完成，没有另行编写；其他舱和其他物件台词尚未加入。Enter 翻页，Esc 关闭，显示对话时角色移动锁定。

运行 `scripts/dev/verify_room1_door_sensor_r1.gd`，检查无芯片阻挡、扫描先于开门、慢速滑动、门板和碰撞同步、黑色门洞、不能走出、出口按键、门口防夹、离开自动关门、舱体原文及对话锁定，均通过。`capture.gd` 生成 `evidence/` 下四张真实 Godot 截图。旧门板仍是占位，扫描线是临时视觉提示，房间静态烘焙没有为动态门更新。正式主场景未切换。
