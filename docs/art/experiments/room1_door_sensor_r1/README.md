# Room 1 主门与自己舱体交互

按 F5 从原有标题画面开始，进入当前 Room 1；从标题进入时隐藏审查提示和测试快捷键。标题「設定」支持对象名提示开关与窗口／全屏；房间内 Esc 打开暂停，可继续、打开设置或返回标题。对象名设置在标题与房间间共享，当前运行期间保留，不是磁盘存档。旧版游戏内音量和语言控件本来就是未接入的占位项，当前仍未实现，项目目前没有 BGM。`scripts/dev/verify_room1_title_flow.gd` 测试标题设置、开始、暂停、提示开关、继续、返回标题及新游戏重新播放开场；`capture_title_flow.gd` 生成菜单画面并在图形模式检查窗口／全屏切换。

在 Godot 打开 `scenes/dev/room1_door_sensor_review_r1.tscn`，按 F6。按 `0` 到门前，再用 WASD 靠近：测试芯片开启时，门板上会先出现约 1.5 秒临时扫描线，然后用约 3 秒滑开。U 切换测试芯片；离开后门延迟关闭，有人处于门口感应区域时保持打开。门、扫描效果和认证规则尚未最终定稿。

门后是黑色，人物不能走出房间。门开启后在门口按 E 使用出口；当前没有下一场景，所以只显示尚未准备的提示。`destination_scene` 是留给后续场景的配置，只有有效目标时才执行场景切换。

开场自动出现两句「あ……頭、痛い……。」「ここは……どこ？」；Enter 翻页，Esc 可关闭，结束后恢复操作。同一次游戏运行内再次进入不重复播放，新游戏重置后可再播放。

靠近 P12 按 E，可调查主角自己的休眠舱：原画面变暗，现有通用 128×48 屏幕贴图原样放大叠在画面上，不移动游戏镜头。原图及舱体屏幕的姓名、状态均为原来的空白占位；两句台词仍是「情報パネル……？」「グラン……私の名前、みたい。」，因此姓名暂未在画面上呈现。Enter 翻页，Esc 关闭，关闭后画面和移动恢复。屏幕断电时只显示屏幕关闭提示，不展示亮着的特写。其他舱和其他物件台词尚未加入。

运行 `scripts/dev/verify_room1_door_sensor_r1.gd`，检查开场台词、门、舱体台词、信息图叠层、镜头不移动、关电和退出对话，均通过。`capture.gd` 生成 `evidence/` 下的真实 Godot 截图。叠层直接使用现有通用贴图，未修改源图。旧门板仍是占位，扫描线是临时视觉提示，房间静态烘焙没有为动态门更新。正式主场景未切换。
