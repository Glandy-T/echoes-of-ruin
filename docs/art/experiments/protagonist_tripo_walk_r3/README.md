# 主角 · Tripo 分件到行走实测

同一套[平涂三视图](../protagonist_model_flats_v1/README.md)。前、人物右侧、后，左侧槽空。使用国内版 Studio 在同一份新资产上处理。R2 留作原样对照。Blender 仅回读、测量和按动作采样渲染。

| 阶段 | 结果 | 本次观察到的积分支出 |
|---|---|---:|
| H3.1 标准分部件，标准几何、无贴图 | 13 个网格、973628 三角面 | 45 |
| 重拓扑 P1.0 智能网格，三角面，目标 8000 | 9693 三角面 | 35 |
| 2K 临时测试贴图 | 国内 Studio 绑骨入口要求先生成贴图，用户授权这一步 | 10 |
| 类人自动绑定，两次 | 两份导出均有一套 41 骨的骨架 | 20 × 2 |
| 选择行走预设，导出时选择 1 个动作 | 两份 GLB 都含 walk，Blender 时间轴 0–56 | 未观察到额外扣点 |

余额 1500 → 1455 → 1420 → 1410 → 1390 → 1370。共 130 积分。以上是网页版实测。一次分件生成、一次智能低模，同一低模两次绑定；测试在第二次结束。实际 GLB 含骨架和动作，正式游戏资源未替换。

两轮迈步时都可看到脚边被拉成尖片，侧视第 2、4 张最明显。按同一走路动画相位，固定镜头方向和倍率，跟随人物位置截取 0、7、14、21、28、35、42、49 帧。测量每一帧蒙皮后网格边相对静止网格的长度，排除原长小于等于 0.002 的短边；两轮最大异常都在腿部 tripo_part_3。衣摆也会随迈步变形。数据支持腿部蒙皮异常，尚未逐顶点归责到某一根骨。当前结果可以验证动作管线，但不适合直接充当可玩主角。未尝试第三次。
