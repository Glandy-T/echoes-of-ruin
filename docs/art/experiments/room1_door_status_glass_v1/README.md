## 做法

1. **对准凹口**：r32 贴图里凹口内部是 11×6 个原生像素，换算到 1.37×2.30 m 的门叶上是 0.1346×0.0750 m，中心在 (+0.0061, 0.300)。发光块改为正好这个尺寸和位置，贴图里 1px 的暗边留作窗框。
2. **暗玻璃着色**：整窗都带状态色，先乘 0.82 的透光率，再按三级色阶由中心往外变暗：中心 100%、中圈 74%、最外一圈 50%。色阶按凹口自己的 11×6 原生像素格计算，每格只有一个颜色，和门面的像素画法一致。待机时是近黑的玻璃色。
3. 黄闪节奏、红、绿颜色和触发条件都沿用原来的门灯逻辑，只是换了显示方式。
