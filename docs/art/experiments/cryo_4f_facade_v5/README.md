# 4F 横移遮挡与门目标修正 v5

2026-11-04，针对用户两张实机图继续修正。入口仍是F6 `scenes/dev/cryo_4f_complete_v3.tscn`。[本轮实机与修前截图](preview.html)。本轮不制作门后灰色环境，不改变静态贴图或烘焙。

## 原因与修改

v4只验证了正对门的前后距离，并让门使用相机至人物中心的单独射线。横向站到门旁时，射线不再穿过门，门会恢复实体，但旁边墙体仍由宽探针保持半透明。用户两张截图暴露了这一漏检。

本轮把墙板、门板、门体与门楣映射到同一墙中心平面；平面位于相机与人物之间时，整面使用相同的42%不透明度。墙板的外饰偏移、门板的厚度不再使它们各自切换。相邻可见范围留有边缘余量，横移到门旁时不单独恢复门。碰撞和两侧原材质保留。

同时统一门的交互目标：当前可交互范围1.5m内选最近的一扇，走廊正中等距时优先Room1主门。提示、认证触发、主门认证范围和黑门洞穿越均使用这个选择结果。对门成为目标时，主门提示关闭，E只认证对门；即使主门仍开着也不会返回Room1。靠回主门后才显示其认证／穿越提示。各门仍按v4黄闪→红灯拒绝，电梯停运例外保持。

半透明前景后面仍存在Room1实体门与黑门洞；它们的黑色形状与前景有视差，透过前景看到这些黑色不代表前景门恢复实体。这里按用户此前要求保留双面黑门洞，灰色环境留待后续。
