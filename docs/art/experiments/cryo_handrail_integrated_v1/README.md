# 一体化护栏｜单段轮廓对比

用户认为现有扶手“好现代”，本轮按已同意的方向制作一段一体化护栏灰模，比较栏体、握持边和折返的关系。[本地并排图](preview.html) · [GitHub 并排图](preview.md)

**2026-11-15 用户认可 C 的整体造型**，反馈“可以，这个更舒服点看起来”。后续扶手以 C 的一体化栏体、内凹握持边和连续转角为造型基线，继续完善接合、净宽及像素表面。

原稿基线为 `1133379c9ba4330081a153424c369c4e180023f9`。A 是既有圆管竖杆样段，B 是既有折板样段，C 是本轮新形体。三款都取同一条 3.30 m 梯跑、1.90 m 高差和折返口，采用相同灰色、1280×720 画幅、机位及光照。

C 采用暂定 80 mm 厚的预制栏体，位于踏步边缘的梯井侧。结构厚度收进原有梯井空间。0.90 m 握持边与 1.10 m 栏顶沿用样段的高度，本轮把握持边做成栏体内的凹槽，下部留了手指回握的凹面。槽深暂试 67 mm、高 120 mm，主体按 1.10 m 模块分段，6 mm 接合缝有背衬，转角沿同一截面接续。这些新增尺寸都是可调整的造型试作值。

## 画面与使用

- `overview` 看单段整体轮廓，`grip` 看握持槽，`turn` 看折返截段。三种技术机位统一剖去遮挡的墙体。转角在梯井中心截断，便于对照。
- `hero` 使用现有楼梯游戏方向与纸片主角，补看体量和遮挡。它仍是单段审图，完整楼梯围护与墙侧握轨接续留待整合检查。
- 用 Godot 4.6.2 打开 `scenes/dev/cryo_handrail_integrated_v1.tscn`，按 F6。1／2／3 切 A／B／C，↑↓ 切机位。传入 `-- --capture` 可复现 12 张图。

[Blender 工程](model/handrail_integrated_v1.blend)保留三份独立可编辑样段，[GLB](../../../../assets/art/cryo_handrail_integrated_v1/)可分别导入。[构建脚本](model/build_sample.py)读取已发布审图工程，提取旧款并创建 C。本轮使用单色形体材质，PixelLab 新生成用量为 0。后续表面仍执行项目 PixelLab 与 Aseprite 工作流。

## 已查与待看

源模型逐对象检查闭合边、退化三角形和正体积，原始结果保存在[模型清单](model_manifest.json)。实际 Godot 截图逐组检查了相机、画幅、灰色和各光源的一致性，[运行记录](evidence/capture_record.json)可以读回。

C 的整体轮廓已获认可。80 mm 厚度、槽口尺度、底部厚实程度和材质身份仍需在接合与表面阶段核对。下一步按 C 完善完整通行净宽、墙侧握轨和双跑接合，像素贴图继续执行 PixelLab 与 Aseprite 工作流。
