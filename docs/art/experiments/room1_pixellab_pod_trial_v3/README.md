## Godot 导出（本轮新增）

`godot_export/pod_closed_v3.glb` 与 `godot_export/pod_open_v3.glb` 是给 Godot 4.6 的静态导入候选：前者取源工程 frame 1，后者取既有 frame 60 的 45°开盖终态。没有另导出动画 GLB，也没有猜测运行时的开闭控制。

- 两个 GLB 只含舱盖、壳、内衬、床垫与脚端屏幕的导出副本；没有展示地台、相机、灯光、动画控制 Empty 或已烘焙的灯光。
- 导出副本把 Blender 审图用的三阶 Emission 材质换成 glTF 兼容的 Principled Base Color 材质。原光照没有烘焙，Godot 的场景光照和像素化表现仍需单独配置。
- GLB 内嵌 v3 的七张 PNG。每个导出网格片只保留一张实际使用的 `TEXCOORD_0`；多材质舱盖／壳按表面拆成导出片，因此不会把 Blender 里第 3 张及之后的 UV 层误称为可由 glTF／Godot 自动保留。
- 实际 GLB sampler 为 `magFilter: 9728`（NEAREST）与 `minFilter: 9984`（NEAREST_MIPMAP_NEAREST）。导入 Godot 后仍应通过项目的 post-import 设置显式将 `BaseMaterial3D.texture_filter` 设为 `TEXTURE_FILTER_NEAREST`。
- [导出清单](godot_export/manifest.json) 记录模型数量、嵌入贴图、实际 sampler、UV0 检查和米制包围盒。导出脚本为 [export_godot.py](export_godot.py)，它只处理内存中的导出副本，不保存或改写 v3 Blender 工程。

## 相比 v1 的变化

v1 限制所有结构边缘与材质明暗，结果接近平色加几处斑点。本轮按参考研究中的分工组织表面：

| 表面 | 本轮表现 | 来源 |
|---|---|---|
| 舱盖 | 中央盖板、折面色带、接合处暗线与亮边、印刷编号、局部角部像素 | 项目底图 → PixelLab Pro → Aseprite 编号整理 |
| 长侧壳与底座 | 密封色带、外壳／结构底座分区、维护与编号区域、边缘局部像素变化 | 同上 |
| 端部 | 端面色阶、已有端部上的像素面板轮廓、01编号、下部结构色带 | 同上 |
| 内衬 | 深灰内壁、边缘压暗与收边 | 项目原创像素图 |
| 床垫 | 衬垫边缘、按行组织的折线／缝线色阶 | 项目原创像素图 |
| 头窗 | 深蓝灰玻璃色块、阶梯状反射带与亮暗边 | 项目原创像素图，原头窗几何不变 |
| 信息屏 | 空姓名栏、中性系统字段与静态状态条 | 项目原创像素图＋Aseprite 字形整理 |

图案全部在贴图中。没有把盖板、线、印刷、反射或屏幕信息另建成几何，也没有新增按钮、管道、设备或第二块玻璃。Pixel Canals 用作技法与画面质量参考；未上传、下载或复制其模型／贴图／截图。

本轮色板为象牙灰涂层、冷灰结构、深蓝灰密封／玻璃和克制青色屏幕。它只是当前候选，不锁定全项目配色。屏幕文字与条形图是静态审图版式，不代表已决定的语言、病理数据、休眠状态或交互UI。

## 实际生成与整理

**历史v2原图来源：**三次 PixelLab Web Creator **Pro AI edit**，输入各自的原创底图：128×256舱盖、256×80侧面、128×80端面，每次10次额度、合计30次。本轮v3沿用原结果整理，没有新生成、额外订阅、购买或升级。

本轮允许结构边缘、受控接缝、角部明暗和有位置依据的微小变化；同时限制额外部件、反复网格、霓虹和大量锈蚀。PixelLab 原始图保存在 `raw/`；精确编号在 Aseprite 的独立图层绘制，不把AI乱码当成最终文字。可编辑文件保留原始表面、编号整理与隐藏底图层。

Chrome 下载曾停留在 `.tmp` 文件名；完整PNG字节从对应下载文件复制到本目录，尺寸分别对应三张图。之后的Aseprite复合导出与原图分开保存。没有清理下载目录或通过隐藏网页接口取得图片。

Aseprite 批处理时已安装的 PixelLab 插件会报告 `handle-pose.lua` 对话框警告；本轮七份分层源文件与PNG实际保存成功。没有修改插件配置，**也没有将批处理整理宣称为通过 Aseprite PixelLab 插件联网生成**。

## 模型与 UV

源：`../room1_pod_reference_v4_1/room1_pod_reference_v4_1.blend`。四个组件沿用：固定壳、整片盖、床面、脚端屏幕。

- 网格顶点、拓扑、组件位置、尺寸、开盖关键帧和45°终点沿用原件。
- 原材质槽与 `UV_PAINT_candidate` 留在工程中；只追加本轮材质与试验UV。
- 舱盖／头窗／内衬／床垫采用本地XY映射；外壳按原面法线区分长侧面与端面；屏幕沿用已有0–1UV。
- 侧壳两侧分别处理UV方向，保留同一长侧壳表面方向；v3 已删除该图上的重复 `UNIT 01` 字样。
- 外部三个平面图采用约111.3 texels/m的平面尺度。部分斜面、内壁与床垫纵向密度不同，仍需后续正式UV密度审查；这不是项目统一规格。
- 当前固定壳顶面按位置选侧面／端面颜色区，转角投影有局部断线和拉伸风险。正式母版可再调整UV岛或专用顶面色带；本轮没有更改几何来掩盖映射问题。

## 材质、镜头与像素显示对照

1. **原照明版**：sRGB Base Color、Closest采样、粗糙Principled材质，Camera和灯光沿用原件。用于看清贴图自身的贡献。
2. **受控色阶版**：同贴图、同Camera，基于原面法线方向使用1.00／0.78／0.57三档亮度，通过Emission输出减少连续3D明暗。原灯光未编辑。
3. **原生像素显示示例**：720×500渲染，以最近邻放大到1440×1000；原图一并保留。常规对照为1440×1000。这里只比较采样观感，不修改Godot Viewport或锁定游戏画布。

三档材质是本项目自制的 **Blender审图方案**，不声称 Pixel Canals 使用了同一 Shader，也没有证明已经在Godot实现。玻璃目前通过不透明颜色与反射色块表达，物理透明、动态反射、发光及动态屏幕不在本轮范围。

## 复现

1. Python + Pillow运行 `source/prepare_guides.py` 可重建原创底图；保留既有 `raw/` 输出即可复现本次AI结果，重新生成不会保证一致。
2. 四张辅助底图见 `source/auxiliary/`。Aseprite批处理运行 `source/finish_maps.lua`，传入 `root` 为本目录的绝对路径，生成七份 v3 分层工程与 `textures/` 导出。
3. Blender 5.0.1后台运行 `apply_full_textures.py -- --render`，生成 v3 工程、三张审图与 `structural_readback.json`。源图已打包，无需运行脚本即可打开 `.blend`。
4. Python运行 `source/package_review.py`，生成最近邻2×展示图与图像文件清单。
