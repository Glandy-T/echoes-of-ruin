# Room 1 全墙细节推广 r24

2026-10-30。用户认可r23局部A/B的细节程度，并明确要求四墙及所有差分保持同等完成度，不再出现几乎空白的墙板。

本轮以r23原生256px的细节密度为依据：接缝／灯槽／墙脚有成组沉积、细碎边缘与逐渐变淡的过渡，完整大面继续保留。差分改变痕迹的位置、形状与重心，保持相近的丰富度。Pixel Canals继续作为整体技法硬参考；其NoAI图片／模型／贴图未提交生成服务。

## 制作与范围

- 复用用户认可的r23 A/B原图，新增六组PixelLab双墙板（C–H），共8组独立原图、16个不同半板；另外单独返修门洞所在宽墙板。
- 所有新图由PixelLab官方 `POST /v2/inpaint-v3` 在原生256×256编辑。只输入项目自己的PixelLab墙图与保护遮罩，不缩小放大、不翻转冒充新差分、不手绘或程序生成做旧。
- 四墙全铺设新的材料层，白色可编辑区完整替换；黑色结构保护区与既有灯面逐像素保持r22。旧稀疏材质不作为半透明底层与新图混合。
- 同墙不重复同一个半板；相邻不使用同一双板原图，正对墙与四角避免相同分配。裁到房间边缘的墙板也要在实际镜头检查。
- 地坪、20个舱体、门、灯带位置/外观/功率、模型、UV、碰撞、布局、游戏相机与原始GI均保持。仅四墙颜色图变化，不重新设计其他资产。

生成提示、原创输入、遮罩、原始输出、真实任务ID/用量保留。`source/material_density_screen.json`只辅助定位可能较弱的单块半板，不作为自动美术批准；原生16块、四墙铺设、门洞周边及实际游戏镜头需要逐一观察。

## 拒用与门洞遮罩修正

初版G/H和门洞图出现过大的剥落／枝状痕迹，已拒用，另用PixelLab从认可的项目导图返修。它们没有因“更密”就被接受。原始输出与拒用原因保留在 `raw/`、`source/rejected_outputs.json`，最终选择见 `source/selection.json`。

另查到r13旧门洞遮罩仅开放两侧窄带，遗漏实际开口旁的一部分可见墙面；继续复用会残留r22稀疏条带。新导图按现有1.4×2.4m开口、原80px/m世界映射标明未使用的开口区域，黑遮罩保护该区域，白遮罩覆盖全部真实可见墙肩。PixelLab最终 `portal_opening` 绘制对应材料，导图的深色孔标记不进入最终贴图。模型／开口／门本体不改，见 `source/portal_mask_scope.json`。

实际新增11次成功PixelLab请求、共110 generations（含拒用与返修）；另复用r23的2份已认可原图，不把技术裁切／铺设算成新AI调用。账户余额及账单文件只在本地核对，不上传公共交付。

## 使用与编辑

独立场景 `scenes/dev/room1_wall_detail_full_r24.tscn`（F6），1为r22旧墙、2为r24全墙，其他场景材料在两组中都为r22。O开关P12，H说明；正式入口不自动切换。

- 运行颜色图：`assets/art/room1_wall_detail_full_r24/wall_{left,right,front,rear}.png`。
- 四墙可编辑母版：本目录 `editable/`。
- 完整材质版Blender：`room1_wall_detail_full_r24.blend`，沿用r22几何/UV，只重绑四墙颜色图。实际游戏效果以Godot截图为准。
- 同机位对比：`preview.html`。若文件预览不能加载，运行 `python source/serve_preview.py` 后在浏览器看本机地址。

本轮沿用r19既有原始/降噪GI作材料对照，没有重烘新颜色的间接反弹；不把本轮称为新配套光照交付。技术检查与制作者审图不替代用户对整室的最终审查。

## 交付核验

- 216份既有文件保持；素材检查245项通过，四份Aseprite回读与最终PNG逐像素一致。
- Blender源重开后131对象的几何／UV／变换／灯／相机保持；四个墙文件对应7个既有图像数据块全部重绑，250个外部图缺失0、绝对路径0。
- 运行不变性3,977项通过，开／闭两种状态只切四墙贴图；20舱、地坪、门、原GI与Shader不变。
- 69张1280×720实际GPU图，237项截图检查通过，旧墙复位逐像素一致。正常游戏镜头覆盖前后两排左中右，另有门洞／四角、真正显示的前墙、24张A/B无遮挡分段巡检，以及4张raw/denoised门楣／后墙角对照。
- 前后墙各4段、左右墙各2段重叠巡检，逐块查看了全部墙板的灯槽至下沿。舱体与显示代理只在技术扫描时临时隐藏，之后恢复；地面保留旧烘焙投影，切面外灰色背景不是墙面材质。正常游戏图不替换为这种诊断状态。

制作者逐一查看16个半板和四墙各段后，未发现r22式接近空白的差分；门洞旁的漏改条带已被新mask覆盖。痕迹分布仍有强弱与形状变化，完整大面保持。实际风格取舍由用户对整室继续审查。
