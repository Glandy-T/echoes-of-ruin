## 实际改动

来源是[v1原始OBJ](../protagonist_tripo_body_v1/README.md)，保留其四边面；只在工作副本应用Y-up转换和精确重合点焊接。焊接后的OBJ也有28对脚趾交叉，说明不是GLB三角化独有的假象。

第一种删除脚趾后直接封口的方案虽无自交，但实际审图像截断方块，已拒绝。最终在足部低于z=.070的区域以x=.026作真正平面截环，沿原脚长补x=.045／.058／.064三个收束截面，形成简化、圆钝的脚趾包络。没有逐个保留细小脚趾；趾缝与皮肤细节留待之后像素贴图确认，不把当前脚形当作最终美术批准。

前脚包络以外2762个表面坐标的多重集完全一致，脸、人体比例、胳膊和腿没有重塑。原始corner normals在任何焊接前捕获，按未改面的坐标匹配恢复；最大法线向量回读差约.0072，不宣称浮点存储逐位相同。已实际看正／侧／背／斜视与脚部前侧／侧面同机位图，确认此前连带改变脸和手腕明暗的问题已修正。

## 临时骨架已经做到什么

`body_v2_motion_probe.blend` 为独立诊断副本：19骨骼，身体2950点；Blender heat自动权重后保留最多4项并归一化，无漏绑定点，最大权重和偏差4.47e-8。它有1／20／40／60帧四个关键姿势：原A姿势、抬臂、弯肘、迈步。正／侧／斜视均已渲染，各帧均为有限坐标且真非邻面交叉为0。母版保持没有骨架／权重。

这不是生产步态或运动系统：没有手指骨、IK、重心、足底落地、根运动或Godot播放验证。自动权重的腋下、肩肘、髋膝仍需结合衣物精修；抬臂等处个别边长变化超过2倍，应按[诊断记录](source/motion_probe_report.json)审看，不以零交叉宣告变形已合格。当前仍用原始约1单位身高，未锁游戏内米制身高。

## 后续顺序与边界

白袍v2外形按用户本轮意见保留；它仍有272对相交和2条非流形边，需要不改变轮廓的拓扑整理。下一步统一身体与衣服的身高、关节和A姿势，用同一骨架试穿，再加入现有有限体块头发。动作收敛后再固定UV和PixelLab像素贴图。没有动Room1、4F、光照、镜头或当前游戏角色；本轮没有新增Tripo／PixelLab生成或费用。
