# 主角灰模 v2：剩余细发、发尾与部件关系

2026-11-06。接续用户审看后的[国内版清理v1](../protagonist_tripo_cn_cleanup_v1/README.md)，原始Tripo导出与v1均保留。只整理不必要的细条、局部发尾及后续UV所需的部件关系，保留现有头型、发量、长度、面部、白袍、身体、姿势与尺度。

## 本轮边界

细发与主体相接时，须根据实际面与连接关系选择，不能只按组件大小或包围盒删除。删除细条造成的局部缺面需要补回，不能用大面积剪切、整体体素重建或替换头部掩盖问题。发尾只整理细碎尖齿，保持当前长发轮廓。

非头发部分保留原有坐标与表面明暗；当前不生成新参考、不消耗Tripo或PixelLab额度、不制作最终UV、贴图、骨架、动画，也不替换游戏里的占位主角。

## 实际结果

- 删除经前后审图确认的左侧14面小卷丝；保留右后的宽发束。试删右侧14面会截断原有宽发束，最终没有采用该删除集，不能按洋红色诊断图误删。
- 仅平顺头发最下方一小段的细碎尖齿：135个头发顶点沿本地Y轴小幅调整，最大0.003原始单位。X／Z不变，头发最高、最低位置不变；这不是最终游戏米制尺度。调整以固定的一圈邻点高度为依据，并逐点缩小可能翻面或严重压瘪三角面的位移；保留四边面的两种对角线均参与检查。仍有少量较宽发尾，未把下沿削成直线。
- 非头发部分的所有面、坐标和角点法线保持；全部保留面的原始自定义法线沿用，避免局部调整出现新的黑色三角片。最终为2515顶点、2582个多边面，GLB正常三角化。
- 建立`Hair_Main`、`Robe`、`Head_Neck`、`Hands`、`Feet`五个可选编辑组。它们是顶点组，不是已完成的可动画分件；微小残留组件保留原始面ID，未强行归类或顺手删除。

同机位实际图中，左侧游离卷丝消失，发尾细齿减少；正面、斜视的人体与衣服观感保留。v1和Tripo原始源的哈希均未变。实际改动、退让比例及保留ID见`source/build_report.json`；文件与非头发保护检查见`source/delivery_validation.json`。这些结果不代表用户最终美术认可。

## UV之前仍需要做的结构工作

头发仍保留少量较宽的起伏发束，原始网格也仍有开放边界与非流形位置，本轮没有把它宣称为最终干净拓扑。白袍、头颈、手脚在空间上可以辨认，但袖口、下摆及内侧厚度不能仅凭连通组件判定已经正确；诊断中只能确认白袍领口的大边界符合预期。下步应根据实际造型整理衣服开口／内侧和必要的腿部代理，再做可变形拓扑与UV试展。当前没有UV、骨架、权重或实机角色替换。
