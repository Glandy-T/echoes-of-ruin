# 45° 主待机站姿候选

[1× 三方对照](compare_1x.png) · [3× 三方对照](compare_3x.png)

从左到右为旧待机首帧、定稿 45° 和 A、B、C、D 四个种子。旧稿取 384×128 图集左起第一个 96×128 单元。展示时按脚底对齐，保留各图原有像素大小。候选直接采用 PixelLab 整帧原件。

| 候选 | 种子 | 观感 |
| --- | ---: | --- |
| [A](A/raw/01.png) | 6112531 | 双手相叠，被握的手朝下，比 B 易分辨。眼鼻较定稿简化。 |
| [B](B/raw/01.png) | 6112547 | 手收得最紧，原尺寸容易读成一块。 |
| [C](C/raw/01.png) | 6112591 | 视线略低，眼睑和嘴角最接近定稿。两腕的方向能分开，小臂上的握点仍不够明确。 |
| [D](D/raw/01.png) | 6112613 | 垂臂备选。手与裙身分开，轮廓最清楚，站姿较接近设定图。 |

C 的上半身最有放松中带一点拘谨的感觉。四张的脚位有前后和左右差别，宽裙下的单腿承重都偏含蓄。站姿待选。

[生成脚本](pose.py) 中保留了按定稿 45° 描定的 18 点初始骨架、握臂骨架和垂臂骨架。以人物左腿（画面右侧）承重，同侧髋向外 2 px、上提 2 px，另一只脚向外 3 px、向前 2 px。肩线反斜，鼻尖向镜头方向挪 2 px 并降低 1 px。每个种子重复同一骨架三帧，从中选取一张。四次请求合计 8 generations，按首尾余额差计算。[对照图脚本](review.py)
