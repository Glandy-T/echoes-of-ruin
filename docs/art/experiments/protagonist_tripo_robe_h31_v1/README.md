## 实际结果

- 外形基本保留圆领、宽长袖和长袍；比原v2更平滑、略直长。只是观察判断，不是尺寸一致或用户新稿认可。
- 原始OBJ有3870顶点、3853多边形（3851四边面＋2三角面）、7704三角面。网页报3864顶点；不把网页导出格式差异当作网格完全相同。
- 本轮精确非相邻三角面检查未检出真自交，亦无非流形边、退化面或游离顶点。但有4个连通块：3850＋14＋3＋3顶点，后3个是小型脱离碎片。正面／侧面可见黑方片和浅色多边形不是贴图变化；检查图采用统一灰色。
- **功能开口仍不合格。** 下摆中央9条向上探针全部撞到低位内部封挡面，位置约为袍高的12%；仰视的“凹进去”不等于内部贯通。领口也可见浅凹封面。袖口有局部孔口证据，但不能推断整件可穿、适配身体或能正常变形。
- 原始下载和已认可旧模型SHA-256检查前后不变。没有焊点、重拓扑、删片、封孔、权重或新贴图，问题原样保留以便判断。

因此本次重新生成**没有直接得到合格衣物**。小碎片属于可能有限清理的问题，但清理碎片不解决内部封挡和运动拓扑。不能只删掉黑方片就宣布修好，也不继续无目标抽卡。
