# 45° 主待机 D · 两帧呼吸

[1× 循环](45/breath_1x.gif) · [3× 循环](45/breath_3x.gif) · [Room 1 实拍动图（原比例裁切）](45/room_native.gif) · [吸满全景](45/room_01.png) · [呼出全景](45/room_02.png)

吸满 1.2 秒，[首帧](45/01.png) 直接复制自 [r1 D](../protagonist_idle_pose_45_r1/D/raw/01.png)。呼出 1.6 秒，[第二帧](45/02.png) 删除 y=38，顶部补一行透明。以画布顶部为 y=0，胸口 y=34～52 中，y=38 和上一行只有 3 个像素不同，是唯一最小值。两态合计 2.8 秒，本轮 0 generations。

| 独立核对项 | 结果 |
| --- | --- |
| 首帧文件与 r1 D | 字节完全相同 |
| 呼出图与从首帧重建的图 | 0 个 RGBA 像素不同 |
| 呼出图 y=39～127 与首帧同坐标 | 0 个 RGBA 像素不同 |
| 呼出图与顾问 B | 0 个 RGBA 像素不同 |
| 1×／3× GIF 解码后与相应底色上的原图 | 两帧均为 0 个像素不同 |
| 两份预览及 Room 1 动图的帧数、时长和循环 | 2 帧，1200／1600 ms，无限循环 |

[生成脚本](build.py) 用矩形复制制作第二帧。[核对脚本](verify.py) 单独用数组删除指定行，再在顶部拼透明行，逐像素比较全部 RGBA 通道与导出的 PNG，发现多余改动即报错。[完整核对记录](verification.json)

[Godot 拍摄脚本](room.gd) 生成并重载 [SpriteFrames](breathing.res)，验证其图像、逐帧时长，然后在 Room 1 五向站姿审图机位拍下两个状态，使用同一比例与脚底锚点。游戏镜头下头肩轻微沉落；3× 可辨两态切换。
