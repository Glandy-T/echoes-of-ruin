# Room 1 室内光源试排 r1 — 2026-10-14

用户指出：左墙外观异常；原灯带太亮并像稀疏灯泡；房间另有休眠舱玻璃窗透出的光与屏幕荧光，但许多舱已故障，不应全部点亮。用户选本轮先试3亮、其余熄灭，编号可调整。

## 查看与调整

打开 `scenes/dev/room1_lighting_test_r1.tscn`，F6运行。WASD移动；1～9检查中央、四边／四角；R复位、T标记、H说明；**L灯带、G舱窗、B屏幕**可独立开关对比。

根节点导出 `window_lit_pods`、`screen_lit_pods`，默认均为 P02/P12/P17。可分别调整列表后F6试排；编号和3亮17暗都是照明候选，不是确认的故事／故障分布，也没有把故障具体原因编入设定。其他舱的窗后光、屏幕发光与局部投光关闭，屏幕底色同时压暗。

## 左墙修正

实际GLB左墙内表面的UV是U≈-0.521978～0.478022、V=0.5～1.5，超界钳制导致下半面重复采样深色保护带。测试场景为该内表面增加UV偏移 `(4.75/9.1, -0.5)`，映射恢复0～1；颜色与发光图使用同一修正。

这次修正在Godot测试材质中实现，原GLB、Blender与Aseprite文件未覆盖。后续应把正确世界坐标映射回写源工程／导出流程，旧r1/r2仍保留异常左墙以供比较，不宣称所有源资产已修复。

## 连续灯带

旧8个稀疏点光与外部检查用方向光停用。房间保留前墙／屋顶只投影和侧墙显示，镜头边界沿用r2。

`room1_continuous_strip.gdshader` 用四条连续边界线段计算表面距灯带的衰减，作为墙地与舱体的低亮填光；灯带本身使用原发光遮罩，候选表面能量0.38，原导出自发光0.65。填光强度0.24，基础环境光0.12。颜色仍沿用淡灰蓝白。

这是**连续线光的视觉近似**：通过材质EMISSION加入受控填光，避免GL Compatibility对单网格局部灯数量的限制及稀疏灯泡亮斑。它不是面积光、光线追踪、GI或带真实遮挡的线光；不自动产生舱体遮住灯带后的动态阴影。连续灯带的最终投光／阴影方案仍待审。

## 舱窗与屏幕

- 原玻璃网格沿用，独立材质使用Alpha Depth Prepass、alpha0.35、roughness0.22，保留原像素反射贴图；玻璃本身不发光。
- 窗后新增临时发光衬面，使用原窗网格的副本下移0.025m，近似舱内柔光；亮舱才显示，停机舱隐藏。不是主角模型、内部设备或已确认产品结构，也不是玻璃折射／焦散模拟。
- 窗旁局部Omni投光：能量0.08、范围1.6m、衰减2.5、开启阴影，关闭额外镜面高光；光源位置是透窗光的近似，不代表真实灯泡安装位置。
- 屏幕沿用原像素图，发光按贴图乘算，能量0.45；小范围投光能量0.08、范围0.75m、开启阴影。字形／状态条仍为静态占位。
- 每个舱的玻璃、衬面和屏幕材质独立，避免修改共享GLB材质后20舱一起亮。舱体普通表面共享连续填光材质以节省资源。

窗后投光目前仍有局部光池，玻璃的透明度、反射观感、屏幕亮度与环境整体明暗均需用户审图；不把材质属性设置视为美术验收。没有新增玩法、碰撞或主角物理。
