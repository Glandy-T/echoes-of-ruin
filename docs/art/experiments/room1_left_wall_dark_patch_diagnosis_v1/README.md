# 左墙下沿黑块：来源已定位，尚未修复

2026-10-27。用户表示本轮原生贴图看着还行，但指出新旧对照中左墙下沿一直有一块不合理的黑色。**该问题来自旧光照烘焙，不是这轮墙面材质设计。** 本目录仅保存诊断，不修改游戏模型、UV或光照图。

## UV2几何证据

对当前使用的 `assets/art/room1_open_hero_bake_r1/room1_baked_uv2_r3.glb` 读取 `TEXCOORD_1`（Godot UV2），把其他所有三角形与左墙内表面的UV矩形做裁剪、计算正面积重叠。

左墙内表面 UV2 面积约 **0.006163112**；有四个舱体侧壳的UV三角形落入其内部，每个重叠面积约 **0.00003323**：

- `Bake_P02_pod_v3_shell_side`
- `Bake_P11_pod_v3_shell_side`
- `Bake_P13_pod_v3_shell_side`
- `Bake_P20_pod_v3_shell_side`

数值见 `uv2_overlap.json`。这些对象共用同一张烘焙光照图，正面积重叠使其光照数据不能与左墙独立保存；这与展开图中的舱壳条纹及通道隔离结果吻合。**属于光照UV排布／制作问题，不是引擎限制，也不应当作自然阴影保留。**

## 后续修复对象

应修复共享光照图中的 UV2 排布与岛间余量，再生成匹配新UV的光照图／运行网格；检查的不仅是颜色UV0。前一轮左墙r4仅修过UV0，明确保留UV2，因此没有消除这次发现的UV2重叠。

不能通过重画墙面、去掉正常阴影、提高环境光或把旧EXR继续配给新UV来掩盖问题。原生墙地小样可以保留；当前需要处理的是其继承的烘焙基线。
