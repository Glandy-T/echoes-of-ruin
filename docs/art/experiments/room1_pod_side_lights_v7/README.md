# P12 舱内两侧灯管 v7

2026-10-27，单舱照明候选，待用户审图。用户要求取消中央光球，改为内部两侧灯管；之前未交付的v6调暗点光方案已停止，本轮不再沿用该点光。

## 效果与运行

[开合／透光对照页](preview.html)。Godot运行 `scenes/dev/room1_pod_side_lights_v7.tscn`，F6。O开／关盖，U两侧灯管开关，G舱内灯，T玻璃显隐，J回位，WASD移动。

两条灯管固定在壳体内部左右长边、舱口唇边下方；随开盖保持原位，不安装在舱盖上。每条发光面长1.70m、高22mm，中心位于舱局部 `x=±0.447m, y=0.31m, z=0`。窄暗色保护壳贴着原内壁。发光为柔和偏冷白，床面保留灰蓝材料与分段线，不靠大块蓝白自发光覆盖床面。

## 技术实现

- 可见灯管及壳：独立可编辑Godot组件 `scenes/dev/room1_pod_inner_tubes_v7.tscn`，四个BoxMesh；两种静态姿态各挂一份，实际只显示当前姿态。
- 灯管表面与床面受光分开：表面Shader控制低亮度扩散罩；内腔Shader在两条灯管实际位置作分布式线光采样，沿全长均匀分布，而非把中央光斑拉长。
- P12原Omni代理已关闭，`energy=0`、`visible=false`。旧头部点光距离衰减分支不在新内腔fragment中运行；没有保留一个隐藏的中央光源。
- 玻璃沿用v4透明Shader与原像素反光，玻璃没有自发光。P02/P17、屏幕发光、墙面灯带、环境底光、曝光、模型／贴图／UV2均保持。
- v5两姿态局部光照及原r9房间GI继续复用。本轮两侧灯的局部受光为运行时近似，没有声称新整室路径追踪烘焙或完整新碰撞／开盖动画。

**灯管目前是Godot组件试装，尚未合并进Blender／GLB母版。** 现有舱体可编辑源及八份像素母版仍在v4实验，实际房间UV2／打包Blender仍在v5。以后定案合并时按本组件位置、长度与发光面方向同步，不能只导出裸旧GLB就称包含本灯管方案。

## 实际检查

13张实际Godot GL Compatibility截图均1280×720，无截图提亮。开盖时光沿长边分布，床面分段及明暗能读出；闭合头窗能透见真实床面与内腔边缘。不同角度中一侧灯管可能被舱盖或舱口遮挡，这属于实际几何遮挡，不把单图只见一侧误认为只装了一条。

同机位床面固定区域 `x440–560,y370–410` 对照：原v5点光的蓝白像素2910个，v7为0个；这只是该区域的像素诊断，不是全屏或色彩验收标准。灯管开关与玻璃显隐／内腔灯／反光控制均有效，灯管和玻璃恢复图均逐像素还原。原P12代理关闭，P02/P17仍为0.16，环境底光0.025，灯带代理数仍0。完整读回在 `evidence/runtime_readback.json` 和 `source/quality_check.json`。

只有P12改为本方案，其余19舱不批量替换。地面仍为此前搁置的r9，闭合盖对周围地面的全室静态投影仍沿用v5已说明的限制。没有修改房间结构或全项目像素参数，没有新AI／PixelLab调用。
