## 本轮处理

- 地面：全室统一蓝灰连续地坪，复用128×128的原创材料像素图，以3.2m镜像采样衔接，保持低对比连贯块状层次。默认材料变化强度0.6；轻微压暗仅靠真实房间周界，不在每块重复单元的边缘画线。没有十字色带、砖缝、箭头、随机脏污或额外接触事件。
- 墙面：保留现有房间级低对比主面，不把小样斑块满铺成脏墙；新像素处理集中在真实墙角、墙脚、门洞附近。默认控制值0.5，实际主面混合约4%、交界处最多25%，另有极弱的交界收口色差。主体仍简洁；颜色围绕原暖灰方向。
- 灯槽、发光面及墙脚保护带直接保留r4结构与映射。原生像素PNG／Aseprite、GLB／UV2、光照HDR、布局、门、20舱及人物均保持。

新增层的3.2m／128px约40texels/m只是本候选采样值。原结构和主面基底沿用原映射；不是全项目统一密度。镜像保证单元边缘连续，但具有6.4m周期；它仍是大面材质试验，不宣称最终独立无重复贴图。脚本Inspector可调墙／地强度；`04_stronger_variation.png`保留更高强度对照。

## 运行与检查

仅新建继承场景、材料脚本和Shader。`room1_surface_full_room_r1.gd`接入地板顶面及六个墙面／门楣内表面，共7份既有材质；底面／侧壳不覆盖。颜色按世界位置采样，模型UV0／UV2均未修改；最近邻、1280×720、原游戏镜头、r4光照及人物阴影保留。

`evidence/capture_record.json`记录七处实际绑定，连续发光模式为1、归一化参数5.3333，光照路径明确指向r4。三处游戏机位各有四模式对照；另有13处全室检查，包括真正显示的前墙、门洞及覆盖全部20舱的总览。审图位置在通道内，技术相机不写入游戏场景。

父代理及独立审图检查过最终截图，未发现新增成片重复脏斑、黑块、三角光照切割或灯带接头。技术前墙近景仍有现有极低对比色调变化，不能据此声称场景完全纯色或已最终批准。图案强度、精细度和重复感仍由用户审图决定。

**这轮只比较固有色；新的材质间接反射未重烘焙。** 保留同一r4照明是为了比较材料。确定候选后，若作为正式资产，再整理对应源贴图／映射并配套更新反射解算，不能把本轮Shader试验当作新的烘焙GLB交付。
