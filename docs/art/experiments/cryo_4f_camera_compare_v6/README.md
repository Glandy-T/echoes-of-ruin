# 四楼镜头与前侧门墙显现对比 v6

2026-11-04。根据用户最新澄清独立制作：相机仍在前侧墙外，通过前移、放大构图或组合减少多余空房画面；前侧墙门平时隐藏，接近才整段渐显、离开渐隐，比较距离和门前区域触发。**不使用围绕人物挖洞消隐，不选定最终方案。**

F6入口：`scenes/dev/cryo_4f_camera_compare_v6.tscn`。[实机、运动与测量](preview.html)。原F5、v5及其F6入口保持。

## 操作

- 从Room1开始，正常E认证开门、第二次E出门；也可按F8直接到走廊，Home回室内。室内与连接区保持原镜头，镜头方案只在八条水平走廊生效。
- 1–5：A原构图、B镜头前移、C缩小视角、D适度组合、E更近构图。切换保持玩家位置。
- T：沿墙距离／门前区域。R：50%半显／100%实体对照。F7：自动／强制隐藏／强制显现，HUD显示当前状态。
- F11整层俯视、F12技术切区，F9灯带、F10 raw／降噪继续沿用。E的门禁权限、黄闪红拒绝、主门黑屏穿越保持。
- 默认A、距离触发和50%只是第一组测试状态；100%会挡住人物，保留作为对照，不代表已选定默认成品。

## 镜头比较

| 方案 | 相机到玩家的水平距离 | 水平FOV | 相机高度 | 用途 |
|---|---:|---:|---:|---|
| A | 8m | 50° | 2.2m | 原构图基准 |
| B | 6m | 50° | 2.2m | 前移，俯角随同一注视点增大 |
| C | 8m | 38.5° | 2.2m | 不移动相机，缩小视角放大 |
| D | 7m | 44° | 2.2m | 适度前移加缩小视角 |
| E | 4m | 50° | 2.2m | 更紧的构图，检验比例及环境可见范围 |

B/C/D放大程度接近，用于比较不同透视；不是把每种方案做到相同距离。相机Z受前侧墙外表面与0.35m余量约束，所有方案均不越过前侧墙。室内恢复原8m／50°镜头；总览仍是原正交技术镜头。

图像测量使用同一个走廊中线点x=16m、z=-10.7m，前墙隐藏时测量地坪前边界之外的下方空白；这不是整层所有点的空白比例。人物实际像素高度由固定姿态“有人物／隐藏人物”图对读回，区别于1.65m比例标记的理论投影高度。完整数值见`comparison_analysis.json`。

## 墙门显现与建筑边界

- 32组前侧房间门墙，以冻结的房间左右边界（约21m）为完整段，墙板、门板和门楣一起显现。共享同一显隐状态，跨房间边界留0.4m释放余量。
- 不新增美术颜色：复用v3接收网格、UV0／UV2、r24墙、r26地坪、r30门及对应HDR。新增显示实例只按建筑边界切分原表面，不围绕人物裁洞。
- 当前走廊前侧的原壳体和背面墙用完整平面在渲染中隐藏，显现时只绘一层已有走廊面材质，避免墙面和灰色背壳重复叠加。相机仍位于墙外。物理网格、碰撞与静态烘焙受光不变。
- 前侧状态窗跟随整段显隐，原门禁状态机驱动颜色；认证中的门在已有交互范围内保持可见。门后灰色环境仍是既有占位，未制作其他房间室内。
- 连接廊、楼梯及室内不套用这套前墙规则，继续既有v5显示方式。上下楼梯与公共区专用镜头不在本次比较范围。

## 两种触发规则

| 规则 | 进入 | 保持／释放 |
|---|---|---|
| 沿墙距离 | 在相应房间段内，距前墙中心平面≤1.15m | 距离>1.35m后等待0.20s，再渐隐 |
| 门前区域 | 上述距离条件，且距门中心左右≤1.2m | 左右>1.5m或距离>1.35m后等待0.20s，再渐隐 |

显现和隐去各约0.28s。进入／退出阈值不同，避免人物在同一边界来回微动时反复开关。50%与100%是两个可切换强度，不把“认证红灯”当成显隐触发；认证期间保持显示仅为读得清本门反馈，不授予权限。

## 验证与仍待选择

`functional_validation.json`检查120组相机位置（5方案×8走廊×3纵向位置）、墙外余量、人物画框内、室内相机恢复、32门墙组、原469个新增整层碰撞体数量、隐藏墙与分区门碰撞、原E认证／黑屏穿越／返回、对门拒绝、距离边缘、门前区域边缘和跨房间段边界往复。

实机PNG和4段运动GIF覆盖：五种镜头的隐藏／50%／100%，两种触发在远处／贴墙偏离门／贴近门三处，真实移动接近及退开、沿墙横移。GIF使用全序列共享调色板，避免调色板变化造成伪闪动；原始1280×720逐帧PNG与实际模拟时间保留。`--fixed-fps 60`是捕获步长，不是学校设备的真实FPS评测。另有7张实机认证及黑门洞往返，证明新显示层能读到黄／红灯，且切镜发生在全黑、返回恢复室内原相机。

同一静止角色帧的15组“有人物／隐藏人物”图对测量表明：50%单层显现保留约50%人物图像对比度；100%实体使人物信号接近0，会把人物挡住。此项是可视性结果，不代替用户选择强度。B/C/D视野比A紧且角色比例接近；E最紧、人物显著变大。镜头、触发方式、显现强度仍待用户比较决定，没有迁移正式F5。

## 复建

1. Godot4.6.2导入，运行`scenes/dev/cryo_4f_camera_v6_verify.tscn`。
2. 运行`scenes/dev/cryo_4f_camera_v6_capture.tscn`，需要图形渲染。
3. 运行`scenes/dev/cryo_4f_camera_v6_auth_capture.tscn`补充认证与往返画面。
4. `python docs/art/experiments/cryo_4f_camera_compare_v6/analyze_preview.py`（Pillow、NumPy）生成动图、联系表、测量与审图页。

源逻辑与两个显示shader均在`scripts/dev/cryo_4f_camera_*v6*`，源资产继续使用`assets/art/cryo_4f_complete_v3`。没有重烘焙、PixelLab调用或新颜色贴图，新增生成额度0次。
