# Room 1 墙面旧化 r4 — 中等可见强度候选

2026-10-27。用户认可r3接缝，但认为旧化仍不明显，明确要求以Pixel Canals为参考，在参考较强的旧化与当前过弱的版本之间折中，不再极端克制。r3完整保留，本次只调整墙面旧化。

- [实际同机位对照](preview.html)：原应急光游戏镜头、技术近景、Base Color，以及全室回归。
- [五层Aseprite](editable/wall_age_r4.aseprite)：r3精确底图＋灯槽下沉积、墙脚积灰、缝边旧膜、保护带旧接触四个独立层。关闭四层可回r3；r3接缝原分层母版继续保留。
- Godot打开 `scenes/dev/room1_wall_age_r4.tscn`，F6；M切r3／r4，N纯颜色诊断，J回位，H说明，WASD沿用。

## 实际参考与本次取舍

本轮再次用Chrome扩展操作[Seafoam的Pixel Canals Viewer](https://sketchfab.com/3d-models/pixel-canals-low-poly-game-level-0e7cd01efb484aff817e3b03425cc080)，在沿岸墙体的两处斜角切换Final Render／Base Color。实际看到：灰色旧化沿墙顶、接合线与底部连续聚集，轮廓以大小不同的像素簇伸向主面；中部仍有较完整浅色区域。颜色通道中也保留这些变化。没有据此推定作者的准确贴图尺寸、UV、笔刷或Shader。

采用这种“沿边连片＋不规则阶梯轮廓＋完整主面”的组织方法，缩短侵入主面的范围、提高相对r3的色阶差异。这里的中等强度是本项目候选的艺术选择，不是对参考纹理做比例测量。密闭设施表现为积灰、失色、密封／金属旧接触，不复制室外护岸的水损或植被。

## 本轮具体变化

- 灯槽下方：连接收口的灰色带，有大形与1–2像素的小轮廓变化，向主面伸出约5–28cm的候选深度。
- 墙脚：较明确的连片积灰与失色，贴着保护带向上变化，局部约15–45cm；深／中／浅灰形成层次，留出中央完整墙面。
- 接缝两侧：局部旧膜／粉尘依附已有结构，不再任意撒在墙中央。**认可的接缝8px轮廓保持逐像素相同。**
- 金属保护带：旧接触面与边缘失去光泽，通过较宽的像素簇和短亮边表达，不画明显深刮痕。

灯罩发光面逐像素保持，灯光强度、曝光与游戏镜头不改；地面、模型、UV、门、20舱及人物位置保持。新旧化影响约15.8%的样段像素，其余保留r3；这个数只是资产差异面积，不是材料损坏率或全室目标。

## 源与导入

本轮是项目原创像素轮廓绘制，没有随机散布或AI生成调用，新增额度消耗0。没有下载参考模型／贴图，也没有把参考图像交给生成工具。`source/build_age.py`重建独立图层；Aseprite批处理 `source/package_master.lua`保存源和实际PNG导出。实际Aseprite合成是最终导出的基准，避免不同软件的透明度舍入造成源与PNG差1级。

新PNG在 `assets/art/room1_wall_age_r4/wall_sample.png`，256×272，沿用当前80texels/m候选。仍仅接入现有左墙3.2m试段；样段两端回归既有墙面，防止矩形贴片边。新接入继承r3／r2的正常材质与N诊断恢复逻辑，未新建Shader算法。

继续使用原 `assets/art/room1_wall_finish_r4/` 的配套GLB／UV2／HDR；名称里的“旧化r4”不代表重新烘焙了光照。新固有色反射未重烘焙，当前不作为新整室烘焙包或已批准全室资产。

## 验证

`source/check_delivery.py`核对实际Aseprite导出、五层源、接缝／发光面精确保持、同机位尺寸，以及r3基线和N往返还原。实际Godot捕获9张对比／恢复图与13机位巡检；技术相机只用于检查，不写入游戏镜头。检查记录见 `quality_record.json`。最终视觉强度仍交用户审图，不能用文件验证替代美术认可。

实际r3基线与N往返图对上轮画面逐像素一致（变化像素0、最大通道差0）。新旧原照明图在游戏机位相差16,205像素、最大通道差16；技术近景相差40,593像素、最大通道差17。差异位于左墙样段，未改曝光。数值只核对变化范围／存在性，可见度与中等强度仍按实际图判断。
