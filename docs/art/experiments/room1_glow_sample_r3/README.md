# 屏幕光晕修整 r3 — 2026-10-14，本地待审

用户希望矩形轮廓光更自然，并指出玻璃窗接缝过于平滑、以后需要像素接缝。本轮只修屏幕光，玻璃材质和几何沿用r2；接缝列为后续待办，未制作。

打开 `scenes/dev/room1_glow_sample_r3.tscn`，F6运行。1屏幕、2窗、3整舱、4室内；C比较内容发光与旧边缘发光，J比较柔和投光与旧投光，N开关Glow，P开关附近投光。V像素反光、B屏幕电源、G舱内光、H说明沿用。

原贴图含完整矩形边框与顶部长横线，r2的边缘衰减仍让顶部线明显发光。r3保留这些像素图案，但在发光通道排除边框／顶部装饰线，将文字与状态条作为主要光源。遮罩针对这一张显示纹理的UV布局；替换UI布局时须同步调整。没有修改源PNG或把轮廓随机化。

屏幕局部投光能量由0.012减为0.004，范围0.5m改为0.65m，衰减指数2.5改为1.5，以减少屏幕下沿明亮横带。仍有真实阴影，外壳凹槽会影响受光形状。屏幕本身为矩形，因此亮内容集中在矩形内是正常的；本轮减少独立发亮的框线，不声称光晕完全没有矩形特征。
