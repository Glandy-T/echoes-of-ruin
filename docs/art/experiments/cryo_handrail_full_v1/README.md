## 形体与接合

保留 ST-01 的 3.30 m 梯跑、每跑 1.90 m 高差、11 个可见踏面及第 12 个平台踢高。踏步、鼻口、平台和六件 L01 灯条的几何坐标沿用原工程。墙面为握槽重新分体，两个转台侧墙也承接对应灯条，未更改通道平面位置。入口和楼层平台的墙槽延续到端头。

栏体沿 C 截面：厚 80 mm，握持边距名义坡面 0.90 m，栏顶 1.10 m。内侧折返收到梯井内，最大 X 为 1.65 m；最后约 0.45 m 过渡到平台高度，完整转角接上另一跑。楼层平台内侧栏体延续到平台端部。此候选使用连续栏体，没有保留旧单段的三片拼装缝，避免无实体接合的背衬小块。

墙槽开口高 120 mm，背面按墙内 67 mm 定位；因背衬厚度，射线命中的实际空腔深度约 **65 mm**。三面衬体是真实几何，没有用贴图画黑线冒充凹槽。外侧墙厚 190 mm，握槽不外挂到净宽内。

## 像素表面与来源

主体通过 **PixelLab 官网 Creator → Edit Image / Pro Flash** 生成，使用官网图库内已有的项目自有 `M06-01-R1` 输入。本机 Chrome 扩展仍拦截本地上传，因此直接选同一张已上传素材，没有改用其他生成方式，也未上传 Pixel Canals 内容。原始输入、提示词、输出和实际出图证据均在本目录。[生成与额度记录](source/generation_record.json)

本轮新图为 256×256 原生浅暖灰哑光矿物／陶瓷复合面，以细小连接像素簇表现材料，不加入喷漆式污斑、踩踏磨损或黄锈。`C_BODY.png` 保持 PixelLab 原始像素；`C_SLOT.png` 复用相同图像，通过独立材质略压暗。现有墙面和踏面继续用已交付 PixelLab 细矿物纹理，其他灯、鼻口等沿用既有材质。新栏体的这一版是材料底面，没有宣称完成全楼最终旧化设计。

以 **80 原生创作像素／米** 为本项目基准。墙体用实际正交面轴，C 截面每条硬折面连续展开；内外弧均按实际三角形长度展开，避免内弧像素突然变细。两件继承的 `ClosedFlight` 网格存在旧 UV0 退化，本候选仅重投其 UV0，未改顶点和拓扑。硬折边与端盖允许 UV 接缝，同一连续带不逐段重置。UV0 作为可重复颜色图坐标可以越过 0–1；此处不是光照图集。

## 实际检查与边界

所有审图为 Godot 实际运行截图，1280×720、最近邻过滤。12 组灰模／像素对照的相机、环境光、实时光及剖切对象相同；另有最低亮度／所在区激活对照和 28 秒人物灯光演示。近景降低了点光源强度，以避免浅色完整栏体过亮：为原建筑审图的 0.18 倍，最低／激活仍为 1:5。这是审图配置，尚未冻结为整楼最终照明。

技术视图按检查目的临时剖切遮挡墙，`capture_record.json` 逐图保存隐藏对象；外墙另有正向巡检图，不把被隐藏对象算作已观察。所有机位仅属于新审图场景，没有写进正式游戏镜头。本轮没有烘焙或沿用旧 UV2／EXR，raw／denoised 光照图集检查不适用。

- [Godot 碰撞实测](evidence/runtime_clearance.json)：两跑各 11 条实际三角碰撞射线，宽度约 1.800 m；转台内弧顶点到端墙约 1.800 m。22 个踏步中心的 1.62 m 高、半径 0.125 m 胶囊静态检查没有重叠。
- [源模型与形体记录](model_manifest.json)、[独立复查](evidence/independent_validation.json)：分开核对闭合边、退化面、源几何、凹槽和实际导出 UV 密度。
- [相机与光照记录](evidence/capture_record.json)、[交付匹配与同机位检查](review_manifest.json)、[打包材质来源](source/packed_materials.json)。

胶囊静态检查与预定路径人物演示不等于移动控制器、碰撞爬楼、寻路或完整楼梯间安装已验收。下一步先审查本轮 C 的整体、握槽和材质；正式安装时再与已冻结楼层空间、门的扫掠和实际游戏镜头合并验证。

UV 密度统计排除了旧踏步侧面三角化产生的 15 个共线、近零面积 fan 数值残差；这类面没有可定义的像素密度。所有有效表面另行统计，未用目标值替代实测。

## 复现
