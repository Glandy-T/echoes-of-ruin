## 尺度与简化边界

尺寸来自冻结标准层 CAD 与现有楼梯工程：层高 3.8m，半层高 1.9m；梯跑净宽 1.8m、水平长 3.3m、踏面深 0.3m；每半层 12 级高差，11 块可见踏面加平台最后一级；平台完整宽 3.8m、深 1.8m。

这是一个独立剖切模块，只展示一个梯跑、入口和转向平台。返程梯跑、屋顶、上段墙体及完整围护被省略；下段代表墙用于检查材料搭配，不是楼梯间建筑完成稿。踏步以封闭立板和实体支撑表达，不采用原灰盒斜坡穿过薄踏板的形式。简洁八面柱扶手仅为占位，外形和最终构造未定。

三次官方 PixelLab `/inpaint-v3` 请求，每次10生成点，共30点；本轮只读核实余额从161降至131。原始输出均256×256，右侧64px为受保护的项目墙面参照，不进入矿物面导出。A/B 左192px直接裁出；前缘条裁出原图 `(0,48)-(192,64)`，因为实际生成的结构带出现在该位置。裁切不重采样、不放大、不调色，不添加绘画。三张请求未重试抽卡。

逐像素检查发现服务在遮罩外参照片区分别改动1／3／15像素，因此不宣称输出的遮罩外部分完全原样。该右侧参照片区全部排除出新材质导出，不影响所用原生裁片；r24墙身本身直接从已有资产裁出，没有使用生成结果替换。

A 颗粒较细，作为当前审图默认；B 有较粗矿物块，单独保留比较，不声称已经选定。做旧与颜色仍需结合实机图由用户确认。镜头、光照与 UV 尺度在 A/B 对照间保持一致。

踏步用不同的确定性 UV 相位取样，取消原先每两级完全重复的分布，不改变密度、不新增程序绘画。Godot 导入 GLB 时会在资产目录生成同名前缀的三张 PNG，它们是内嵌图片的像素相同副本，不是新的美术版本；同目录主 PNG 和 Aseprite 母版是可编辑来源。

Blender/Godot 使用 nearest 色图、粗糙度0.95、非金属、低镜面反射。没有法线、置换或程序化脏污，也没有复用旧房间光照图。重复平铺的接边需要实际检查，本次不宣称随机差分系统或全建筑材质已经完成。

## 光照和验收边界

Godot 截图使用1280×720、48°透视和临时中性实时审图光。相比 Room 1 的昏暗环境更便于检查落脚点；**不是最终楼梯灯带、运动感应或烘焙结果**。灯带位置、提前亮灯范围、停留保持与渐灭仍按[楼梯灯光 Brief](../../CRYO_STAIR_MOTION_LIGHTING_BRIEF.md)另行实现与审查。

本次不新增光照图或 UV2，不把可平铺 UV0 的重叠当成光照 UV 重叠。未来整栋使用烘焙时需按 [Room 1 光照 QA](../../ROOM1_LIGHTMAP_QA.md)重新生成配套图集并检查实际效果，不能把本样本的材质检查当成烘焙通过。

技术与实际画面检查详见 `validation.json`；用户最终美术认可尚未获得。后续先选定矿物面的颗粒和明暗，再推广至实际楼梯模块；不直接扩成整栋新一轮返修。
