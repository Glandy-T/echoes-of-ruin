# Room 1 地板局部细节对比 r25

2026-10-30。用户认可r24全墙后，要求检查地板是否同样有细节丢失，先做局部PixelLab对比，模型与布局不动。

## 查证结果

当前r24只拥有四个墙颜色图参数，地板仍来自r22 `floor_with_leaks.png`。文件和运行路径没有丢失。

r22的 `source/prepare_floor_tiles.py` 把r15的512×512区域最近邻降为256×256再交给PixelLab，`source/compose.py` 随后在824×364网格拼合、2倍最近邻放回1648×728。相同世界区域的原生作画密度因此由80降至40 texels/m；PixelLab也重新组织了图形。**观察到的问题是细碎边缘与渐淡过渡变成较大块团，并非整块贴图未加载。**两者都改变了观感，本轮不能定量分离缩放和生成图形各占多少影响。该密度只描述这些资产，不作为全项目新标准。

## PixelLab制作记录

使用官方 `POST /v2/inpaint-v3`，1次实际任务、10 generations。输入是本项目r15 PixelLab地坪与当前r22的保护区域；Pixel Canals仅作为可读像素簇、层次与渐淡过渡的技法参照，NoAI内容未上传。

`source/prepare.py` 只裁切原创输入并制作占用／边界遮罩；白区由PixelLab整片返修，黑区精确保留。`compose.py` 只做配准与0/255替换，不画污斑、不改变形状、不缩放；旧做旧不作为白区半透明底层。原始AI输出可能改变黑区，但这些像素完全未使用，实际保护区域经逐像素核对。

提示、导图、遮罩、任务ID、真实原图、用量及哈希在 `source/`、`raw/`、`result_candidate.json`。账户余额文件只在本地保存，不进入公开交付。

## 当前实际观察（制作者，非用户验收）

同机位正常暗光下，A→C的整体变化较弱，差异主要出现在P12/P13床脚的细碎接触过渡；B提供r15的原始细碎像素参照，C重新组织局部接触的团簇与渐淡过渡；两者不同位置的痕迹强弱不一致，不能简单以更密判断更好。原色诊断可以区分贴图的像素组织与光照压缩，不能把原色更清楚视为实际游戏效果已经通过。未见白框、旧材质穿透或明显矩形拼接边。

无遮挡技术图会临时隐藏舱体及对应显示／发光代理，完成后恢复；原有GI仍保留舱体烘焙投影，因此暗色舱位不能视作新增地板矩形。原色／无遮挡图不显示GI，实际舱底保护区仍是旧r22像素，可能显出保留区域的材质轮廓；它不属于白区新材质，正常舱体图才用于检查可见接触。正常游戏图保留舱体，未用诊断状态替换。额外相机与原色诊断仅存在于截图流程，不写回游戏相机或修改曝光。
