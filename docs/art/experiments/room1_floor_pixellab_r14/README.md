## 本轮图像来源

全部材料创作通过官方PixelLab `/generate-image-v2`及`/inpaint-v3`，使用已有Aseprite扩展的同一账户认证。输入是项目原创的干净蓝灰色导图、限定冷色调色板和实际舱底几何轮廓；没有提交Pixel Canals的截图／模型／纹理，也没有沿用r5／r8／r9人工做旧图层。Pixel Canals用于像素簇尺度、边缘材料层次和3D承载像素细节的技术目标。接口参数依据[PixelLab官方文档](https://api.pixellab.ai/v2/docs)。

底材以低对比的大块矿物涂层色差和更细的像素簇构成；墙脚原图表现贴边积尘；舱底差分表现与支撑轮廓相连的细颗粒接触痕。`contact_b`产生了明显长划痕，因此弃用，改用PixelLab重做的`contact_c`。`base`／`base2`两次编辑均返回单一颜色，因此改用PixelLab图像生成接口和8色冷色调色板生成`base3`；没有把空白结果算作完成的做旧。`leak_b`轮廓过硬、`leak_c`过弱、`leak_d`呈长裂缝状，均弃用。合格的`leak_a`按实际舱角方向旋转／左右翻转用于四个固定舱位；这是同一素材复用，不宣称四张独立差分。原始结果全部保留，最终只使用base3、edge、contact_a、contact_c、leak_a。

十一次实际任务（包括弃用六张），每次10 generations，共 **110 generations**。各任务ID、固定seed、提示词、mask、原始PNG和实际额度在`source/`、`raw/`、`result_*.json`。凭据未保存到交付文件。

## 几何配准与可编辑文件

- 颜色图仍为1648×728，80 texels/m，映射`u=(x-.2)/20.6`、`v=(z+9.3)/9.1`；保持现有房间20.6×9.1m。
- 20个旧舱底支撑轮廓来自既有实际落地顶点记录。前后排原生接触素材按0／180度旋转，不拉伸。当前P12是新版独立舱，另保留近景审查其实际接触；没有声称其几何与旧舱完全相同。
- 墙脚四边的PixelLab材料沿真实墙边配准，后墙门洞区间不画封闭横线；漏液位置仍固定P03、P06、P13、P18，不在运行时随机分配。
- 脚本仅做导图、mask、原生像素重复／旋转、边缘技术过渡、背景色对齐和分层。接触原图里的深色舱底占位多边形被遮掉，不导入地板。底材拼接仅在16px范围处理周期边界，不生成新的脏污形状。最终冷色通道关系另作技术检查。
- `source/assemble.py`生成四层：PixelLab底材、四边墙脚接触、20舱底接触、4处冷却液。`source/package.lua`保存Aseprite母版并导出运行PNG，`source/placements.json`记录逐舱素材与位置。

## Godot检查与边界

F仅比较r9旧地坪／r14新地坪；墙面和灯带维持r13。N查看颜色诊断，J回游戏观察点，WASD移动。新增场景只替换地板颜色图，沿用最近邻采样、现有UV2和r9间接光。

实际截图覆盖左中右游戏镜头、全室20舱总览、无遮挡地板原色、四角墙脚、门口、四处漏液及P12接触。原生贴图和近景与旧地面并排；检查记录在`source/quality.json`。技术俯视与近景隐藏了角色，故临时关闭其孤立胶囊投影，游戏镜头比较仍用原角色遮挡参数；这些取证设置不保存到游戏场景。N恢复比较对舱体所在区域单独报告，地坪区域应一致。不把文件或哈希检查当作用户视觉批准。

本轮没有修改模型、UV或光源，也没有重烘新固有色的间接反射。候选认可后再安排现行墙、地、门的统一光照打包；当前结果属于材质审查，不是新的完整烘焙工程。旧r9只供历史对比，新图不混用旧老化。
