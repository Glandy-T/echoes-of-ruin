# 90° 走路 · 收小步幅的一步

[六帧循环](one_step.gif) · [逐帧姿势](poses.png) · [高度曲线](heights.png) · [原生坐标 CSV](landmarks.csv) · [可编辑 PXO](step_skeleton.pxo)

以 r3 的定稿参照、骨架编码和已生成像素为源，在本地重新摆姿势。腿来自 r3 的近腿，脸、躯干及手臂取自定稿侧面，远侧手腿单独压暗。头颈、发梢、衣服、近远侧手腿各有图层。此次新增 0 generations。PXO 第 1 帧为站姿参照，第 2～13 帧为十二个等间隔骨架。前六个动作帧有角色画面，后六个仅有换侧骨架。打开隐藏的 Skeleton 图层可检查关节。

## 步幅和时间

r3 四姿势的落脚测量为 44／45 px。这次按反馈收小，触地时前后脚尖 x 分别为 38、70，间距 **32 px**，约 **0.422 m**。以近脚为支撑脚时，六张图在 y ≥ 116 区域量出的脚尖 x 分别为 38、43、49、54、59、65。下一触地姿势的骨架左右交换。前脚跟先落，下沉时膝盖屈起，经过位支撑腿立直，上升位脚跟开始离地；近臂从后往前，与近腿反向摆。两脚张开后，下摆到第 2 帧才最宽。

沿用 r3 实测的两步周期 1.068 s 比较步幅，每格 89 ms，播放约 **11.24 fps**。六帧为一步，GIF 在第 6→1 帧重放同一侧支撑，整圈接缝留待第二步验收。按缩短后的步幅推算，此节奏约为 0.79 m/s；若保持游戏目标 1.1 m/s，两步周期应为 0.768 s，十二帧为 15.63 fps。这里仅调整美术小样。

## 高度与发梢

坐标以原图左上角为原点。头顶取合成图最高的不透明像素，骨盆取两髋关节点中点，发梢取后脑最外侧一簇的尖端。高度为相对第 1 帧的位移，向上为正。六帧支撑脚底均为 y=126。

| 帧 | 动作 | 头顶 | 骨盆 | 后发梢 | 后发梢绝对 (x, y) |
|---:|---|---:|---:|---:|---|
| 1 | 触地 | 0 | 0 | 0 | (76, 13) |
| 2 | 下沉 | −2 | −3 | 0 | (75, 13) |
| 3 | 回升 | −1 | −1 | −2 | (77, 15) |
| 4 | 经过 | 0 | 0 | −1 | (76, 14) |
| 5 | 上升 | +1 | +1 | 0 | (77, 13) |
| 6 | 预备触地 | 0 | 0 | +1 | (76, 12) |

脸保留定稿像素。第 2 帧整头向前 1 px，头下沉比髋少 1 px。后脑只选 (74,11)、(74,12)、(75,12)、(75,13)、(76,13) 五个像素；刘海只选 (53,11)、(52,12)、(51,13) 三个像素。由根到尖逐渐增加位移，发根固定在头上。相对整头，两个末端第 1 帧原位，第 2 帧上 2 px，第 3 帧后 1、下 1，第 4 帧下 1，第 5 帧后 1、下 1，第 6 帧上 1。头顶最低在第 2 帧、最高在第 5 帧，后梢分别在第 3、6 帧到达相应极值。

运行 `python make_step.py` 可从上级目录原工程重建。需要 Pillow、NumPy 和 Matplotlib，曲线中文字体使用 Windows 微软雅黑。生成脚本重新解包交付工程，逐层比对可见像素，从导出帧读取三个标记，并逐帧校验 GIF 的像素、顺序与播放时间。
