# Room 1 主角出仓预演 r1

用户确认共3个亮仓：主角仓＋2个红屏仓。门左侧原亮仓P12作为主角仓；P02/P17屏幕为红色，表示内部人员死亡。其余17仓关闭窗光和屏幕。P02在前排，屏幕背向固定镜头，正面游戏视角看起来只有两个屏幕亮，是朝向遮挡而非遗漏供电。

## 运行

Godot 4.6.2 Compatibility 打开 `scenes/dev/room1_pod_exit_animation_r1.tscn`。
进入后P12舱盖保持原资产45度打开姿态，6.5秒依次播放躺卧、起身、向左跨过舱边、落地。R重播，空格跳过，之后WASD／方向键行走，H说明。分辨率锁定1280×720，摄像机仅跟随XZ，高度和朝向固定，出仓和常规移动都有渲染插值。

## 实现与限制

- 沿用已批准资产，不另做人物模型。胶囊动作只用于时序和空间预演；没有骨骼、手脚动作或最终角色动画。出仓阶段为脚本轨迹，关闭角色实体碰撞，落地在无障碍的相邻通道后恢复真实重力与碰撞。
- P12打开状态单独重烘焙房间和20舱的连续灯带照明，四整条发光面，0灯带Point/Spot代理。避免沿用关闭舱盖的静态影子。舱盖当前保持打开，不播放开合；将来动态开合必须再处理灯带遮挡，当前静态烘焙不支持任意开盖角度。
- P12实体改为各网格空心三角碰撞（壳体、内垫、打开的盖子），其余19仓沿用关闭外壳凸包。屏幕光晕世界同步替换P12遮挡，并加入人物遮挡。胶囊动态阴影使用世界空间两端点，跟随躺卧和起身旋转。
- 两个死亡仓以亮度重映射为红色，屏幕文字／像素结构保留；屏幕自身、模糊光晕和局部代理光颜色一致。玻璃和舱内光保留原效果，像素接缝和贴图返修仍待后续。
- 新烘焙保留上一轮左墙UV修正；旧候选场景、原GLB、原贴图未覆盖。

## 制作与验证

运行 Blender 5.0 `--background --python scripts/dev/bake_room1_open_hero_r1.py` 生成129接收网格UV2、2048线性HDR及降噪EXR。包装脚本设置输出目录与打开舱编号，再运行现有烘焙／降噪脚本。发布包含运行所需降噪EXR、GLB、纹理及导入设置；原始未降噪EXR留在本地，可由脚本重建。

Godot `--script scripts/dev/build_room1_pod_exit_animation_r1.gd` 构建场景；`--script scripts/dev/validate_room1_pod_exit_animation_r1.gd` 实际渲染检查：3亮窗／3亮屏、45度开盖、原分辨率锁定、相机高度朝向不变、播放途中输入隔离、落地碰撞恢复、通道行走与重力、重播／跳过、自动播完交接。8张截图及validation.json保存同目录。截图含两个红屏的正面近景，便于看清P02朝向。

动作和视觉仍待用户审阅，验证通过不代表美术验收。
