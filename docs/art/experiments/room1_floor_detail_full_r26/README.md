# Room 1 全地坪细节与差分 r26

2026-10-30。用户认可[r25 C局部](../room1_floor_detail_r25/README.md)，要求按这个完成度推广全地板，多做差分，保持连续地坪、无接缝，PixelLab制作，模型与布局不动。

## 当前范围

- 地板保持同一张1648×728颜色图，覆盖现有20.6×9.1m地坪。80px/m只描述本资产的现行映射，不成为全项目规范。
- 新增21份独立的PixelLab原生256×256世界位置原图，7列×3行；不同位置只使用对应原图一次，不用翻转或缩放冒充差分。生成分块是技术处理，**没有画地砖、网格、拼缝或路线**。
- 以C版的细节完成度为基准统一生成全室；原C样段单独留在r25作认可依据，不作为一块冻结的旧材质嵌回最终地板。原样段41,452个有效材料像素由PixelLab重新接回，模型和实际占位不改。
- 实际20舱的落地轮廓从当前r24 Blender中的r19 v8封闭接收体只读提取，并逐像素比对旧mask，结果一致；没有根据旧文件名猜测遮罩仍然适用。隐藏在舱底的像素保持现状。
- 四处已有干涸漏液仍在P03/P06/P13/P18；四墙脚及20舱接触依现有位置处理，不新增漏液或剧情含义。
- 墙面固定已认可的r24；舱体、主门、灯、玻璃、屏幕、模型、UV、碰撞、房间尺寸、布局和游戏相机均不改。

## PixelLab制作与连续性

输入仅为项目自有的r15原生地坪、已认可r25 C材质和实际占用遮罩。使用官方 `POST /v2/inpaint-v3`，所有输入/原图均为原生256×256，不走r22的缩小生成再2倍放大流程。Pixel Canals继续作为像素簇、材料信息层次和渐淡过渡的硬参照；作品NoAI内容未上传。

新图按世界像素坐标配准，相邻区重叠24px（横）／20px（纵）；脚本只从真实AI像素中选择颜色误差较小的重叠边界，不画脏污、不模糊、不调色叠旧层。白区整片替换、黑区严格保护；`pixel_source_ids.png`记录每个材料像素来自哪张原图，可逐像素核对。不同原图数与实际请求数分别记录，不能把技术裁切当作新素材。

首批4份原图的彼此连接没有可见栅格，但冻结的C区域显出矩形暗补丁。尝试4份PixelLab外围48px返修后，原C本体色差仍能被读出，因此这4份没有进入最终层。逐像素冻结C不是用户要求；最终用一份原生PixelLab请求重新接回原C有效材料区域，原C文件保留为风格／完成度依据。导图只在输入阶段把自有原细纹的基色参考配到周围新涂层（RGB参考偏移7/6/5），实际白区最终像素全部来自PixelLab，不是脚本调色或旧纹理层混合。

另拒用原floor_11／floor_12的大块角状暗面和原floor_18的假画布暗边，分别由PixelLab从原始导图返修；最终选用 `_fix`。全部原图、失败尝试与原因保留，不能因调用成功就当美术合格。

实际29次PixelLab请求／290 generations，包含3张弃用世界原图的替代与4次弃用外围尝试；最终使用21张不同位置原图（其中3张为返修版）＋1张原C区域统一接回图。

提示词、任务ID、真实用量与来源见 `source/requests.json`、`result_*.json`、`source/final_provenance.json`；账户余额与日志仅本地保存，不进入公开交付。
