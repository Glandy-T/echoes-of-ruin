# 90° 小跑 · 原件姿势与远侧配色

[1× 循环](run_1x.gif) · [3× 循环](run_3x.gif) · [两步同相位并排](paired_steps.png) · [逐帧坐标](measurements.csv)

八帧均取自 `8fbfc5a` 的[骨架原件](../frames/)。03、07 恢复原件的蹬地姿势。远腿与远臂沿用 run8 色阶，按侧别逐帧上色。已核对八帧的透明度和头部像素，均与各自原件相同。

从画布顶部向下量，头顶 y 为 **6、8、5、4 ／ 5、9、5、4 px**。髋与头在 02、06 同时到达各自最低点。03→04 和 07→08 均回升 1 px。指定原件的实际头顶全距为 5 px，最大相邻变化为 4 px。02、06 后脚分别离地 18、19 px。

循环为 8 帧、12.63 fps，GIF 每圈 630 ms。此次本地上色使用 0 generations，阶段累计 43/200。
