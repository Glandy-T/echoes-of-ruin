# 90° 小跑 · 顾问骨架实测

**眼看结果**。骨架版多数姿势能辨出袖口、肘、腕和手掌。01 首次返回的远手与身体断开，单独换种子重生该姿势后接回；03～05 的前手仍显握紧。01、02、06 的颈部比定稿站姿显长，01、02 的胸口侧面略向前顶。单次旋转退路的颈部更紧凑，收下巴的方向更接近顾问小样，胸前也更平顺，但前手又抬回胸前，02、06 的前臂在浅色衣料上仍有一段读不清。两组均供比选。

**来源**。主试使用 [顾问的 8×18 关节](../advisor_lean_mock/joints_rotated.json)，参照图、参照骨架、视角、描述、深度顺序和初始 seed 均来自 run8_lean。同 run8 逐项校验双侧髋、膝、踝。未将 822968c 或本地手绘版作为输入。第一批 [八帧原件](raw/) 完整保留。首帧独立的 35 像素远手需要重生；标准人形接口拒绝单姿势请求，随后用同一个 01 姿势填满最少三个目标位、换一个种子，取 [第一个候选](retry_01/raw/01.png)。其余七帧保持第一批返回值。骨架审图全部直接从这些透明 PNG 输出，没有局部手修。

**退路**。八张输入全取自 [run8 的 PixelLab 原始返回图](../run8/raw/)，逐帧将上身绕原髋点前转 9° 一次，用三次 Scale2x、一次旋转和最近邻缩回原尺寸。髋点所在行及以下与各自原件 RGBA 完全相同。未另转头、贴图或修手臂。[单次旋转透明帧](fallback/frames/)

**测量**。下巴取头部前轮廓向颈收进的拐点，至最后一行连续颈部肤色的垂直差作为露肤高度。定稿站姿 6 px；骨架版 01～08 依次为 8、7、6、6、7、7、7、7 px；退路为 5、6、6、4、4、5、4、5 px。两组头顶最低点都在 02／06，没有读出比髋晚一帧的最低点。[逐帧数据](measurements.csv)

同步对照沿用 run8 的 12.63 fps 和原 GIF 延时。以 01／05 中 y≥116 的可见脚尖同脚交叉追踪，run8 原审图为 60／60 px，骨架交付帧为 62／61 px，退路为 64／64 px。此处不修改游戏速度。

**用量**。首次提交前 1653.9，重生开始前 1650.9，重生结束 1648.9。因此整组 3 generations，第 01 姿势重生 2 generations，本轮合计 5，走跑累计 29/200。首批完成瞬间的余额尚未更新，分项以后一任务开始时的余额核对。[首批回执](generation.json) · [重生回执](retry_01/generation.json)
