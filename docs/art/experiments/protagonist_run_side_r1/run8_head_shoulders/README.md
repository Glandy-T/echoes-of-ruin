# 90° 小跑 · 头肩整块前移

[站姿／run8_lean／本版同步对照](comparison.gif) · [原尺寸](run_1x.gif) · [三倍循环](run_3x.gif) · [逐帧坐标与错位角度](measurements.csv)

八帧取自 run8 对应帧。触地、下沉把头顶至腋下的全部像素向左移 5 px，蹬地、腾空移 6 px。反向平移后，这一整块的 RGBA 与原始 run8 对应帧完全一致，包含发梢、颈、肩和袖子上缘。头肩的垂直运动也取自 run8。站姿用于对照比例；跑姿的肩袖随摆臂转动，与站姿轮廓有逐帧差异。

腋下到髋共 22～24 行，向下均匀把横移量收至 0，相邻像素行最多错开 1 px，平均方向与竖直线的夹角为 12.8°～15.3°。前摆帧使用 run8_lean 的半开手掌和前臂，在袖口下接合；远侧前臂在躯干后面。02、06 双手经过腰侧，沿用 run8 对应姿势。髋部及以下、两步 60 px 的步幅、八帧逐帧延时均与 run8 一致。原速为 12.63 fps。

三图中的黄线指后脑发际轮廓，青线指后肩。后脑取头顶下第 5～15 px 范围内最后方的可见像素，含发梢；后肩取头顶下 30 px 这一行最后方的肩部轮廓，避开向后摆的肘和袖口。人物朝左，后脑 x 减后肩 x 为正表示后脑更靠后。同一取点下，定稿站姿为 76 − 72 = 4 px；对照图中显示每一帧三张图各自的取点。此值随肩线的取样高度而变。
