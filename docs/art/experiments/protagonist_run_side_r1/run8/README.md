# 主角 90° 小跑 · 八帧审图

每步依次触地、下沉、蹬地、腾空。01 近脚落地，05 远脚落地。08 直接接 01。每次落脚时髋在 x=64，踝在 x=56，前足的连续承重区为 x=48～59，中点在髋前 10.5 px。02、06 髋比触地低 3 px，摆动小腿向后折，后脚离地 23 px。03、07 支撑腿伸长，脚尖接地，对侧膝向前。04、08 髋比触地高 1 px，两脚分别离地 2、12 px。

地面 y=125。髋高按驱动骨架的髋点计算；裙子遮住髋关节，不能直接从人物像素量出。脚的离地高度按导出的透明 PNG 分脚读取，取地面到该脚最低可见像素的差，0 表示着地。近侧是画面中较亮的一侧。

## 绘制与复核

八个姿势一次交给 PixelLab Animate with Skeleton v3，以 90° 定稿立姿为人物参照。前摆时从肩向前送肘，前臂向上收向胸前；后摆时手回臀旁，下沉时双手经过身体两侧。头在肩上，髋到颈的骨架前倾约 4°。发梢与下摆按上一个相位的高度保留跟随。

02、06 的近前臂用同一肤色色板接回原画的手和袖口。07 原件的后腿蹬伸不足，修后沿用同批 03 的下半身并交换远近明暗。其余校正集中在前手末端、接地脚掌、蹬地脚尖和各脚的高度；01、05 的后脚水平位置按 60 px 步幅校准。上表及播放速度均从修后帧复核，未在游戏中测脚漂。
