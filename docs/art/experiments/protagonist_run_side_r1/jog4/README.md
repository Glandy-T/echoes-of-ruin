## 成片测量

依照走路版口径，在两张触地帧的 y ≥ 116 区域分别读取两脚最靠左的可见脚尖。追踪同一条腿，从它的落脚帧量到另一条腿的落脚帧。

| 支撑脚 | 脚尖 x 起点 → 终点 | 一步 |
|---|---|---|
| 近侧（01 → 05） | 28 → 86 | 58 px，0.7656 m |
| 远侧（05 → 下一轮 01） | 28 → 87 | 59 px，0.7788 m |

按 125 px ≈ 1.65 m，平均一步 0.7722 m。两步共 1.5444 m，在 2.5 m/s 下周期为 **0.61776 s**。四张小样的播放速度为 **6.475 fps**，相同周期的八张为 **12.950 fps**。GIF 的实际延时按 10 ms 舍入，一圈 0.62 s。这是精灵画面量值，未接入游戏速度。

地线为 y=125。两次触地的脚底都在 125，两次腾空最低的脚底都在 123。头顶 y 依次为 6、3、6、3，骨盆关节 y 为 62、59、62、59。[成片坐标](measurements.json)

## 姿势和修整

同一站立定稿输入 PixelLab Animate with Skeleton v3，一次生成四张。骨架以髋中点到颈点为轴前倾约 7.9°；头前探，肩放低。肘角 85.7°～91.5°，腕部在腰侧小幅前后交换。触地前膝 y=91、后膝 y=90，后踝 y=114。腾空时收腿，脚跟保持在膝下。[逐帧骨架坐标](joints.json) · [PixelLab 原件](raw/)

原件的两张腾空图脚底高度不一；审图版在小腿下段配准地线，略收触地姿势的后膝。远臂与远腿使用较暗肤色，01、07 补连远手。头部沿用定稿图的像素，短发末端在落地时相对头部滞留上方 2 px、腾空时下拖 2 px。后发梢 y 为 14、15、14、15。下摆局部在触地时滞留上方最多 2 px，在腾空时下拖最多 1 px。四张只取高低两端，精确的一帧相位差要等中间姿势加入后再验证。[修整与导出脚本](review_jog.py)
