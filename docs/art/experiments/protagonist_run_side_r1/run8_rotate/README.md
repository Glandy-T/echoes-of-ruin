# 90° 小跑 · 髋部旋转版

[run8／顾问小样／本版原速对照](comparison.gif) · [原尺寸循环](run_1x.gif) · [三倍循环](run_3x.gif) · [定稿站姿与八帧颈部放大](neck_detail.png) · [逐帧像素测量](measurements.csv)

从 run8 的八个姿势起稿。原帧在下巴下方接到生成的躯干时，有些帧的前缘错开约 2 px。旋转前，按原来的头部位置对齐 90° 定稿站姿，从下颌接入完整的颈、领口和左右肩根，过渡到原跑姿的袖子。保留各帧发梢。前摆手掌和前臂使用源自 run8_lean 的半开手修图，先还原到直立姿势的肩位，和躯干一起旋转。

原色块连续做三次 Scale2x，在 8 倍像素网格中绕髋向前转 9°。头部在下巴与后颈交界处绕上颈关节反转 4°，相对原画净前倾 5°。八帧共用相同的角度和取样位置。降回 128×128 后，眼线、刘海接脸处用定稿原色复位，胸前轮廓修去突出的单像素阶梯，髋缝在腰部衣料内接齐。垂直起伏把头、颈、肩作为一个整体带动，滞后量在腰部收至零。髋最低在 02、06，头顶最低在 03、07。

|---|---:|---:|

| 后发际至领口最长一列连续露肤 | 4 px | 全部 4 px |

前喉取下巴尖下方、从下巴尖向后 8 个像素列内的连续颈部区域。颈部近图以各帧下巴对齐，便于检查局部形状。以同一标记对齐后，从下巴到最后一行颈部肤色的 16×7 px 区域，八帧 RGBA 完全一致。角色仍有前后摆臂和发梢随动。

各帧自髋点所在行起，与 run8 逐像素一致。两步各 60 px，12.63 fps；三份 GIF 的每帧延时均与原 run8 相同。本次新增 0 generations，走跑累计 24/200。
