# 主角 90° 跑步 r1 · 四姿势小样

[原尺寸循环](pilot_1x.gif) · [三倍循环](pilot_3x.gif) · [四姿势](poses.png) · [PixelLab 原件](raw/)

站立参照为定稿 final_90.png。PixelLab Animate with Skeleton v3 一批生成两组左右交换的触地和腾空姿势，预定八帧中的 01、03、05、07 等间隔播放。略前倾，收肘和提膝。截图和动图保留原件，便于判断模型实际遵循骨架的程度。

目标一步约 1.1 m，速度 3.5 m/s，目标周期 0.629 s。小样 GIF 周期 0.63 s，每步占两格。如果补齐八张，目标时钟约 12.73 fps。这个时钟依据设计步长。

两张触地帧的前脚底 y=122，后脚底 y=110，两张腾空姿势最低点分别在 y=119 和 116。r2 走路的 y≥116 测量带在跑步触地帧里只框到一只脚。分别在每只脚脚底上方七行取最前端，两个触地姿势的前后脚尖 x 都为 23、106，水平间距为 83 px（1.096 m）。腾空阶段身体继续前移，这个间距只能作为空间尺度参考，不能代替世界坐标的实际落脚距离。

原件的两张触地姿势把远腿画得偏亮，03、07 的脚底高度相差 3 px。腾空清楚，触地时后腿伸得较直、裙摆张得较大，观感更接近大步跑。当前审这一版的步幅和腾空感，再定八帧的下沉、收腿和压衣摆。未接入游戏。小样费用 3 generations，走路及本次小样合计 12/200。使用 pilot.py 生成并按回执续接同一任务，review.py 从原件重建审图文件。
