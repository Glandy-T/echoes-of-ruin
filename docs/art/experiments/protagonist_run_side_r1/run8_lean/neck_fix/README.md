# 90° 小跑 · 颈部修正

[修前／修后同步循环](comparison.gif) · [原尺寸](run_1x.gif) · [三倍](run_3x.gif) · [八帧测量](neck.csv)

前一版在下沉和蹬地间单独移动了头，领口跟随躯干，下巴到领口的垂直间距从 8 px 跳到 2 px。本次取前一版 04 帧的下巴、颈和领口，三处逐帧等量平移；肩线在衣料内与各帧原有的袖型衔接。发梢沿用各帧的原画。头顶 y 依次为 3、4、6、4，两步对称，最低点比髋晚一帧。

测量在透明 PNG 上进行。下巴取头顶中心线前方至少 3 px 范围内最低的脸部肤色像素，领口取最高的象牙白衣料像素，纵坐标向下增加。八帧修前间距依次为 5、8、2、4、5、6、2、4 px，修后均为 4 px。颈部像素相对位置已逐帧核对。

每帧从 y=38 往下与前版 RGBA 逐像素相同。两步各 60 px，12.63 fps，GIF 各帧延时与 run8 一致。本次使用已有 PixelLab 原画进行局部修整，新增 0 generations，走跑累计 24/200。
