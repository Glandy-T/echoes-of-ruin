# Room 1 镜头边界与封闭房壳试验 r2

2026-10-14。用户同意尝试：房间中部跟随，靠边时摄像机停止跟随；保留封闭房壳，朝向镜头的前墙／屋顶不出现在画面中，但继续投影。只处理镜头边界与墙顶可见性，光源设计和主角物理仍待后续。

打开 `scenes/dev/room1_camera_bounds_test_r2.tscn`，F6运行。WASD／方向键移动；R复位；T显示／隐藏比例标记；H显示／隐藏说明。数字1中央、2左、3右、4前、5后，6前左、7前右、8后左、9后右，可直接检查各处。

## 本轮变化

- 沿用r1的固定9.75°俯角、2.2m世界高度、50°水平FOV。中部按X/Z跟随，边缘目标离开中心，摄像机保持固定朝向与高度。
- 前后镜头范围先试Z=1.0～4.54m。该范围针对当前1280×720、16:9画面和1.65m比例标记检查；不是所有镜头参数或窗口比例的通用边界。
- 透视镜头在不同前后深度的可视宽度不同，因此左右范围按标记头部深度计算，避免靠前时用较宽的后墙范围把人物挤出画面。
- 左／右侧墙恢复可见，用真实墙面收住侧边；前墙和屋顶使用 `SHADOW_CASTING_SETTING_SHADOWS_ONLY`，保持节点可见参与投影，只隐藏其实体画面。源GLB完整保留。
- 原光源参数未调。封闭屋顶会遮住上一轮检查用方向光，所以房间比开放剖切版暗，这是封闭遮光的实际结果；下一轮再做室内灯光设计。

当前前景舱仍正常遮挡角色。在后侧角落，标记下部会被舱遮挡；本轮没有透明舱、角色穿透描边或自动转镜头。比例标记仍无碰撞，可以穿舱，不是主角行动原型。正式人物尺寸／可走路径确定后，应重新审查遮挡。

## 验证

`validation.json` 检查中央、四边、四角共9个位置的完整标记包围盒在画面内，摄像机高度／朝向锁定，中部等量跟随、侧边停止，以及目标Y／旋转不影响镜头。输出9张实际Godot截图，另有移除前墙／屋顶投影的明亮对照。

封闭投影与移除投影对照使用同镜头、同灯光、同标记位置，并读取中央地面区域的亮度差，验证只投影的屋顶确实遮住方向光。图形验证使用Godot 4.6.2、GL Compatibility、1280×720。

已目视检查中央、侧边、前侧和后侧四角：房间边界由侧墙、后墙和地面填充，未见外部虚空；前侧完整胶囊在画面内。镜头停止后的人物偏离中心、前后运动造成的透视大小变化与舱体遮挡仍需用户实际试玩判断，不视为最终镜头验收。

复现：Godot控制台运行 `--headless --path . --script res://scripts/dev/build_room1_camera_bounds_test.gd`，随后运行 `--path . --script res://scripts/dev/validate_room1_camera_bounds_test.gd --resolution 1280x720 --quit-after 240`。r1保留；生成脚本会重建r2，手工修改后应另存再重跑。

依据：[Godot 4.6 GeometryInstance3D只投影模式](https://docs.godotengine.org/en/4.6/classes/class_geometryinstance3d.html#enum-geometryinstance3d-shadowcastingsetting)。只投影并不自动建立碰撞或保证所有光源都遮光，灯光自身仍须开启阴影；本轮验证的是已有带阴影方向光。
