# 分段投光试验 r2 — 已放弃，2026-10-14

用户希望暗一些、能看出灯带的明暗渐变与遮挡阴影。此中间试验停用旧无阴影填光、降低环境光至0.025，用多组Spot/Omni模拟灯带。实际光照与开关阴影差分通过，但墙面仍出现一串灯泡状光斑。

用户当场指出“你是不是又把灯带变成灯泡了？”。这个方法没有满足连续灯带要求，已停止作为候选，不再通过增加点光继续调试。后续改用四整条连续发光面烘焙，见`room1_lighting_continuous_bake_r3`。这些中间文件和截图保留作失败记录，没有提交上传。

本试验脚本包含临时地板分区以避免Compatibility每物件光源数量限制；未应用到原GLB、主场景或后续烘焙版本。阴影是分段灯的动态阴影，不能称为连续灯带阴影。
