# Room 1 墙角光照质量 r3

2026-10-27。修正UV2重排后的低采样烘焙噪声／降噪波纹；当前出仓r3及墙地小样默认读取本版。[同机位对照与全室巡检](preview.html)。

## 原因与处理

r2解决了跨对象UV2重叠，但64样本的原始漫反射光照噪声很重，HDR降噪后在墙角形成横向明暗波纹。上轮只检查黑块和三角切缝，漏过墙角，不构成完整验收。

本版保留r2的模型、UV0／UV2、网格映射、原生颜色贴图、灯带几何／颜色／能量、相机及曝光，只把固定采样从64提高到1024后重新烘焙。2048图集、4px扩边和原HDR降噪算法保持；没有局部涂抹、模糊颜色图、取消阴影或改墙面设计。CPU一次性烘焙106.7秒。

`quality_record.json`记录GLB、映射和UV2记录与r2逐字节一致；原UV2零退化／越界／重叠及连续墙面对角边记录继续适用。源Blender中烘焙前后UV0／UV2哈希一致。采样数只是本版候选值，不能当作所有场景的保证值。

## 实际检查

- `evidence/`：两个相同游戏机位、原材质／局部材质小样的r2／r3对照，以及不改变色调的原生墙角裁切；另保留64／1024的降噪前画面。
- `survey/`：6处原游戏镜头，4个墙角，门洞，2个技术总览，共13张。技术相机只存在于截图进程，不保存游戏场景；检查前墙时临时将原本仅投影的剖切墙真正显示。两个新总览覆盖全部20舱及地面。
- 父代理及独立审图均确认：这些画面中没有r2墙角横条、旧左墙黑块或明显三角光照切割。当前材质小样8图已刷新。

**检查范围是上述光照伪影，不是整场景美术最终批准。** 全室巡检还记录了既有独立问题：通常隐藏的前墙UV0／材质尚未统一，出现中段保护带及偏黑下半墙；灯带有窄竖向接头。这些不应被重新命名成光照噪声，也不计作已通过美术审查。

## 可编辑工程与后续规则

- `room1_corner_quality_r3_packed.blend`：原独立网格、原UV、四条连续发光面与打包HDR光照／颜色图；1024采样可继续编辑。
- `assets/art/room1_corner_quality_r3/`：GLB、降噪EXR、映射、布局记录、烘焙参数，配套使用。原始未降噪EXR只留本地，工程和重建入口保留。
- `scripts/dev/bake_room1_corner_quality_r3.py`：读取r2固定姿态源，前置核对布局，保留UV，烘焙后复制原GLB／映射。已存在结果时默认拒绝覆盖；明确重建设置 `ROOM1_CORNER_ALLOW_OVERWRITE=1`。
- `capture_corner.gd` / `capture_room_survey.gd` / `capture_raw.gd`：真实渲染入口；记录有机位与实际文件路径。raw审图需要本地重烘焙输出的EXR。
- 后续遵循[光照制作与交付检查](../../ROOM1_LIGHTMAP_QA.md)及根目录AGENTS补充；不能再以一个角落变好或UV检查通过替代整场景审图。

旧r2留作错误基线，本轮未新增资产造型、未调用PixelLab、未改玩法或技术分辨率。
