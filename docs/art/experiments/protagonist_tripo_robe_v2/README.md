## 静态检查与下一步

[独立结构 QA](source/robe_topology_check.json)实际导入 raw GLB，结果 **FAIL_STATIC_ROBE_CANDIDATE**：2020顶点、4049三角面、单连通，无退化面，但有2条非流形边和272对非邻面交叉。腋下／袖根等处的内外层和连接需重新整理，不继续在该原始网格上自动权重。它保留作外形参考，不是变形网格验收结果。

颈口、双袖口与下摆的短距离中心射线均未立即撞到封口；[下摆实拍](evidence/independent_underhem_opening.png)可见内腔。这是局部开口证据，不证明整件衣物没有问题。带内外层和收边的开口可以没有网格边界，不能仅按边界边数量断言封口。[导入统计](source/mesh_audit.json)分别记录 OBJ 和 GLB，不能把网页 Quad 标签当成全四边面或可动画保证。

身体 v1 的两脚趾附近已有28对真正相交，先作局部简化；当前没有把这些问题藏在白袍里。身体与白袍的臂角、归一化高度不同，截图各自居中不表示已经合身。

1. 用户审看整体人体／袍型；先简化身体脚趾，衣服按外形候选重新整理腋下及内外层拓扑，再重跑静态检查。不要无限重抽或把原网格直接自动绑骨。
2. 统一米制身高、A姿势、肩肘腕和髋膝，再试穿；检查抬臂余量、袖口、腋下、裆部和下摆。
3. 一个共享 humanoid Armature 驱动身体、衣服与后续头发；必要的裙摆辅助骨也属于该骨架。先做临时权重及待机、弯肘、抬臂、行走／跨步小样。当前没有实施或验证动作。
4. 动作检查后再整理生产UV、密度和PixelLab贴图。保持弱五官设计，头发以v2有限体块为来源，不回到细发丝。
