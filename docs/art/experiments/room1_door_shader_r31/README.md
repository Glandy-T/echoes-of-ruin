2026-11-17。用户审 r30 时认为门的“不锈钢感”仍偏强，要求先只改着色器做对比。**待审候选，正式 F5 未切换。**

- [同机位对比页](preview.html)：A＝r30（v3 门着色器），B＝r31，1280×720。先看最上面的游戏镜头门区放大图。

- 着色器：`scripts/dev/room1_door_shader_r31.gdshader`；场景控制：`scripts/dev/room1_door_shader_r31.gd`（继承 r30）。

## 测得的原因

在 r30 同机位截图中测量门区和左右墙面（数据见 `source/measurements.json`）：

| 项目 | r30 | r31 | 墙面 |
|---|---|---|---|
| 游戏镜头，门区由上到下六段亮度（绿通道） | 36 → 34 → 29 → 28 → 26 → 18 | 38 → 38 → 36 → 38 → 34 → 27 | 39 → 38 → 37 → 36 → 34 → 28 |
| 正面镜头平均亮度 | 27.3 | 33.6 | 33.4 |
| 正面镜头局部像素对比（高通标准差） | 1.29 | 1.68 | 2.85 |

1. **整扇门是一条连续的上亮下暗渐变**：v3 着色器从顶部一路压暗到底部，底部只有墙的约 65%，墙面却到地面接触处才明显变暗。表面又很干净，这条渐变就被读成光滑板材上的反光。r31 改为跟随墙面明暗：上部平，只在下部做接触变暗。底部仍比 v4（已否决）暗得多，门下不会出现光源感。
2. **贴图的细节在游戏里被压没了**：v3 的亮度系数低，门面局部像素对比只有墙的约 45%。r31 以涂层自身的中位色为中心，放大比它暗的像素（沉积、边缘痕迹）×2.6；比它亮的像素只放大 ×1.2，避免门边出现像不锈钢包边的亮框。
3. **色调**：起初怀疑 v3 的 `(0.90, 1.03, 1.04)` 偏冷，但实测门的 B/G 比墙还低（0.93 对 0.985），所以 r31 没有改色调。这一点修正了审图前的口头判断。

## r31 改不了的部分

**r30 贴图 83.8% 的像素是同一个颜色**（亮度 25～95 百分位都是 189.1）：主面基本是平涂，只有角落、边缘和小窗附近有零散痕迹。着色器只能放大已有的痕迹，没办法在平涂区域生出颗粒。所以 r31 解决的是“门比墙暗、整片反光渐变”的问题；门面看上去仍然干净平整。

如果 r31 之后仍觉得像金属板，下一步应改贴图本身，而不是继续调着色器。例如复用已认可的 PixelLab 细矿物底材（楼梯／墙面已有原生素材），作为门主面的底层，r30 的痕迹层叠在上面，用 Aseprite 分层配准。是否这样做，等用户看过 r31 再定。
