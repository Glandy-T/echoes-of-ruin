## 实际生成与下载

使用Chrome扩展操作Tripo官方工作台，沿用项目自有正面v2（192×256，`source/input_front.png`）。HD Model → H2.5 Legacy，Triangle、目标3000面；Texture、Generate in Parts、8K Texture均关闭，Public，AI Complete保持关闭。只生成一次，消耗15免费点，余额200→185；没有购买订阅，没有使用PixelLab，也没有上传Pixel Canals／INSIDE内容。

官方Export菜单可选GLB并显示15次免费导出。正常导出写入用户自定义下载目录，但浏览器下载事件未返回位置，导致重复点击；用户指出文件位置后，本地找到三份同名下载，大小均71604字节、SHA-256一致。只复制一份到本目录，原下载全部保留；**三份文件不是三次生成**。没有从页面内部资源提取模型。下载等待问题不能再写成“导出失败／文件不存在”。

生成网址和文件哈希是来源记录，不代表造型通过。H2.5可免费导出与前一轮P2.0导出要求升级是两个不同模式的实际结果。[前一轮P2.0试作](../protagonist_tripo_trial_v1/README.md)保留原历史事实。

正面能读出简单长袍、宽袖、长发和人体比例；弱化五官的方向与当前目标相容，但不能据此说模型整体可用。

**背面后发有明显碎裂、折叠与尖刺状三角面片，侧面也能看到；这是几何层面的问题，不能交给贴图遮盖。**手指被合成粗块，腕／袖口和袍摆内侧需要继续检查。头发与上半身不能按现有对象结构直接独立修改。已经检查所有四个角度，没有只用正面报喜。

与P2.0截图比较时注意：P2.0是3211个Quad界面读数，本轮是2943个Triangle；两者不是相同三角预算的严格算法对照。本轮只验证免费生成和实际网格可用程度，不据此断言H2.5所有输出质量。
