# Room 1 纸片主角 r1

本审查场景将旧版 Godot 主角的 `idle.png`、`walk.png` 放入当前 Room 1。它是面向镜头的 `Sprite3D`，使用 nearest 采样；角色内容像素高96px映射为1.65m，脚底对应既有 `CharacterBody3D` 的地面位置。

入口为 `scenes/dev/room1_sprite_player_review_r1.tscn`，F6 运行。WASD移动，R复位，O开关P12盖；截图保存在 `evidence/`。物理、移动、相机跟随和接触阴影继续复用现有1.65m胶囊。旧2D角色场景和PNG没有被修改，正式入口没有替换。捕获会用现有测试输入持续推动角色，读回移动距离、walk纹理／帧和停止后的idle回退，不把手动写入一次速度当作动画验证。

本轮仅验证纸片角色在当前低角度3D房间内的体积比例、镜头朝向和与舱体的前后遮挡。它不把2D动画控制器、2D相机、交互或全局游戏流程迁移到3D；下一阶段再将旧2D功能按需要接入。
