## 做到了什么，为什么仍然不行

1. 原始AI白袍的内外层、收边共用组件并在袖根折叠。整体self-union产生大量非流形边；局部抽取外层留下肩袖破洞，均未采用。
2. 受控表面重建得到单组件、零边界／非流形／退化／自交的静态实体，领口、双袖口、下摆保持开口；恢复原平滑法线后同机位轮廓重合约99.8%。这些只证明静态表面修复，不证明服装变形拓扑合理。
3. 按身体对齐尺寸与A姿势，共用23骨架（含4裙摆辅助骨）试穿。休止姿势、弯肘可零自交／零可见皮肤交叉；伸手、迈步、大幅抬臂仍失败。袖根严重堆折、拉扯，不能用贴图修掉。
4. 权重平滑／姿势平滑不能替代袖根结构，停止继续堆补丁。覆盖身体可按换装规则隐藏，但衣服自身缺陷没有因此获得通过。

最终拒绝版本的精确检查见[fit_report.json](source/fit_report.json)：rest 0/0；大幅抬臂160/0；弯肘0/0；迈步2/45；伸手47/0。斜线前为衣服自交对数，后为可见皮肤与衣服交叉对数。完整被覆盖身体的碰撞另列，不能把遮挡写成完整无穿插。

## 接续方法

保留白袍为外形参考。在与身体对齐的统一休止姿势下，建立单层、连续、适合变形的衣物网格；袖根／腋下与袖肘需合理环线，不能把AI双层实体直接套权重。先让单层衣物通过基本动作，再处理内侧／收边／厚度，最后进入UV与PixelLab贴图。动作未通过前，不升级为当前角色。

本轮未新生成Tripo／PixelLab内容，也未改Room1、灯光、镜头或Godot占位主角。
