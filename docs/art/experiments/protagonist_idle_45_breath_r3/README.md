# 45° 主待机 D · 颈肩、左臂与双腿修订

[修前修后同速对照](45/compare.gif) · [原尺寸](45/breath_1x.gif) · [3×](45/breath_3x.gif) · [六帧并排](45/six_frames.png) · [Room 1 原比例动图](45/room_native.gif) · [全画面](45/room_1.png)

修前第 4、5 帧头向画面右侧移了 1 px，脸和衣领之间又使用不同的位移。面部画法没有旋转，但在朝左的三分之四视角下，下巴读成向后扬。现将头、下巴、可见的颈部和中央领口竖向配准，发梢只做竖向跟随。第 1 帧仍是 r1 D 原文件，中央胸腰区域（x=57～80、y=33～82）六帧逐像素等于 r2。

左侧腕部在 r2 的 y=57 行从 3 px 膨胀到 5 px。细长肢体使用连续网格后再取整，会重复或跳过同一行的肤色和轮廓像素。这版从 D 的原件取左臂，每一行的宽度、颜色与次序都保留，手随肩抬落。放松腿的膝向内移 1 px，跟端在第 4、5 帧抬 1 px。双腿从裙底至踝上逐行核对宽度和原画色块，承重脚底与放松脚前掌持续接地。

6 帧、2.8 秒，0 generations。已在 Room 1 的 1280×720 镜头重载 [Godot SpriteFrames](breathing.res) 并拍摄全部六帧。[制作脚本](build_fix.py) · [实拍脚本](room.gd)
