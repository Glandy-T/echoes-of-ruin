2026-11-04。独立F6候选，继承最新室内r30；正式F5仍为r19。当前交付是**墙板材质＋局部模块＋出门镜头/遮挡原型**。地坪已按用户要求复用r26中央过道原生材质，排除舱位接触轮廓和漏液；不再使用此前纯色占位。

## 运行与操作

打开`scenes/dev/cryo_corridor_sample_v1.tscn`，按F6。WASD移动，靠近Room 1门按E后开始认证；靠近但不互动时保持待机。门洞使用固定的双面黑色遮挡，开门后也不能透视里外，角色仍可正常穿过并触发黑屏切镜头。F8跳到小样；F7切换灰盒／小样。原有F1走廊、F2西梯、F3一层平台审查跳转保留。

用户本轮暂定：出门黑屏过渡，镜头相对室内水平旋转180°，其他房间挡镜头时透明化。此候选实现：

- 出门阈值z＜-9.72m；0.22秒淡黑，在全黑时反向镜头，保持0.08秒后0.30秒淡入。返回z＞-9.25m时反向恢复，阈值间留滞回区，避免站在边界反复切换。
- 保留室内相机高度、距离和焦点高度，走廊只把水平偏移从+Z改为-Z。西梯仍使用原有临时楼梯镜头，不声称楼梯镜头已定稿。
- 走廊按反向镜头映射WASD；切换期间停止移动，切换后需松开原按键再移动，避免持续按键立即把角色送回门内。测试输入仍明确使用世界方向。
- 相机到角色周围约8m走廊范围的射线检查邻室墙、门及小样模块。遮挡对象渐变至12%不透明度，脱离遮挡后恢复；使用材质副本，不修改共享资源，也不关闭碰撞。当前是整块网格透明，不是最终的局部圆形遮挡裁切。门洞黑幕不参加遮挡透明。

## 小样范围与制作来源

冻结标准层与既有route_v3为坐标依据：门外走廊宽2.4m，对面墙前沿z=-11.9m，Room 1外缘z=-9.5m。选取x=6.6–9.8m的一段，避开x=9.8–11.2m门洞。不是整栋外部或1F室外出口设计。

- 一组双墙板模块3.2×3.2m，256×256原生PixelLab图，复用到走廊两侧。上下端、灯槽和板缝用简单低模结构表达；另有0.2m顶盖。两侧是同一模块复用，不冒充两份独立差分。
- 地坪模块3.2×2.4m、256×192；直接从现有r26的1648×728原生颜色图裁取`(768,256)-(1024,448)`中央过道区域。两排舱位轮廓主要在y=43–223及506–686，本区域位于中间，亦避开已知漏液。无缩放、调色、重画、翻转或新生成。来源SHA和裁取坐标见`source/floor_reuse_provenance.json`。历史两次纯色输出保留为失败记录。
- 主要面80原生像素/米；最近邻采样，没有放大重采样。表面偏移3mm用于避免与原灰盒共面闪烁；原碰撞和门洞不变。
- 三个仅影响新增模块的实时补光用于审图，不影响r30室内材质或烘焙。无新光照图，也没有套用旧室内光图到新几何；UV2图集、raw/denoised烘焙比较在本次实时样段中不适用。正式走廊灯光与楼梯运动感应灯带尚未完成。
- `cryo_corridor_sample_v1.blend`为可编辑模块源，引用同仓库相对贴图；`source/build_model.py`可重建模型。`assets/art/cryo_corridor_sample_v1/`为GLB/PNG运行数据。
- `raw/`保留PixelLab原图和r26裁片；`editable/`是命名为原图层的OpenRaster母版。本机没有找到Aseprite，故本轮没有Aseprite精修，也没有改用其他工具绘制主体。

## 验证结果与限制

- `physics_validation.json`：实际CharacterBody从房内开门、走廊转向、西梯4F下降至1F，上下坡与四处地面射线通过；64个原路线碰撞体保留。
- `camera_validation.json`：黑屏alpha=1时切镜头，水平朝向点积-1；出门与返回各一次过渡；返回后所有透明副本恢复；实际D键测试在反向视角下向屏幕右移动。原r30材质模式保持2。
- `source/model_validation.json`：三个主要表面UV0均为连续四边面，0–1范围、非零面积、80px/m；共用墙板纹理是有意复用。没有分岛光图或烘焙扩边。
- `evidence/`：1280×720原始游戏输出；同机位灰盒/小样、完整墙板、地坪技术视图、180°反向游戏视图与黑屏/返回状态。技术相机只存在于捕获脚本。
- 技术检查通过不等于美术验收。小样之外仍是灰盒；门背面、全走廊照明、地坪推广、完整差分及楼梯效果未完成，1F室外出口仍待确定。Room 1已认可室内没有返修，主角3D仍暂缓。
