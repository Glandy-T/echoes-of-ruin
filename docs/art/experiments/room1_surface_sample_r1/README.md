## 本轮材质

沿用已确认的连续矿物／工程复合墙面、窄金属保护带、统一蓝灰密封复合地坪，**没有新接缝设计**。墙地都通过低对比、相互衔接的像素色块表达同一材料的面层变化；墙面密度较低，结构和保留沉积集中在实际收口及保护带。

| 对象 | 本轮范围 | 固有色方向 |
|---|---|---|
| 左墙内侧 | Godot z=-6.4..-3.2m，墙高0..3.4m | `#D3D6C9`暖灰为中心 |
| 相邻地面 | x=0.2..3.4m，z=-6.4..-3.2m | `#5A6C73`蓝灰为中心 |

两张原生贴图为128×136和128×128，映射本轮样段时约40 texels/m。**这是局部试验值**，不修改1280×720渲染，不锁定全项目像素密度。区域边界用约0.128m过渡接回旧表面，是审图遮罩，不是墙缝或道路边线。

没有新增十字分区、路面标线、砖缝、面板网格、裂纹、锈斑、明显刮痕、苔藓或无成因的中央污渍。窄保护带上的浅接触只为待审示意，不代表已确定的历史事件；材料化学组成、施工细节、维护史仍TBD。

## 来源与处理

1. `source/prepare_guides.py` 手工指定原创像素多边形，并放入项目已有的灯槽／保护带结构。没有随机噪点生成器。
2. 通过现有官方 PixelLab `edit-images-v2` 接口分别编辑墙、地一次；**各10，共20次订阅额度**。任务、原始PNG、实际提示词分别保存在 `source/*_job.json`、`*_status.json`、`*_prompt.txt`、`raw/`。
3. 原始墙结果仍有孤立点和AI擅加的结构痕迹；`source/finish_samples.py` 做原生像素众数／小孤岛整理、色板对齐，保留较大连贯色块。墙面结构只取既有母版的精确位置，不沿用AI新增接缝。地面同样去除少量孤立像素。
4. `editable/floor_surface_sample_r1.aseprite`、`wall_surface_sample_r1.aseprite` 保留处理后材料、墙面结构、边缘整理和隐藏原始AI结果；分层PNG见 `source/layers/`。

**没有向PixelLab提交 Pixel Canals 截图、模型或贴图，也没有取用原作像素。** 只按[学校人工观察记录](../../references/ROOM1_PIXEL_CANALS_SURFACE_NOTES_20261014.md)借鉴像素簇尺度、色块节奏和结构边缘的信息分布。实际提示词未要求复刻原作者作品。

## Godot接入方式

当前r3运行时使用 `room1_exit_shadow_receiver_r1.gdshader`，固有色取UV0，烘焙连续灯带照明取UV2。小样Shader只在固有色表达式之后追加世界坐标局部混合；**烘焙光、胶囊阴影、自发光、粗糙度计算保持原逻辑**。

- 新脚本在 `super._ready()` 完成后处理已建立的接收材质，避免被继承链覆盖。
- 仅地板顶面和左墙内表面各一份现有材质接入小样；没有新增网格、UV、灯、相机或碰撞。
- 材质仍在原 `baked_receivers` 中，父脚本对阴影与灯带开关的更新继续生效。
- 贴图最近邻采样；PNG导入为无损、无mipmap。原1280×720、50°水平FOV、2.2m机位高度、固定朝向和XZ跟随约束沿用。
- 2026-10-27追加UV2修复并重烘焙，当前场景和本目录8张截图已采用配套新数据；见[修复对照](../room1_left_wall_uv2_fix_r2/preview.html)。烘焙反射仍按原整室固有色计算，局部新材质未另做反射解算。
