# Room 1 渲染像素密度对照 r1 — 2026-10-14，待审

用户觉得当前画面太高清，同意先试原画、640×360和426×240的同镜头对照。尚未锁定项目像素密度；不将试验分辨率当最终规格。主项目project.godot、原模型／贴图、相机角度和照明参数不改。

打开 scenes/dev/room1_pixel_resolution_test_r1.tscn，F6运行。F1原画1280×720、F2中640×360、F3粗426×240；默认F2。WASD／方向键移动、R复位、K人物阴影、C碰撞、L灯带、H说明仍可用。

场景用共享World3D的SubViewport真正按三档尺寸渲染，独立Camera同步现有固定跟随镜头；不是先渲染高清再贴像素化滤镜。屏幕光晕在场景Viewport内合成，然后以最近邻整数放大；说明文字留在主窗口1280×720。光晕来源分辨率及模糊范围保留，避免试像素密度时同时改变灯光设计。

1280×720窗口下分别为1×、2×、3×。426×240以3×显示为1278×720，左右各1px黑边，避免强行拉伸到1280导致像素列不均匀。小于内部尺寸的窗口允许缩小以保证可见，不作为像素风最终显示方案。

保存6图：三档native原生渲染图及同镜头comparison图；validation.json记录实际尺寸、输出尺寸、最近邻过滤与镜头同步。低分辨率下撞前排P02仍被挡住，摄像机高度锁定检查通过。已目视对照：640颗粒适中；426轮廓颗粒更明显，但小字与细线丢失更多。风格选择仍待用户审图。
