## 本轮改了什么

四套外壳A／B／C／D，各包含盖板、长侧壳、短端壳三张原生贴图。内衬、床垫和截面三张共用新材质，舱内比外壳更干净，不做随机满面污点、破洞、锈蚀或恐怖化损坏。外壳旧化集中在已有接缝、角部、凹槽与接触边，使用细小连贯像素簇，保持主体面板和结构色区。

素材源记录已明确：v3的三张主要外壳底图来自PixelLab；v4后来加了脚本旧化。本次只从干净设计／结构图层和已有P12功能编号准备输入，完全不加载v4的`seam_and_recess_aging`、`coating_contact_chips`及截面的`edge_retained_film`。保留的是认可的设计结构与原PixelLab基础，不把旧手工做旧与新生成叠起来。

材质生成／美术返修全部用PixelLab官方`/inpaint-v3`。先在当前房间检查A和共用内腔，再生成B／C／D。15次实际任务，每次10 generations，共 **150 generations**。原始输出、原创导图、实际mask、提示词、seed、任务ID及用量均保留于`raw/`、`source/`、`result_*.json`，没有重复POST。

Pixel Canals继续是像素簇、材料层次及低模3D承载方式的硬参考；输入仅为本项目资产，未上传其作品截图、模型或贴图。Aseprite／脚本只做结构导图、遮罩、功能编号保留、配准、分层、导出和检查，没有绘制新的旧化图案。

## 技术保护与保留范围

- 尺寸和颜色UV不改：盖板128×256、侧壳256×80、端壳128×80、内衬／床垫128×256、截面128×64，保持原世界像素密度与最近邻采样。
- 原图可能轻微改动非编辑区，最终通过mask恢复原结构／功能像素。A曾把侧壳蓝灰上沿改成白色，B端壳曾在蓝灰底座生出浅色块；因此分别锁定侧壳0–25行、端壳55–79行的原结构色区。B／C／D侧壳生成时已用锁定版mask；其他锁定属于明确记录的几何／色区保护，不是手绘补旧化。
- 编号12是P12样本，作为可编辑功能层保留；长侧面不重新加UNIT01。没有给其他舱复制12，也没有编造人物姓名或运行结论。动态屏幕继续显示已有姓名／系统字段和三条状态条。
- 玻璃及动态屏幕贴图／Shader、全部四个灯管部件保持现状，不属于本轮新生成。不把保留的旧实现宣称为本轮PixelLab产物。灯管亮度、玻璃alpha、反光和屏幕窄边均未改。

## Godot与Blender适配

运行`scenes/dev/room1_pod_pixellab_r16.tscn`按F6。P切换旧v4材料／新候选，K依次切换A–D，O沿用真实开关盖。当前只替换P12的12个实体表面，沿用v8 GLB、控制器、动画、碰撞及原P12开／闭端点光照；其余19舱保持旧版。地板用r15，墙面／灯带用r13，门与房间布局不变。

`scripts/props/cryopod_material_variants_r16.gd`只替换已有实例的`color_map`，可恢复原纹理。六个角色映射到12个实体接收面，不触碰玻璃、显示面、灯管发光面及灯管外壳。Godot截图和`material_bindings.json`读回实际绑定；不是仅凭PNG存在就声称导入完成。
