## 门禁灯语

已核对GitHub main的[一体化门禁约定](https://github.com/Glandy-T/echoes-of-ruin/blob/main/docs/art/ROOM1_INTEGRATED_DOOR_ACCESS_BRIEF.md)：小窗认证黄闪，权限不足显示红色，不亮通行绿灯。按本次用户要求和此前E门交互方案，在运行中的其他认证门接入：

1. 靠近保持暗色待机，按E开始1.5秒认证；小窗0.5秒周期黄闪（亮0.30秒／暗0.20秒），颜色沿用Room1。
2. 没有权限时，小窗红色1.5秒，随后回待机；门保持关闭、不亮绿框，**不弹权限不足模态文字框**。认证中重复E不重启计时，离开1.8m范围或返回室内取消尚未完成的认证。
3. 认证窗在每扇门两侧按现有宽度和位置生成，包含没有走廊接收面的分区门；沿用1.518m中心高、0.115×0.045m小窗尺度。它是已有门禁显示面，不增加独立读取设备或照亮走廊的点光源。
4. [停运人员电梯](../../CRYO_PASSENGER_LIFT_ENTRANCE_BRIEF.md)是专用例外：已有约定明确禁止运行黄闪／红色拒绝认证，因此仍不接入该状态机；停运反馈保持。
