- **身份基准**：`assets/characters/idle.png` 第一帧 96×128，游戏内仍在沿用的偏蓝黑长发、刘海、柔和脸部、宽松浅色休眠服和赤足。
- **历史对照**：11 月 3 日的正面 v2，只用于展示此前的写实偏移，没有作为本轮生成输入。

## 实际生成与用量

通过 Chrome 扩展操作 **PixelLab 官网 Creator → Edit image → Pro**，提交一次，输出 **192×256、32 个可见 RGB 色、二值透明背景**。开启 Remove background，Max colours=32，没有指定外部调色板。账户本期用量 **36→46／2,000，消耗10，剩1,954**；页面显示下次重置／续费为12月13日。没有调用独立计费 API，也没有购买或更改订阅。

原始旧精灵只裁第一帧，并以最近邻放大2倍作输入导图；这是为192×256编辑画布准备的**参考导图**，不把它当新增创作像素或成品。PixelLab重新绘制后的原图单独保留于 `raw/front.png`，最终PNG与它逐字节一致。本轮没有手绘改动。

Chrome文件上传最初被扩展权限拦截，用户开启“允许访问文件网址”后上传成功。官网“Download image”点击后没有返回下载事件；随后通过浏览器只读DOM接口保存**当前可见生成结果自身的嵌入PNG数据**，未重采样、未截图冒充原图。
