2026-10-29，待用户审图。运行 `scenes/dev/room1_door_inner_light_r17.tscn`（F6），F4 比较旧整框变绿／新内侧灯芯。继承 r16 单舱、r15 地坪与 r13 墙／灯带；没有替换 F5 正式入口。

[同机位对照](preview.html)。用户先指出整块门框发光不自然，随后否定了均匀的宽薄荷绿灯面。因此最终候选采用暗色灯槽中的细窄绿 LED 漫射芯；中间失败候选的两张截图以 `rejected_flat_green_*` 保存，不能当作当前结果。

## 实物依据与项目适配

- [CEDES cegard/Smart InfoLight](https://www.cedes.com/en/products/cegard-smart-infolight/)：原厂说明门开启／打开时灯条为绿；原厂的[实装近照](https://media.cedes.com/filer_public_thumbnails/filer_public/1b/64/1b64bbf7-d96f-4689-9651-2cf7f99e15fb/infolight_open_doors_detail.png__650x433.3333333333333_q60_HIGH_RESOLUTION_crop-smart_subsampling-2_upscale.png)可见窄绿灯芯、暗色型材与相邻金属表面。已通过 Chrome 实际查看图片。
- [HÜBNER SensIQ signal](https://www.hubner-group.com/en/products/elastomer-solutions/door-safety-systems/sensiq-signal/)：将照明集成在门沿防夹型材，绿光表达可上车／通行。
- 以上支持的是门沿集成灯和通行指示的做法。没有从照片推断精确色值、光度、灯罩材质或照度；照片本身受曝光影响。四边连续环是本项目已确认的未来设施设计，不能声称现实参考就是同款四边门框。
- 设计判断：前一候选的问题包括发光面过宽、颜色和亮度横截面过于均匀，以及没有暗色灯槽肩部。把绿光减淡成宽薄荷色色条仍然像描边，不能靠更换一个绿色值解决。

## 最终候选改动

- 旧四条方截面门框不再切换到绿色材质。三边外收口保持普通暗色，旧底部装饰条继续隐藏。
- 四个新增单面灯槽面共 16 顶点／8 三角形，放在原门板后侧与黑色门洞背景之间。侧面／顶部有约 26mm 的暗色安装面，中心约 9mm 为柔边灯芯；这些是本次视觉试排尺寸，不是原厂数据。
- 灯芯从中心到灯罩边缘衰减，暗色肩部只有很弱的局部散射。使用普通绿 LED 的方向，取消整片宽倒角的薄荷色发光。没有全屏光晕、额外点光源或照亮整面墙的绿光。
- 门板移动时，实际深度遮挡加实际门板 X 范围限制共同控制露出部分。关闭时不亮；授权通行并打开时亮；半开时只亮左侧及已露出的上下段，右侧等门板移开才露出。底部光面与地坪齐平，没有凸起发光门槛。
- 小认证窗、门板模型／UV／PixelLab 颜色图、门体滑动／碰撞／认证、房间墙地和 P12 材质保持。此轮是灯面、材质发光与遮挡修正，PixelLab 调用为 0，没有生成或手改像素旧化图。

## 验证与局限

- [运行校验](source/runtime_validation.json)：真实靠近、扫描、授权开门、人物穿门、自动关门复位、无权限小窗提示通过；门板／碰撞同步，行程仍为 1.52m，碰撞仍为 1.37×2.30×0.085m。新增面位于门板背后，没有新增 Light3D。
- [截图记录](evidence/capture_states.json)：1280×720 输出、相同游戏机位的旧／新关闭、20%、50%、全开；另有前／左／右斜视角、扫描和拒绝。技术相机只在截图脚本中，不写入游戏相机。
- [像素差分校验](source/render_occlusion_check.json)：比较同机位灯芯开／关，闭合时强制供电仍无可见漏光；20%和50%开度下被挡住的右侧无发光变化。校验只对记录的正面游戏机位作数值判断；斜视角另做人工审图。
- 当前房间使用烘焙／自定义受光材质；这次没有重烘或添加真实动态 GI。灯罩肩部的轻微散射是局部材质近似，不能当作真实墙面反射计算。远处像素镜头下细灯芯会落到约一个源像素，近景才能看清截面。
- 技术校验通过不等于用户认可美术结果。P12 新材质仍只覆盖一舱，其余19舱未因此更新。

## 重现

1. Godot 导入项目，F6 运行 r17 场景，靠近后墙门；F4 比较旧／新灯面。
2. 运行 `scenes/dev/room1_door_inner_light_r17_verify.tscn` 完成真实通行周期。
3. 使用可见渲染窗口运行 `scenes/dev/room1_door_inner_light_r17_capture.tscn`；截图脚本自行退出。
4. Python 安装环境已有 Pillow、NumPy 时运行 `source/check_capture.py`，只读对比截图并输出 JSON，不绘制美术。
