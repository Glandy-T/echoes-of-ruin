# 三亮仓统一玻璃与舱内光 r3

用户要求统一三个亮仓的透光做法。新候选 `scenes/dev/room1_pod_exit_animation_r3.tscn` 将P02/P12/P17全都使用r2同一玻璃透射Shader、同一内衬受光Shader和相同参数。源像素反光纹理保留，舱盖内衬／内盆／内垫均按各自舱内灯的位置受光，G开关同步控制所有三个舱。P12打开状态、出仓动作、两个死亡仓红屏、17个暗仓、原分辨率和相机仍沿用。

统一材质与效果不意味着从每个角度看起来同样亮：P12的玻璃随盖子打开，离舱内光源和视角都不同，距离衰减照常计算。主角仓不再另用旧零透光玻璃。透射／局部辐照仍是Compatibility视觉近似，非物理折射；玻璃像素接缝仍待后续。

运行：R重播，空格跳过，出仓后WASD移动，G舱光，H说明。

实现：r2脚本增加可覆盖的亮仓材质列表，原r2仍为两个闭舱；r3覆盖为三个。没有复制整套Shader或给主角仓另调一组参数。

验证：`validate_room1_pod_exit_animation_r3.gd` 实际渲染8张开关图（三仓近景各2张、游戏镜头2张），检查三个舱共享相同玻璃／内衬Shader、开关同步归零、供电仍为3仓和窗口亮度差。读回结果见validation.json。主角仓近景含打开玻璃及内衬，仍待用户审阅。
