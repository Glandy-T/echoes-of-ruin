## 已观察与验证边界

实际打开检查了两张原生输出、侧面面部和并排图：侧面朝画面右方，背面不露正脸；侧面保持简化脸部与鼻／下巴轮廓，白袍连续、长袖、赤足和头发体块可辨。三张均192×256，alpha头顶y11、脚底最后一行y244，不需要移动或拉伸配准。

`source/validation.json`验证尺寸、原生PNG导出、正面源精确一致、Aseprite可见像素／alpha回读、两次实际任务与对齐数据。头顶与脚底一致不证明肩、肘、膝等被衣物遮挡的关节达到工程精度。发尾下缘、袍身厚度和褶皱并非逐像素对应，后续应在同一个3D体积上统一。

后发轮廓和衣服背面是首次补出的**候选设计**，不是从正面可靠测出的事实。没有额外设计后背开口、绑带或装置；服装如何真正穿脱仍未定案，后续需要时单独处理。当前背面主要是连续白袍与后发体块。

## 拆分原则

1. **身体体系**：头颈、手、脚；头部可单独编辑，皮肤材质统一。衣内人体先保留必要体积与变形参考，不必精修不可见裸体。
2. **白袍**：独立衣物网格，袖子与袍身连续；领口、袖口、下摆有必要厚度。裙摆留变形区域，避免几片纸板拼接。首轮不做布料模拟。
3. **头发**：后发主体独立；前额／侧束用少量体块或可分选组，方便修轮廓。首轮不做逐根发丝、透明发卡或复杂头发物理。
4. **共同动作**：一个角色骨架驱动所需网格；拆分不是把人体剁成互不关联的零件。后续检查衣物穿插、权重、UV和Godot尺度。

AI可能仍生成连成一体的网格，进入Blender后需要实际检查分离、补面、拓扑与权重。当前只建立拆分计划，没有声称已完成拆件或已经适合动画。三视图主稿先完整穿着，部件标注单独提供；本轮不额外生成裸体或未经确认的新装备。

Room 1模型、材质、灯光、镜头、现有占位角色和正式入口均未改动。
