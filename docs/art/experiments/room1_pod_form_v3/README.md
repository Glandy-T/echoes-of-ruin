# Room 1 单舱轮廓 v3：平直主体与克制切角

状态：**轮廓待用户审查，尚未批准为正式资产。**

## 本轮依据

用户指出 v2 圆化过度，与提供的 `Scifi - Cryogenic Sleep` 截图差异明显。本轮按最新反馈修正：保留长侧壁、宽顶面和端部的平直结构；在上沿与四角用短折面过渡，取消胶囊式圆端和连续鼓起的曲面。

参考文件只用于观察轮廓与设计。本模型由脚本重新建立，没有导入、修改或重拓扑第三方 GLB，也没有使用 FreeCAD 几何作为美术模型。

用户提供的参考：Artboard Silvio Pinheiro，[*Scifi - Cryogenic Sleep*](https://sketchfab.com/3d-models/scifi-cryogenic-sleep-3e65d80f30fb4a9e81f721f1c0cb8474)。本次没有将原 GLB 或用户参考截图加入仓库。

## 修改内容

- 外包络沿用当前单舱小样的宽 1.05 m × 长 2.30 m × 高 1.00 m。
- 舱身侧壁为大平面，四角改为单段短切角；上肩和下沿保留必要收边。
- 舱盖采用宽平顶、斜肩与少量小折面，前后端改为平直端面。
- 只在头部保留蓝色窗口区域。蓝色为审查标记材质，尚未制作玻璃表现。
- 舱盖保持一个完整刚性部件。用户要求的“先抬起，再向侧边顺轮廓滑下”仍为设计意图；v3 先审静态轮廓，没有继续扩展动画或导轨。
- 关闭图使用与上一圆化候选相同的相机、灯光、分辨率与审查底座。地面两条线沿用原来的尺度标记，均不属于舱体。

## 轮廓与 UV 的顺序

建模时已考虑大面连续性、头窗边界与接缝位置，并保留名为 `UV_DRAFT_pending_form_approval` 的初步展开。**此 UV 不是已检查完成的绘图模板。**

下一步应在用户确认轮廓后整理 UV：主侧面与顶面保持清晰、易画的岛；接缝优先落在结构转折、底部和内侧；统一朝向与像素密度；用棋盘格检查拉伸和接缝；最后导出像素绘图模板。贴图分辨率、图集安排和全项目像素密度仍未锁定。

不应为了省面把影响轮廓的切角全部取消，也不应依赖纹理补救错误的大形。
