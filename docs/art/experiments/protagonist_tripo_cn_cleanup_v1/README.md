# 国内版主角灰模：有限修整可行性检查 v1

2026-11-06。用户授权：先看最新国内版P2.0主角是否好修；不好修则分层／分件生成，不继续一次生成整个人物。

唯一基线为[国内版P2.0原始导出](../protagonist_tripo_cn_p20_v1/README.md)，源提交 `e1cf58ff8fc58297b380bf566762c06833bcad76`。旧H2.5本地修模已被否决，不使用它的网格、头发体块、头部替换或整体切割方式。

## 边界与判断标准

- 原始GLB、OBJ、MTL、ZIP保持不动，所有试做另存。
- 先诊断真实连接关系，区分导出造成的重合顶点与实际游离面片。连通组件数量不等于合理分件数量。
- 允许删除源模型自带底板，清掉确认独立的细长碎发，并合并几乎完全重合的导出接缝顶点。
- 保留主要头、面部、后发体积、白袍、四肢、原始姿势和尺度；不凭空换发型、不整体换头或重雕人体。
- 用户进一步明确：模型中的发丝太多、对贴图不利，也没有必要。头发只保留发型轮廓和少量宽体块发束，细发丝、卷丝、窄条结构应清理；细节分界以后由像素贴图表达。
- 同机位审看修前修后的正、侧、背、斜视和后发近景。只有实际画面改善、主要轮廓保住，才能判定有限清理值得继续。
- 外观清理与变形网格可用性分开判断；未通过不做UV、像素贴图、绑定或角色替换。

如果必须大幅重建头发／头部或重做主要体积才能修好，停止硬修，按已授权的头发、可见身体和独立白袍方向准备分件生成；新参考图仍按PixelLab工作流，不能拿旧错误模型或第三方NoAI内容作为生成输入。

## 本轮结果：主要细发可以有限清理，候选待审

实际同机位观察：额前细卷丝、两侧多数游离卷丝、后脑叠加的两条长窄发片已减少，长发主体和面部遮挡关系保留。白袍、四肢、姿势、尺度没有重塑。本轮没有额外调用Tripo生成，没有消耗新额度，也没有上传新参考。

具体修改：删除底板组件32；删除经RGB审图确认的10个独立细发组件；另删除主发组件6中只以顶点相接的一条79面细卷丝。共删除424个原始多边面，其中1面是底板、423面是细发。保留面的顶点位置不变，合并1e-6原始单位内的重合导出顶点。最终候选2536顶点、2596个多边面，GLB会正常三角化，不能把两者面数混作同一统计。

合并顶点曾使白袍明暗改变，已通过按原始面和每个角点坐标映射，恢复9864个保留角点的自定义法线；最大分量偏差不超过0.002存储量化容差。最终五组前后截图均在此修正后渲染，使用相同相机矩阵和1280×720分辨率。`source/build_report.json`与`source/delivery_validation.json`记录数据，不能代替外观认可。

**残留与下一步：**主发边缘仍有少量贴主体的细条／小勾和发尾锯齿；后发大面略显壳状，手指、脚部也仍是原始生成精度。这轮确认有限清理能改善外形，不代表已经得到适合UV和动画的完整低模。下一步先审此候选；若继续使用，应将头发边缘整理成少量干净发束，并整理衣服／身体的部件与变形拓扑。若必须大幅改形才成立，则按已授权分件路线制作，不再用整人生成碰运气。当前不推进UV、贴图或绑定，也不把现有开放边界当作已经修完。
