## 做了什么

原始后发不只是独立悬空面片，多数已经和身体融合，直接平滑、删小碎块或布尔切割不能可靠整理。最终按实际面片区域切开，移除破损后发与头顶，补上局部支撑面；保持原身体、宽袖和袍子的主要比例。删除的7个小连通块共40顶点也有来源记录。

为避免旧头顶与新后发产生明显硬接头，本轮同时重建低信息头部、颈部、连续头发主体与少量侧分刘海。脸只保留基础体积及轻微鼻部朝向，不加五官表情、眼球或口腔。它仍需用户审看，不能写成“既定最终发型／脸型”。

对象分为`Gown_Continuous`、`Hands_Source`、`Feet_Source`、`Head_Clean_WeakFeatures`、`Neck_Clean`、`Hair_Main_Clean`、`Hair_Fringe_Clean`共7个。袍身和袖子在同一衣物对象中；手、脚仍按左右成对保存在各自对象，并未做精细指趾或动画结构。颈与头可单独编辑，尚未建立连续的动画身体。后发与刘海是少量实体体块，没有逐根发丝或透明发卡。

保留原表面的自定义法线，避免单纯分件改变衣物明暗；新补面采用独立的支撑几何与法线。脚本用于网格构建、边界整理及验证，不生成或绘画任何材质做旧。

`00_ORIGINAL_REFERENCE`保留原始参考，默认在视口隐藏且不渲染。`01_LOCAL_CLEANUP_CANDIDATE`是本轮修改。`QA_CAMERAS_ONLY`只有静态审查相机，不属于游戏镜头。GLB只包含候选部件，不含原参考、相机、灯光或骨架。

## 如何看图

正、侧、背、前斜侧、后斜侧使用同机位和相同Workbench显示，输出1280×720。`before_*.png`与`after_*.png`是实际模型渲染，不是生成服务重画；`comparison_*.jpg`只是两张原生渲染的相同范围裁切排版。

`part_ids_*.png`额外使用深发／浅袍等纯色材质ID，帮助识别形体和部件。**这些不是PixelLab像素贴图，也不是最终调色／光照效果。**默认Blender视口以部件色显示，正式的灰模对比仍用统一单色，不用颜色掩盖几何检查。

本轮模型身高仍沿用源文件的归一化尺度；新发顶略高于旧源，未标定实际人物身高。身体、房间净尺寸和游戏内占位人物都未调整。

## 复现

用Blender运行`source/build_cleanup.py`，从前一轮原始GLB重新构建独立候选和所有实际渲染；随后运行`source/validate_saved.py`回读，最后用Python/Pillow运行`source/package_preview.py`整理预览。脚本不需要联网或第三方凭据。`source/diagnose.py`可以重建本地坐标诊断，坐标缓存不提交。
