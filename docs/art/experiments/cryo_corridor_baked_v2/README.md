# 4F走廊局部配套烘焙 v2

2026-11-04。为当前3.2m长走廊小样的两侧墙板与地坪增加独立烘焙。像素颜色仍使用室内r24墙板和r26过道裁片；没有新生成或重画材质。F6入口：`scenes/dev/cryo_corridor_baked_v2.tscn`。

[实际效果及原始／降噪对照](preview.html)。E门认证；F8到小样；F9统一开关两条灯带与其烘焙贡献；F10切换raw／denoised。

## 和室内统一的处理

- Cycles DIFFUSE的DIRECT＋INDIRECT、COLOR关闭；不把材质颜色重复烘进光图。Godot按最近邻采样颜色、线性采样HDR光照，固有色乘照度，烘焙倍率1.2沿用室内参数。
- 可见灯带作为独立发光区域处理，不再次乘接收光照；发光色保留像素图变化，按室内的连续灯带辐射尺度与显示压缩方式处理。烘焙发射强度为20×0.06/0.225；运行中没有叠加六个临时Omni补光。
- 1024×1024共享光图，4096采样、关闭自适应采样；4次总反弹／3次漫反射。先做1024采样后在原始近景发现噪声，再提高到4096，保留初次测量记录供收敛对照。降噪只用于线性HDR，不修改像素颜色图。
- 烘焙源包含冻结路线附近的实际墙／楼板、Room 1外侧不透明墙和剖切显示的顶棚作为遮挡／反弹环境；它们是烘焙上下文。运行中仍只替换原小样的三个接收面。

## UV与配套数据

三个连续四边面共享图集，光照密度120px/m。墙一：`(16,16)-(400,424)`；墙二：`(416,16)-(800,424)`；地坪：`(16,448)-(400,736)`。没有把面内两三角拆成不同图岛。

UV2有效三角6个，零正面积重叠、零退化、零越界。图岛原始间隔16px；4px dilation后理论剩余8px间隔。已实际检查墙脚、灯带、四角与地坪边缘；不把间隔参数单独当成无串色证明。Godot导入关闭网格压缩与自动LOD，EXR按线性数据读取。

GLB、raw／denoised EXR与manifest SHA来自同一轮；`audit_bake.py`会重开源工程复查UV2与HDR数据。`uv2_validation.json`、`bake_validation.json`保留完整数值；`bake_manifest.json`位于资产目录。

## 实际检查

`evidence/`包含相同相机、曝光、1280×720输出的游戏镜头、两侧完整墙、完整地坪、四处墙脚和灯带近景的raw／denoised对照，以及关灯／恢复。另保留此前实时补光版的相同游戏与墙板机位供比较。

技术相机只由捕获脚本设置，不保存进游戏镜头；两面墙在技术检查中恢复不透明，避免被遮挡透明规则掩盖表面问题。游戏视角仍使用既有邻室透明机制。

`camera_validation.json`检查按E后认证、黑屏下180°转向、返回室内、透明恢复、反向输入与实时灯关闭。源工程：`cryo_corridor_baked_v2.blend`。可重建脚本：`../cryo_corridor_sample_v1/source/bake_v2.py`。

## 当前边界

这是3.2m局部候选的配套烘焙，不代表整条4F灰盒路线或楼梯已完成美术。小样之外仍保持原灰盒。正式F5仍未迁移；Room 1已有光图、颜色与镜头不变。人物仍是沿用室内照明表现的临时纸片角色，没有把角色烘进静态光图，正式3D人物受光与动态阴影尚待后续制作。烘焙版本较临时补光版更暗，当前保留真实结果供用户审看，未另改曝光或涂亮地面。
