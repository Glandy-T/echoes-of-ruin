# Room 1 摄像机角度与平面跟随试验 r1

2026-10-14。用户明确要求按顺序推进，本轮**只测试摄像机**：参照用户提供的低俯角近侧视室内截图，以主角为中心，随左右／前后平移，但镜头不能上下移动或转动。房间光源与主角行动／物理单独留待后续。

## 查看

在 Godot 4.6.2 打开 `scenes/dev/room1_camera_follow_test_r1.tscn`，F6运行。WASD／方向键移动比例标记；R复位；T隐藏／显示标记；H隐藏／显示说明。镜头没有旋转、升降或滚轮缩放控制。

浅金色1.65m胶囊只是人物比例和跟随目标，不是主角模型或美术方案。移动是在地面 X/Z 平面直接平移，无重力、跳跃或碰撞；可以穿过舱体，不能作为行动／物理通过的证据。

## 当前试验参数

| 参数 | 当前值 |
|---|---|
| 投影 | 透视 |
| 水平FOV | 50° |
| 世界高度 | 2.2m，固定 |
| 与跟随目标的前后距离 | 8.0m |
| 构图中心高度 | 目标地面位置上方0.825m |
| 俯角 | 约9.75°，固定 |
| 初始目标位置 | `(10.5, 0, -4.75)` m，主通道中央 |

这是根据截图做的首个可运行候选，不将角度、镜头距离、FOV或人物显示大小视为用户验收。根节点Inspector可调整导出参数后F6比较；运行中固定镜头参数。

摄像机独立于目标层级。只读取目标的X/Z，世界Y恒定；使用初始化时的固定Basis，忽略目标的Y及旋转。这样未来目标跳跃或转向也不会带着镜头抬升或旋转。未加入跟随缓动、边缘死区或自动旋转，使平面中心跟随可以先单独评估。目标移动范围只是房间内的试验边界，不是碰撞。

房壳／20舱／灯光沿用上轮导入审图，未改GLB、材质、灯光或主游戏配置。前墙、左墙、屋顶继续只在测试副本隐藏。前排舱在低角度镜头下会进入前景；向前移动可能加重遮挡，是否需要后续遮挡策略待用户审图。

## 验证与截图

用Godot实际渲染中央、左／右、前／后和隐藏标记的六张1280×720截图，已目视检查中央、左移、后移和无标记构图。数值检查确认：X/Z等量跟随；世界高度固定；Basis固定；目标构图中心保持在屏幕中心；目标Y变化及旋转不影响镜头；比例标记斜向运动归一化。结果见 `validation.json`。

当前前景舱体、角色显示大小、近墙处构图仍需实际移动审查。用户截图用于角度／构图参考，并未把编辑器截图的精确镜头参数当作已知。

## 复现

```powershell
& '<Godot控制台exe>' --headless --path . --script res://scripts/dev/build_room1_camera_follow_test.gd
& '<Godot控制台exe>' --path . --script res://scripts/dev/validate_room1_camera_follow_test.gd --resolution 1280x720 --quit-after 240
```

生成脚本从上一轮场景另存测试副本；手工修改测试场景后先另存，不直接重跑覆盖。依据 [Godot 4.6 Camera3D](https://docs.godotengine.org/en/4.6/classes/class_camera3d.html)。
