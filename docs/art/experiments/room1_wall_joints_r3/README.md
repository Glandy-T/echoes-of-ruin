## 接缝做法

在既有3.2m左墙样段中加入两条纵向拼接，约1.6m间距。两侧是浅色倒角与内收暗面，中间是连续深蓝灰密封芯；用明确的像素色阶表达装配厚度，而非在主面上加脏斑。大面仍暖灰／象牙白，地面仍使用r2统一蓝灰。

接缝止于灯槽下方、落到保护带上沿，不穿过灯罩，不让整条灯带分节。没有增加横向密集网格、螺丝、设备、文字或家具。借鉴Pixel Canals在颜色图中组织构件亮边／暗边的分工，不复制其都市元素。

256×272图、80texels/m沿用r2候选；暗芯2px约2.5cm，含倒角的完整色阶轮廓8px约10cm，属于本次可读性试值。它们不是全项目工程模数或最终接缝尺寸。只有颜色图改变，几何没有真的挖槽；大幅侧移时不会产生实体凹槽视差，若后续需要可另验证。

## 源文件与范围

`source/build_joints.py`绘制项目原创整数像素层，`source/package_master.lua`用Aseprite另存r3母版，并导出实际可见合成读回。Aseprite从r2的精确PNG底层开始，避免旧透明图层重新合成造成1级颜色舍入；原r2分层母版保持。

新PNG仅有两条8px轮廓范围的3,280像素变化，范围以外及发光面像素完全一致。新接入继承r2的Shader、N诊断还原和r4光照；只切换墙面贴图，地面在两个对照模式中完全相同。没有修改模型、UV、灯光、游戏镜头、门、20舱及人物位置。新固有色的间接反射未重烘焙，不称为新烘焙包。

本轮没有调用AI生成、没有新增额度消耗。独立结构图层比重新生成随机材质更适合本次明确的拼接位置。
