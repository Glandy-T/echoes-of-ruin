# 屏幕柔化扩散 r4 — 2026-10-14，本地待审

用户明确：问题是整片荧光有强烈的方块／截止边界感，不仅是边框线。r3修边框未充分回答这项要求。r4将深蓝底色从发光通道排除，另做向外逐渐衰减的屏幕光晕，保持像素文字本身清晰。

打开 `scenes/dev/room1_glow_sample_r4.tscn`，F6运行。1屏幕、2舱窗、3整舱、4室内；F新旧效果对照（true为r4、false为r3）、N光晕、P附近投光、B屏幕电源、H说明。玻璃材质和内部照明沿用r2，V仍可切换像素反光；玻璃像素接缝留作后续待办。本轮没有提交上传。

## 实现

屏幕原贴图最近邻采样不变。原来的低亮度阈值使深蓝背景也参与发光，在实际Compatibility截图中表现为亮方块。r4候选使用0.28～0.52的亮度权重，降低背景底色，保留文字与亮状态条。此阈值针对当前素材和渲染模式，不能作为所有屏幕的统一值；原PNG和GLB未改。

新效果在单独的1/4宽高SubViewport中渲染P12发光内容；静态可见房壳和舱体以黑色深度遮挡副本保留遮挡。镜头每帧同步原镜头的变换、投影、FOV、尺寸及近远裁剪，Viewport跟随窗口尺寸。透明玻璃不当作不透明遮挡。

四个分离式Gaussian模糊Pass生成近／远两层：sigma2与7，采样半径21；在1280×720时约对应8／28个全分辨率像素的sigma。两层线性过滤，以0.35／1.4权重叠加到原画面；扩散不被限制在屏幕UV矩形内。字形原画没有被模糊，屏幕外受光仍由原局部灯负责。此光晕是镜头散光的视觉候选，不是照亮外壳的GI。

新候选关闭本小样的原Environment Glow，避免旧核继续把内容混成亮板；F恢复r3材质与原Glow。玻璃材质和内部局部灯保留，但新候选没有原全场Glow后处理，因此玻璃等其他物件的后处理光晕也随之关闭。项目渲染模式、主场景、源贴图及旧小样未修改。

## 验证与范围

保存10张实际图：新效果、同核心材质但无扩散层、r3同镜头对照、全部光晕关闭、屏幕关闭、玻璃、整舱、室内，以及发光来源和远层模糊图。开关差分通过，并专门比较屏幕几何投影包围盒外4～48px区域，确认效果越过屏幕边界；屏幕断电隐藏光晕。结果见 `validation.json`。已目视检查近景、来源遮罩、远层扩散和整舱。

只作用于P12的本地审图场景；美术观感仍待用户判断。遮挡副本是静态快照，未完成动态物体同步，也未做全室多屏幕性能测试；不要直接推广到游戏主场景。玻璃像素接缝、灯带最终照明、主角物理均未在本轮处理。
