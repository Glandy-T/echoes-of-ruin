## 原图与选片

生成及美术返修继续使用PixelLab官方`/generate-image-v2`、`/inpaint-v3`。输入仅为项目自己的r14材质和几何导图；Pixel Canals仍是像素簇、材料层次及低模3D承载方式的硬参考，没有向服务上传其作品图像或资产。

开始的部分底材使用r14作为style image，但结果几乎复制原构图。它们被保留为弃用证据，后续改用相同文字方向和蓝灰调色板生成新分布。既有任务不重发POST，所有新任务有独立ID、seed、提示词和额度记录。长划痕、过强条纹、粗剥落或近似复制不算合格差分。实际选片及弃用原因见`source/accepted_sources.json`，相似度检查见`source/source_similarity.json`。

`raw/`保留完整原图。`base_00`、`contact_00/01`、`leak_00`和`edge_00`为认可的r14 PixelLab素材复用，不计作本轮新生成。每次生成实际额度记录在`result_*.json`，合计由`source/quality.json`汇总，区别调用数、合格原图数和最终铺设次数。

最终采用**7份底材、5份舱底接触、4份漏液**：其中新增合格底材6份、接触3份、漏液3份，其余为上述r14复用。20次实际调用（13次生成、7次编辑）每次10 generations，共**200 generations**；8份近似复制或风格不合的结果弃用，原图和原因仍保存。

## 减少重复的方法

- 底材保持原生256×256、80 texels/m，不放大、不翻转冒充新原图。不同PixelLab原图以固定布局安排，避免左右、上下紧邻重复及短距离相同素材回环。
- 为保留用户认可的r14色调，对底材仅做全局调色板配准：每种原始颜色统一映射到r14实际底材色。原图形状与像素簇保留，不逐处补画脏污。映射表逐色记录于`source/base_quilt.json`。
- 相邻素材在48px几何重叠区域选择颜色误差较小的像素边界拼接，输出仍来自原图像素，经上述统一配色；不画拼缝，不加模糊渐变，不程序生成新的污迹。布局固定，运行时没有随机换图。每个原图的实际位置及使用次数全部记录。
- 全室实际有32次原图放置，并非32份独立绘制。7份底材各使用2–6次，邻接不重复；规则256px循环相关性和原图配对相似度另在检查记录中量化，仍以游戏镜头和整张地坪审图为准。
- 20舱底接触使用多张独立PixelLab差分，避免相邻或前后正对舱位相同；实际落地轮廓及所有舱位不改。四处漏液仍固定P03、P06、P13、P18，按实际舱角配准。
- 四层Aseprite母版分别保留底材、四边墙脚、20舱接触、四处漏液；旧人工做旧不混回新图。r14仍保留用于同镜头对照。

## 检查和使用

Godot打开`scenes/dev/room1_floor_variants_r15.tscn`按F6。F比较r14重复底材／r15多原图铺设，N看原色，J回观察点，WASD移动。墙面／灯带保持r13，门和舱体、房间尺寸、UV、碰撞、相机与照明不变。

检查包括原图差异、原生整张地坪、256px规则重复率、拼接边界、20舱配准、Aseprite导出回读及Godot实际左中右游戏镜头、总览、四角、门口、四处漏液与新版P12接触近景。技术图隐藏角色时临时关闭其孤立胶囊投影；游戏镜头比较用原遮挡参数。数值检查不替代实际画面审查，最终仍待用户确认。

本轮没有改变模型或UV，不重新烘焙光照；新材质的间接反射仍沿用上一候选作对比，F5正式入口未替换。待材质确认后再安排统一光照打包。
