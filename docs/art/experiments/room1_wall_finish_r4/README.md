# Room 1 前墙与连续灯槽修复 r4

2026-10-27。前墙贴图错位和灯带／灯槽接头亮度差已一起修复。出仓r3场景与墙地材质小样保持原入口，当前默认读取本版数据。[修前后及全室检查](preview.html)。

## 前墙

前墙内面的颜色UV0原为U=-0.5..0.5、V=0.5..1.5；夹取采样把下半墙固定在底部深色像素上，并把墙脚保护带推到中段。GLB只修改该内面的6个UV角点：U+0.5、V-0.5；Blender源对应U+0.5、V+0.5。现在整面覆盖0–1，保护带回到地面附近。

## 灯带与灯槽

后墙两段和门楣的几何、法线、颜色UV0、发光贴图本来连续。问题是三段采用独立光照图岛，Shader又把收到的烘焙光叠加到发光面上，连周围灯槽也被不同图岛照成几段。

最终分两层修正：

1. 三段后墙内面统一映射到一片按世界坐标定义的连续UV2矩形。原图集其他部分统一缩放到0.875并平移，保留原图岛内部拓扑；新后墙图岛与其余图岛至少有0.01UV（2048图上20.48px）的隔离，配套重新烘焙。
2. 发光贴图标出的灯面只显示统一自发光，不再被其UV2或人物阴影再次调制；灯槽外壳仍受正常光照。使用原#CCDDE4发光色和0.225m可见带宽，并以既有发光面参数20×0.06/0.225归一化可见灯面，保留原显示乘数0.7，避免去掉重复受光后变成灰暗不亮的条带。此为可见发光材质归一化，实际烘焙四条发光面的几何／颜色／能量不变。

贴图中灯框外侧的微小结构刻线保留；修掉的是横跨门楣的发光面和灯槽亮度断点。没有重画原生颜色PNG、改配色、加装灯具或新增墙缝。
