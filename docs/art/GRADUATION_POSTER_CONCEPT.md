# 《Echoes of Ruin / 終末残響》毕业制作海报：概念草案

更新：2026-11-17。**状态：创意方向已形成，视觉造型尚待参考研究与审图；不是最终海报规格。**

## 1. 标题的含义与设计目的

“残響”不是指城市实际发声，也不是以音乐、音频播放器或音游为主题。城市及其文明已经沉寂，主角通过建筑、设施、记录和遗留痕迹逐步拼凑其最后的历史，仿佛听见一座死去城市的最后声音。海报应以**死物似乎仍在发声**的视觉隐喻表现这一主题。

同时，宇宙／天文中的“来自过去的信息延迟抵达”可以与游戏结局的宇宙线索形成第二重解读；**不直接展示结局，不在海报中画出飞船或解释真相**。观众第一次看感受到城市的沉默与余响，了解故事后才可能读出宇宙关联。

## 2. 已提出的核心构图

- **整体：极简黑白平面海报**，以剪影、负空间、光的形状和标题为主要语言；不走复杂游戏场景插画路线。
- **下方：正常方向的城市黑色剪影**，以建筑轮廓形成清晰的城市意象。
- **上方：倒置的城市黑色剪影**，与下方互相逼近、层叠，但不必机械镜像或严格对称。
- **中间：上下建筑轮廓共同挤压出一条不规则缝隙／负空间**。缝隙要让人隐约感到“波”“余响”“振动”，但不应直接画成规则音频波形、心电图或频谱柱。
- **光回声：参与整体视觉组织**。借鉴天文“光回声”（过去发出的光沿不同路径经散射而延迟抵达）的形态，使纯黑白／灰阶画面中出现少量“光”、延迟轮廓、衰减弧线或光的层次。光必须与剪影、空隙协同，不是硬贴一个科幻同心圆装饰。
- **标题：最后加入**，使用项目名 `Echoes of Ruin` / `終末残響`，字形与位置在主视觉确定后研究。

**当前明确的不是**光回声采用同心弧线、错位残影还是其他光学造型；也未决定空隙偏尖锐撕裂还是柔和流动、上下剪影是否严格对应过去与现在、标题位置和海报尺寸。这些仍需继续找参考，不能由 Codex 或设计助手默认为已批准。

## 3. 三个需要分别研究的视觉问题

### A. 城市剪影如何形成第二重图像

研究黑白负空间、上下倒置城市、建筑高低疏密与剪影交界；参考最初用户分享的《活死人之夜》海报所体现的“主体剪影 + 隐藏负形”的视觉机制，而非复制其中的手掌、树木或具体画面。重点是：即使没有细节，观众也能识别为城市；第二眼才察觉另一层含义。

### B. 缝隙如何表现声音而不变成音游

研究声学与抽象平面设计中的：波的反射与干涉、散射、衰减、地震尾波（seismic coda）、不规则重复、疏密变化、断裂、缺失和留白。多普勒效应可用于研究波阵面的疏密变化，但它不等于“残响”；避免直接把示意图贴进海报。优先观察建筑本身能否**围出**声音意象，而不是额外叠加波形。

### C. 光回声怎样融入黑白构图

研究天文光回声照片（例如 V838 Monocerotis）、超新星遗迹的余辉及抽象黑白光学海报。核心是**已结束的事件，其过去的信息在后来仍可被接收**。光回声并不要求光源已经死亡；这是一种设计隐喻而非游戏世界中的实际物理机制。考察少量光弧、分层衰减、遮挡、局部高光、残影如何与城市的剪影边界共同工作。避免星空、星球、飞船和大面积霓虹把海报变成通用科幻封面。

## 4. 风格边界和评估标准

1. 优先黑白；允许少量灰阶作为光的层次，暂不引入蓝紫色科幻配色。
2. 先确保纯黑白剪影和中央负空间在缩略图尺寸下成立，再试验光回声。三种意象不必等权。
3. 不要求放入主角；目前倾向**完全不放人物**，由城市独自承担叙事。
4. 城市应与本作巨型人工盆地、层级化未来城市的设定兼容；可抽象，不强制准确绘制整个盆地，也不要套用普通现代摩天楼天际线。
5. 不要用音符、音箱、麦克风、耳机、标准均衡器、整齐音频波形来解释“声音”。
6. 整体追求有辨识度的单一视觉符号，而非把建筑、声波、光环、宇宙分别堆成四个装饰层。
7. 先找真实设计参考、比较负空间与光学表达，再进行构图试验；**当前仅存档概念，不授权直接批量生成最终海报**。
