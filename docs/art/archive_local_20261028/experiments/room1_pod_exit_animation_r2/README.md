# 闭舱窗光可读性修正 r2

用户指出主角仓对面玻璃为黑色。P02确实是第三个亮仓；原验证只统计灯节点启用，没有证明玻璃在游戏镜头下可见亮光。近景对照显示：仅增加代理灯亮度或关闭阴影不能可靠解决低角度下黑窗。

新候选 `scenes/dev/room1_pod_exit_animation_r2.tscn` 继承出仓r1，只修正P02/P17的窗光表现。内垫、固定内盆和舱盖内衬按舱内灯位置增加局部渐变辐照近似；透明玻璃增加局部透射辐亮度近似，保持原像素反光、透明度及渐变。玻璃Shader用EMISSION表达透过来的光，这是Compatibility下的视觉近似，不是物理折射／真实体积散射。玻璃和内衬亮度均与G舱光开关及供电编号绑定，暗仓不套用此效果；已有真实代理灯和投影保留。

P12开舱、出仓动画、三个亮仓、P02/P17红屏、原分辨率、相机和碰撞均继承r1。R重播，空格跳过，G开关窗光。

制作源：r2场景构建脚本、运行脚本、内衬Shader和玻璃透光Shader。验证脚本实际渲染6张图：P02/P17近景开关各2张＋正常游戏镜头开关2张。窗口投影区域蓝色亮度差必须大于0.01；检查G关闭时两个材质供电归零、只修改2个闭舱且三仓配置保留。validation.json记录测量值。画面仍待用户审阅。
