# マップデザイン

## 記録方針

本書はレベルデザイン仕様を記録する。現行の `res://scenes/dev/prototype_room_a.tscn` は端末とドアを用いた機能検証用の簡易プロトタイプであり、以下の序章 Room 1「Cryogenic Room（休眠ポッド室）」のレイアウト、演出、調査対象は未実装である。

## 都市全体の空間構造

都市は、広い低地・盆地状の地形を利用して長期間拡張された巨大都市として設計する。俯瞰では完全な同心円ではなく、不規則な円形・楕円形に近い輪郭とする。

- **中央高地区**：天然地形と人工造成を組み合わせた高地。富裕層居住区、科学技術区、政治中枢区を置く。
- **下層居住区**：中央高地区の周囲に広がる高密度住宅帯。数十階規模の建物が連続し、建物間隔、霞、地形差によって日照が乏しい。
- **外縁管理帯**：自然高地、人工堤、工業、生産、物流、隔離、休眠、監視・防衛施設が不均一に連続する広い管理帯。巨大な一枚の城壁や都市全体を覆うドームにはしない。
- **地下インフラ**：単純な下水道ではなく、水循環、排水処理、廃棄物分解、材料回収、資源再生、物流、保守、地下交通などが重なった巨大な都市基盤。都市の「代謝器官」として扱い、後に主人公が中央高地区へ到達する保守経路にもつながる。

崩壊前、中央高地区の正式入口は認証、隔離ゲート、自動警備、制御交通によって守られており、下層の住民が多数で押し寄せても容易に突破できなかった。主人公は数十年後、停止・劣化した制御系統と地下保守経路を利用して、本来一般市民へ開放されていなかった経路から進入する。

## 都市交通の基本構造

都市は約300km級のため、住宅・配給・教育・基礎医療・日常就労を各生活ブロック内で完結させ、地区間の移動量そのものを抑える。ブロック間は地下・高架の大量輸送軌道、都市規模の高速幹線・環状幹線で接続する。

ゲーム本編で主人公が外縁工業区から政治中枢区へ到達するまでの物語内時間は、移動・探索・休息を含めて**約7〜10日**を目安とする。実際の都市距離をすべてプレイ可能マップとして再現せず、区域間の長距離移動は場面転換や時間経過で省略する。

下層内部では比較的自由に移動できるが、工業区、中央高地区、科学技術区、政治中枢区などへの移動は、IDに紐づく職務・居住権限によって制御される。階級境界は巨大な城壁だけでなく、駅、乗換ノード、隔離ゲート、認証扉、制御交通によって成立していた。

工業区には一般旅客網と分離された物流軌道・地下搬送路を配置する。社会崩壊後は、こうした交通網の停止と認証系統の残存が人の移動を強く制限し、現在のゲームでは通常交通ではなく保守・地下経路が探索ルートとなる。

## 序章：工業区休眠施設の全体構成

### 施設の機能構成

この建物は、人類保存計画の実施に合わせて工業区内に新設された専用の休眠収容施設である。既存の職員住宅や住民向け病院を転用したものではなく、工業区住民の生活機能を圧迫しない独立区画として建設され、休眠ポッド、生命維持、収容管理、非常電力を一体化している。使用される休眠装置そのものは、地球外移民向け長期休眠研究から生まれた初期型・長期運用基準未達の系統を再利用したものである。工業区全体は、生産・物流・備蓄・保守・保安が一体化した重要インフラ区域として設計されていた。

人類保存計画の施設は都市内に密集しているのではなく、広い休眠割当区域ごとに一つの主要施設を配置する。主人公の施設も、その工業区と周辺下層居住区を含む一つの割当区域を受け持つ第一期施設である。主人公自身は工業区の特権要員ではなく、この区域に属する下層市民の抽選枠から選ばれた。

同じ割当区域内では第一期施設のみが実際に稼働した。第二期用の専用施設は建設途中で停止しており、必要なら序章後の背景・遠景・通過地点として、未完成の外殻や資材だけを見せてよい。ただし内部に休眠者は存在せず、第二の「生存者探索ダンジョン」にはしない。

| 範囲 | 機能 |
| --- | --- |
| 1 階 | 申請者受付、登録、身体検査、警備、出入管理、正面玄関、非常解除設備。 |
| 2 階以上 | 基本的に休眠収容階。複数の休眠処置室、フロア単位の監護・サービス空間、職員事務室、設備保守空間、エレベーター、非常階段を持つ。 |

各休眠処置室には数基の休眠ポッドがある。建物全体では多数を収容できるが、社会全体の申請者数に対して休眠枠は大幅に不足していた。

### 序章での進行方針

主人公は **4F の休眠区** で目覚める。4F より上に続く非常階段は崩落により通行不能とし、主人公は下階へ向かい、複数の休眠階を経由して 1 階を目指す。

すべての休眠階を完全なマップとして制作する必要はない。一部の階では短い範囲だけを移動可能にし、それ以外は背景または閉鎖された入口として示す。

- 多数の休眠処置室の扉と連続する部屋番号。
- 観察窓越しに見える停止した休眠ポッド。
- 各階に共通する中央サービスカウンター。
- 通行不能の廊下、変形した防火扉、崩落物で塞がれた区域。

これらを用いて、主人公がいる部屋が巨大な収容施設の一室に過ぎないことを示す。

### 工業区の職員居住区域

工業区には、生産・保安要員とその家族が暮らす専用居住区域を設ける。一般下層居住区より住宅密度が低く、配給・医療・教育・休養施設も安定していたことが分かる構成とする。ただし、富裕層居住区ほど広い空間や自然環境、自由な選択肢は持たせず、「都市の重要人材に与えられた条件付きの良い暮らし」として表現する。

### 工業区の秩序と無人運用の痕跡

工業区の生産中枢は、下層の蜂起によって制圧された場所として描かない。社会混乱期にも一般市民へ中核を開放せず、必要な物資は外縁の管理地点から限定的に供給した。休眠枠や資源配分をめぐる抗議、衝突、封鎖の主な痕跡は、下層居住区、資源分配地点、工業区外縁部とする。

工業区内部は、長期間無人であっても整然、厳密、冷淡で、生産設備・物流構造・保安設備の制度的秩序が残る空間とする。内部の損傷は、長期の無保守、設備老朽化、エネルギー枯渇、局所的な自然構造損傷を主因とし、略奪や内部暴動の痕跡を主要表現にしない。後の下層居住区に置く過密、混乱、仮設構造、抗争の痕跡との対比を重視する。

施設は人間とロボットの共同運用を前提に設計されていたが、現在活動できるロボットは存在しない。ロボットは予備電源の優先供給対象ではなく、電力が生命維持、緊急安全、少数の端末だけを支える段階に入った後、すべて停止した。

後続の場面設計では、必要に応じて以下の構造痕跡を用いる。

- ロボットの停泊・充電区画。
- 低位置の保守インターフェース。
- 搬送ロボット用の通路と誘導表示。
- 医療設備・休眠設備の機械接続部。
- 自動配送口。
- 機械認識用の番号・標識。
- 自動清掃、巡回、輸送、保守に必要な空間構造。

すべての場面へ故障したロボット本体を置く必要はない。空の停泊区画、停止した接続部、機械専用通路だけでも、かつての運用体系を示してよい。各構造の正確な形状と配置は **TBD** とする。

## 4F 休眠区

4F は一層全体が休眠区であり、複数の休眠処置室、主廊下、エレベーター、施錠された安全通路扉、4F を担当する監護空間を持つ。この監護空間は建物全体の中央制御室ではなく、4F 専用のフロア監護施設である。

### 安全通路と非常解除

安全通路は生命安全設備であり、電力やネットワークに完全には依存しない物理的な解除方式を持つ。通常は電子権限システムで制御されるが、現在は電子系統が衰弱している。

主人公は 4F フロア監護ステーションに保管された機械式の非常解除工具を取得し、安全通路を進めるようにする。

| 項目 | 内容 |
| --- | --- |
| 解除工具名 | **暫定：** `非常用機械解除キー` |
| 保管方針 | 制度化されたフロア非常保管モジュールに保管する。通常の引き出しなどへ無造作に置かない。 |

監護ステーション周辺には、小型の職員補給コーナーまたは保管区を置き、長期当直を担った職員の生活痕跡を残す。職員配給、未来技術、高効率の機能主義、実際に人が働いていた感触を同時に示す。

## 序章：工業区／休眠施設 — Room 1「Cryogenic Room（休眠ポッド室）」

### 部屋の役割

本室はゲーム開始、基本操作のチュートリアル、調査システムの導入、雰囲気の確立を担う。複雑な謎解きは置かず、主人公の状態、調査、基本的な環境インタラクションを理解させることを優先する。

- 主人公の記憶喪失、不安、主体的に答えを探す性格を提示する。
- 放棄された施設、目覚めない人々、孤独感を見せる。
- 後期の完全な真相は開示しない。
- 序章全体で扱う「人類保存計画」への問いを準備する。ただし、**この Room 1 の端末・装飾から計画を大量に説明しない**。

### 空間・環境の方針

白く空間の広い、標準化された医療用休眠処置室とする。かつては清潔で機能的だったが、長期の無人状態により、埃、亀裂、破片、局所的な崩落が生じている。

- 主な色：白、薄い灰色、冷色の影。ただし非常状態では白い壁や床も暗い冷灰色として見える。
- 主照明は停止しており、室内の主な光源は弱い非常灯ライン、ドア横の認証パネル、主人公の休眠ポッド内部からガラス越しに漏れる冷光とする。
- 部屋全体を明るくせず、最低限の形状と導線だけが読める明るさにする。
- 背景素材へ強い投影を固定せず、Godot の 2D リアルタイム光源と遮蔽で主人公・設備の影を動的に表現する。
- 環境音：低い機械音、電流ノイズ、滴水音。BGM は無音または極めて弱くする。
- 医療キャビネット、カート、制御箱、ケーブル、破片を少量配置する。
- 明白な政治宣伝、計画の標識、過剰な装飾は置かない。大半の環境物はインタラクト不可とする。
- 人間とロボットの共同運用を示す構造痕跡を必要な範囲で置くが、活動中のロボットは登場させない。
- 損傷表現は老朽化、電力枯渇、局所的な構造損傷を中心とし、略奪や室内暴動を示す散乱を置かない。

### 開場演出

1. 画面を暗転させ、微かな機械音、警報ノイズ、設備作動音を流す。
2. 主人公がまだ暗闇の中にいる段階で、途切れたシステム音声として「予備電源……残量低下……」「長期生命維持……継続不能……」「緊急覚醒シーケンス……開始……」などを断片的に聞かせる。
3. 暗闇の中で、主人公の休眠ポッドが弱い冷光を発する。
4. ポッドが減圧し、扉が開く。
5. 主人公が目を覚まし、戸惑いと不安を見せる。
6. 主人公は身体を起こし、裸足でポッドから出る。
7. カメラをわずかに引き、暗闇の他の休眠ポッドを見せる。
8. 短い独白で、記憶喪失・不安と、自ら状況を確かめる姿勢を示す。
9. 演出終了後、プレイヤーへ操作権を渡す。

演出中はプレイヤー操作を禁止し、通常のゲーム UI とポーズボタンを隠す。演出の背景には、軍用予備電源の残量低下により長期生命維持が継続不能となり、システムが最後の緊急覚醒手順を開始した事情がある。主人公のポッドは偶然ここまで機能していたにすぎず、この時点ではその意味を説明しない。演出終了後に操作とインタラクションを有効化する。

### 休眠ポッドの構成

室内には約 5 基の休眠ポッドを置く。

| 種別 | 状態・役割 | 主な調査対象 |
| --- | --- | --- |
| 主人公の休眠ポッド | 唯一、弱い灯りが残る。扉は開いており、設備は最低限だけ稼働する。 | 可 |
| 停止休眠ポッド A | 完全に断電している。 | 基本は不可 |
| 停止休眠ポッド B | 内部故障、または扉が開かない。 | 基本は不可 |
| 損壊休眠ポッド | 天井からの落下物で直接破壊されている。 | 可 |
| 死亡者の休眠ポッド | ガラス越しに目覚めなかった人物がかすかに見える。 | 可 |

全ポッドを調査可能にする必要はない。停止休眠ポッド A/B は施設規模と空間の雰囲気を見せるためのものとする。

詳細表示中はゲームを一時停止する。簡易表示中は主人公の移動を止め、短い会話を表示する。

### 主人公の表現

本室の台詞は [CHARACTER_DESIGN.md](CHARACTER_DESIGN.md) に従う。記憶喪失と不安を表しつつ、主人公が観察し、行動し、出口を探す人物であることを示す。

- 軽い毒舌・ブラックユーモアは必要なときだけ使い、話しすぎない。
- 死亡者を前にした場面では皮肉を抑え、沈黙または短い言葉で感情を示す。
- 主人公がその時点で知らない情報は台詞に入れない。
- 具体的な台詞は **TBD**。本書では口調と役割だけを定める。

### 端末と出口

部屋の右側に身元認証端末、電子ドア、開放後に見える門洞を置く。

1. 未認証の状態で電子ドアを調べると、ロックされていることを示す。
2. プレイヤーが認証端末を調べる。
3. 端末が主人公の身元を検出・確認する。
4. 電子ドアが自動で上方に開く。
5. 門洞が現れる。
6. プレイヤーが門洞でインタラクトすると、次のシーンへ移動する。

端末の役割は基本的な身元認証と開錠だけである。端末を使って世界観を大量に説明しない。

### プレイヤーの想定フロー

開場演出 → 主人公の短い独白 → 操作権の取得 → `休眠者識別票` の調査 → 任意で同意書・他の休眠ポッドを調査 → 他者が目覚めなかったことを確認 → 身元認証端末を調査 → 電子ドアが開く → 門洞でインタラクト → 次の部屋へ移動

### Room 1 の設計原則

- 全物体の調査を強制しない。
- 複雑な謎解きを入れない。
- 多数の文書や端末を積み上げない。
- 後期の真相を先取りして明かさない。
- 白い医療空間の空虚さと静寂を保つ。
- チュートリアルとして、明快な導線と簡潔なテンポを優先する。
