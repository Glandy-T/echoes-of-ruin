# キャラクターデザイン — 主人公

## 基本設定

主人公は若い女性であり、外見の方向性はアジア系女性を**暫定**とする。彼女は過去の記憶を失っている。物語の中で過去の人格や生活史を取り戻す構成にはせず、自分が下層居住区の一般市民であり、区域ごとの抽選によって休眠対象になったことだけを後から確認できる。

主人公は特別に選ばれた存在ではない。軍用予備電源の枯渇直前まで偶然に稼働を維持した休眠ポッドから、緊急覚醒によって目覚めた一般の生存者である。あと少し遅ければ、他の休眠者と同じくポッド内で死亡していた可能性が高い。

## ピクセルアート制作基準

- 論理解像度 640×360、1280×720 へ 2× の整数拡大、nearest-neighbor 表示を基準とする。
- 主人公の基準 Sprite は原寸で約 96 px の身長を目安とする。
- 過度なデフォルメや機械的な縦方向の引き伸ばしを避け、女性の自然な人体比率と既存デザインの印象を優先する。
- 基準 Sprite を確定した後、idle、walk、調査などを同じピクセル密度で展開する。
- 休眠時の衣服は白〜冷灰色の簡素な患者側の医療・休眠用衣服を方向性とするが、最終デザインは未確定。

## 性格と行動原理

記憶喪失と孤独な環境は主人公に不安を与える。しかし、彼女は慌てたり萎縮したり、他者の助けを待ち続けたりする人物ではない。周囲を観察し、自ら出口と真相を探す。

- 冷静で、好奇心と観察力がある。
- 主体的に行動し、得られる情報を確かめながら進む。
- 表面上は淡々としていても、死者や失われた生活の痕跡に冷淡ではない。
- 深刻な場面では、沈黙、間、短い言葉によって不安・同情・孤独を表す。

## 台詞規則

主人公は軽い毒舌やブラックユーモアを時折使う。これはプレイヤーを頻繁に笑わせるためではなく、荒唐無稽で恐ろしい、理解不能な状況に対して自分の冷静さを保つ態度である。

- 主人公がその時点で知っている情報だけを台詞に用いる。
- 第四の壁を壊すメタ的な台詞は使わない。
- すべての通常物体へ反応させず、必要な対象だけに台詞を置く。
- 皮肉・冗談を頻発させず、終末世界の静寂を損なわない。
- 深刻な場面で無理に冗談を言わせない。
- 作者自身の自然な感想を起点にしてよいが、主人公の性格、現在の認知、置かれた状況に合わせて調整する。

### 一人称

現在の主人公の一人称は **「僕」** を基本とする。ただし台詞では主語を頻繁に用いず、必要な場面だけで使用する。

休眠前の一人称・口調・人格を対比材料として設定しない。過去の映像・音声記録を通じて「昔の自分」を取り戻す展開も採用しない。現在の主人公が、失われた過去ではなく目の前の都市と制度をどう見るかを優先する。

## 人物表現の原則

調査文や独白は、情報提供と主人公の人物像の両方を担う。ただし、説明のためだけに長い独白を置かない。とくに死者、廃墟、過去の生活の痕跡に触れる場面では、短い反応または沈黙を有効な表現として扱う。
