# Room 1 seam contact r6

Four full-wall color maps, each exported from an eight-layer Aseprite master. They correct the r5 clean moat between seam core and aging. Only seam shoulder pixels change; seal core, diffuser and all other wall pixels remain identical.

Scene: `scenes/dev/room1_seam_contact_r6.tscn`. V compares r5/r6. Floor and all other assets continue to use r5. No geometry/UV/light change or new GI bake.

Sources, comparison and validation: [experiment](../../../docs/art/experiments/room1_seam_contact_r6/README.md).
