# Room 1 floor palette r9

Cool neutral blue-gray correction for r8's rejected yellow-green deposits. All ten layer alpha masks, pod footprints and deposit locations are identical to r8; original floor coating and base-material RGB stay unchanged. Only deposit RGB and the warm pale pixels of the existing leak crust change.

Run `scenes/dev/room1_floor_palette_r9.tscn`. F compares r8/r9 palette, I compares matching irradiance. Original geometry/UV2 and lighting parameters stay unchanged. Both floor maps are exported from editable 7/10-layer Aseprite masters, with matching packed Blender and HDR.

[Source and comparison](../../../docs/art/experiments/room1_floor_palette_r9/README.md). Raw HDR remains local or packed inside the source; Godot scene shaders bind current floor PNGs to the unchanged GLB carrier.
